开始之前：需要知道的词

暗物质。 星系和星系团的运动方式很奇怪。就好像存在比我们看到的质量更多的质量。整个宇宙的历史也需要它。这些额外的质量称为*暗物质*。它不发光，也不吸收光：我们只能通过它的引力察觉它。

重子。 普通物质由*重子*构成。恒星、气体、行星和我们自己都由这种物质构成。重子主要是质子和中子。

Ω 和 ω。 Ω_b 表示宇宙中由重子构成的部分。Ω_c 表示宇宙中由冷暗物质构成的部分。小写字母 ω_b 和 ω_c 是同样的量，乘以一个固定的数。这个数与今天的膨胀有关。比值 ω_c/ω_b 等于 Ω_c/Ω_b。

比值 3√3。 在本工作中，施加的条件是：就宇宙平均而言，暗物质是普通物质的 3√3 倍。3√3 约等于 5.196。

标准宇宙学 ΛCDM。 它是描述宇宙历史最常用的模型。它包含暗能量（Λ）和冷暗物质（CDM，是 cold dark matter 的缩写）。*冷*的意思是它的粒子运动缓慢。

Planck 和 DESI。 Planck 是一颗卫星。它测量了*宇宙微波背景*（CMB）：宇宙最古老的光。这种光在宇宙还非常年轻时发出。DESI 是一项大型星系巡天。它测量*重子声学振荡*（BAO）。这是星系分布中留下的一个典型距离。它起着宇宙标尺的作用。

红移 z。 遥远星系的光在宇宙膨胀时被拉长。这种移动记作 z。z 越大，星系就越远，我们看到的时间也越早。

RAR 和 a₀。 在盘星系中，每一点都比较两个加速度。观测到的*加速度 g_obs 来自恒星和气体的运动。仅由重子给出的加速度 g_bar 来自对我们所见物质应用牛顿（Newton）定律。两者之间的联系称为*径向加速度关系，RAR。它只有一个尺度 a₀。对近邻星系，它约为 1.20 × 10⁻¹⁰ m s⁻²：这是本工作使用的 SPARC 值。

拟合和似然。 把模型*拟合*到数据，就是选择模型中的数字。选择的标准是让模型尽可能贴近数据。似然*衡量它做得有多好。这里使用两个误差分数：χ²（读作 *chi-squared）和 Q。它们越低，模型就越贴近数据。

σ。 它是一次测量的典型误差。

预注册。 一个假设在看到将用来检验它的数据之前就被写下并标明日期，就称为*预注册*。

简而言之

数学物质性（MM）是作者的框架。这条记录要问的是：由 MM 提示的单一暗物质解读，能否同时处理多个问题。能给出数字的部分与公开数据作了比较。

这些部分是彼此独立的研究。 共有四项：宇宙学比值的拟合、RAR 演化的拟合、衰变分析和隐藏扇区构造。既没有联合似然，也没有把它们全部连接起来的完整动力学模型。

明确表述的假设（第 6 节）。

  • 我们通过引力感受到的冷暗物质密度，将是*隐藏扇区*的物质。这种物质有自身的内部相互作用。它不同于计入 ω_b 的可见重子。
  • 用 MM 的话说，它是一个“镜像”的普通物质，这个镜像在自身的定律中是正常的，其常数相对于我们的常数来解读。
  • 它的粒子质量、无量纲耦合和热历史仍未指定。*耦合*表示力有多强；*无量纲*的意思是它们是纯数，没有单位。
  • 另外，施加了宇宙学平均密度之比：ρ_c/ρ_b = 3√3。

一个日常生活中的例子，帮助形成概念。两台调到不同频率的收音机互不干扰：一台听不到另一台。但两台都压在同一张桌子上。在这里，隐藏扇区和我们的扇区不能通过光*感受到*对方，但它们通过引力相互吸引。

三点说明，文本马上就给出了：

  • 多一条公设。 这一诠释还设定，隐藏*辐射*不作为我们宇宙膨胀的源。这并不能由两种光彼此分离这一事实得出。没有实现这一点的完整*协变*模型。协变的意思是写成对每个观测者都成立的形式，这是相对论的要求。
  • 完全相同的副本被排除。 假设引力以同样的方式作用于一切。那么，一个与我们的扇区温度相同的副本会增加太多的辐射：ΔN_eff ≈ 7.4。这被测量排除了。隐藏扇区的碰撞、冷却和盘必须单独研究。
  • 一个例子是不够的。 一个带单一标度因子的算例满足两个近似的*屏蔽*不等式（散射和残余电离）。它并不表明这样的隐藏扇区真的可行。还缺少完整的计算。

与数据的一致性检验。 程序 python riproduci.py 报告 745 项通过的核查。它们是代数恒等式、数值计算和对存档宇宙学结果的一致性核查。该程序不重复宇宙学似然的极小化。

  1. 比值 Ω_c/Ω_b = 3√3 = 5.196。
  2. 使用平直 ΛCDM，中微子质量之和 Σm_ν = 0.06 eV。
  3. 施加 ω_cdm = 3√3·ω_b。数据是 Planck 2018（lite TTTEEE、低 ℓ TT 和 EE）加 DESI DR2 BAO。分数 Q 上的代价是 T_B = 0.17。如果加入 Planck 透镜重建，代价是 0.23。计算用程序 CLASS 和 Cobaya 完成。
  4. 这么小的代价意味着所施加的比值与数据相符。
  5. 如果让比值自由变化，拟合给出 ω_c/ω_b = 5.22 和 5.21。
  6. 这是一项*回溯性*的一致性评估：它使用已经存在的数据。它不是独立的*前瞻性*检验，也就是针对尚未到来的数据的检验。针对特定未来数据的前瞻性检验已经预注册。
  7. 在 MUSE-DARK III 的四个分箱中，RAR 的加速度尺度随红移增长。 分箱（bin）是一组距离相近的星系。
  8. 在三条定律（常数、哈勃率、宇宙年龄的倒数）中，H(z) 给出最低的 χ²。
  9. 这一拟合在绝对意义上有多好，在很大程度上取决于如何读图上的误差棒。如果误差棒是 1σ，χ² = 5.48。如果是 95 %，χ² = 21.04。两种情况下都有三个自由度。
  10. 其他简单形式也一样好。z ≈ 2 的星系与这条定律存在张力。
  11. H(z) 作为*唯象*假设（因为能描述数据而选择）保留下来，并为未来数据作了预注册。
  12. 没有偏好衰变的迹象，这里指（几乎）全部暗物质以恒定速率衰变为暗辐射。在计算的剖面中，最低值位于 Γ = 0，也就是没有衰变。约定的阈值是 ΔQ = 2.71。在该阈值处，对*共动*损失的名义临时限制，带透镜重建时约为 2.6 %。不带透镜重建时为 3.8 %。*共动*的意思是在一个随宇宙一起增长的体积内计算：所以膨胀造成的单纯稀释不算损失。
  13. 星系团。 固定的比值给出的重子比例（在重子加冷暗物质上计算）为 0.161。它与大质量星系团的重子收支大致相符。不过，星系的 RAR 不能描述星系团（X-COP）：这个问题依然存在。

这一解读试图连接的问题（第 7 节）。共有四个。第一个是暗物质与重子之比。第二个是 a₀ 的宇宙学尺度。第三个是没有直接探测信号。第四个是暗物质的行为：在宇宙学中它表现为*冷*的，在星系中它遵循 RAR。这些联系的地位各不相同：施加的数值假设、唯象拟合、定性假定。其他研究计划也在处理这些问题的各种组合。支持这一解读的理由就在于这种*融通*（consilience）：一个想法把许多问题放在一起。而且只有当更多联系变成定量时，这一理由才会增强。

这项工作可能怎样被证明是错的（第 10 节）。有两个定量假设，为未来的检验事先声明了不成立阈值。

仍然开放的问题。

  • 隐藏扇区的动力学：热历史、等离子体、碰撞。
  • 子弹星系团的细节。它是一对发生过碰撞的星系团。
  • 从理论得出 a₀。MM 的字面值 cH₀/2 是测量值的 2.73 倍。
  • RAR 的推导。
  • 隐藏辐射不产生引力的协变模型。

1. 物理学家会认出的内容

这些部分使用已知的工具和想法。

  • 固定比值 ω_c/ω_b 的 ΛCDM 拟合。 使用标准的似然和程序：Planck 2018、DESI DR2、CLASS、Cobaya。固定比值就是在两个参数之间加一个线性约束。
  • 径向加速度关系（McGaugh、Lelli 和 Schombert 2016）：g_obs = g_bar/(1 − exp(−√(g_bar/a₀)))。以及它是否随时间变化的问题（MUSE-DARK III；Alcock 2026）。a₀ 接近 cH₀/2π，这是 Milgrom 的一个旧观察。
  • 衰变为暗辐射的暗物质。 在程序 CLASS 中它称为 «dcdm»。Audren 及其同事 2014、Poulin 及其同事 2016、Alvi 及其同事 2022、Bucko、Giri 和 Schneider 2023 都有相关论述。
  • 其普通物质表现为暗物质的隐藏或镜像扇区：
  • Kolb、Seckel 和 Turner 1985；
  • 镜像物质（Berezhiani、Foot、Ciarcelluti）；
  • 多重折叠宇宙（Arkani-Hamed、Dimopoulos、Dvali 和 Kaloper）；
  • Randall-Sundrum 几何中的质量重标度；
  • 原子暗物质（Kaplan 及其同事 2010；Cyr-Racine 和 Sigurdson 2013）。

2. 比值 3√3

设置。

  • 模型。 平直 ΛCDM。一个质量为 0.06 eV 的中微子，N_ur = 2.0328。由此 N_eff ≈ 3.046，即中微子种类的有效数目。这样取是为了与程序 CAMB 比较。使用 Halofit，这是一种描述小尺度结构增长的配方。
  • 参数。 两种拟合都变动 ln(10¹⁰A_s)、n_s、100θ_s、ω_b、τ 和 A_planck。*自由*模型还变动 ω_cdm。而 D-B 模型施加 ω_cdm = 3√3·ω_b。
  • 数据。 两种组合：
  • PD = Planck 2018 lite TTTEEE + 低 ℓ TT + 低 ℓ EE + DESI DR2 BAO（13 个点）；
  • PDL = PD + Planck 2018 透镜重建。*透镜效应*是背景光被所遇到的物质弯曲。
  • 统计量。 Q = Σχ² + ((A_planck − 1)/0.0025)²。要使用的统计量在运行之前就写好了，带有标明日期的哈希值。它是 T_B = Q(D-B) − Q(free)：施加比值后分数变差多少。
  • 事先固定的区间。 T_B ≤ 4：相容。4 < T_B < 9：张力。T_B ≥ 9：在已声明模型中的否定结果。
  • 自由参照。 它是第 4 节中 Γ = 0 处细化的剖面点。这是一次带衰变暗物质的运行，但衰变被关闭。在 Q 上，它在 0.011 以内与 ΛCDM 等价。

  • 一项交叉核查。 早先用 CAMB 作的拟合（Planck + DESI DR2）给出 +0.04。
  • 局限。
  • Σm_ν 是固定的。

  • 这里没有任何东西推出 3√3。

3. RAR 尺度与红移

数据。

  • MUSE-DARK III 的四个分箱，由 Alcock（2026）列成表。它们是从 Ciocan 及其同事（2026）的图 3 *数字化*得到的。这意味着这些值是从图上逐点读出的。
  • 今天的锚点，来自 SPARC（一个近邻星系的集合）：1.20 ± 0.02 ± 0.24。振幅以 10⁻¹⁰ m s⁻² 为单位。
  • 误差棒的问题。 图上没有明确说明灰色误差棒的置信水平。资料来源对完整样本的拟合使用 95 % 区间，并对分箱采用相同的做法。所以两种读法都保留：c68（误差棒为 1σ）和 c95（误差棒为 95 %）。两者都不是根据拟合好坏选择的。

处理方式。 使用平直宇宙，Ω_m = 0.315，Ω_Λ = 0.685。χ² 把数字化的分箱当作彼此独立。这些分箱还有共同的建模和校准不确定度。这一近似不能完全代表它们。

如何读这张表。在 c68 读法下，常数的 χ² = 28.83：结果很差。哈勃率的 χ² = 5.48：结果很好。年龄倒数是 15.33。幂律是 1.16，但它有两个参数而不是一个。

它表明了什么。

  • 四个数字化的分箱支持增长的尺度。
  • 在三条单参数定律中，H(z) 给出最低的 χ²。ΔAICc 准则以 9.85 偏向 H 而不是年龄倒数定律。不过，这些模型不是*嵌套*的：一个不是另一个的特例。所以这个数不能换算成 σ。
  • 在 c95 读法下，H(z) 拟合得不好，尽管好于另外两条。*相对*偏好（哪一个更好）和*绝对*适当性（它是否真的好）是分开的。

它没有表明什么。

  • H 不是唯一的。 看过数据后选择的形式也一样好或更好：χ² 为 1.20 的 (1+z)^¾，或 2.39 的 1 + ln(1+z)。
  • H 不是幂律。 它的有效对数斜率在 z = 0 和 1 之间是 0.84，在两端的分箱之间是 1.11。
  • 重新标度。 把所有 a₀ 值乘以同一个数（在每个 z 上相等），会改变振幅但不改变演化。不过，恒星质量上的共同系统误差不一定恰好这样传播。
  • H 和年龄的形状相近。 振幅拟合之后，两条定律在 z = 0.5 和 2.5 之间只相差 0.062 dex。（dex 是对数标度上的十倍因子。）

存在张力的地方。

  • 在 z ≈ 2 处，A = 1.39 的 H 定律给出 a₀ = 4.21。Milgrom（2017）讨论了 Genzel 及其同事（2017）的星系。取这个 a₀，那些星系的暗物质比例将远高于测量值。这是一项示例性的核查。
  • 我们来看 KMOS3D 中的重子 Tully-Fisher 关系。在相同的圆周速度下，z ≈ 2.3 处的重子质量高于 z ≈ 0.9 处。按定律 V_f⁴ = G M_b a₀，增长的 a₀ 会产生相反的结果。这是定性的张力，不是对 a₀ 如何变化的直接测量。

与 MM 2.42 的联系。 MM 2.42 预注册了年龄倒数定律。在所述的误差假设下，这条定律对这些分箱的拟合比 H(z) 差。原来的预注册保持不变。对它的重新评估在该记录的 2.42.1 版中。这里 H(z) 作为唯象假设保留，有待未来检验。

4. 对均匀衰变的限制

模型。

  • 几乎所有冷暗物质都以恒定速率 Γ 衰变，也就是转变为暗辐射。在程序 CLASS 中，这是 dcdm 模型。出于技术原因，很小的一部分 ω_cdm = 10⁻⁵ 保持稳定。这是*同步规范*所需要的，同步规范是一种写方程的方式。
  • 从 t_i 到今天损失的共动比例是 F = 1 − exp[−Γ(t₀ − t_i)]。表中使用 t_i ≈ 0 和来自 CLASS 的 t₀。把 t_i 取在复合时期，不改变任何取整后的限制。
  • *寿命*是 Γ⁻¹。
  • 衰变产物产生引力。 所以这项分析并不限制这样一种消失：消失到一种按假设对共享引力场没有贡献的成分中。

结果。

  • 没有偏好恒定速率衰变的迹象。 在剖面中，最低值位于 Γ = 0。
  • 限制。 使用约定的阈值 ΔQ = 2.71，在点之间作单调三次插值。名义限制是：
  • PDL：Γ < 1.86，损失 < 2.6 %，寿命 > 525 Gyr（Gyr 表示十亿年）；
  • PD：Γ < 2.74，损失 < 3.8 %，寿命 > 357 Gyr。
  • 这些限制是临时的。 它们的*频率学*覆盖率没有校准：没有检查重复测量时区间有多少次会包含真值。而且剖面的数值收敛并不完全。在 10 个点中的 6 个，两个起点的差别超过了计划的 Q 容差 0.1。差别最大到 0.54。ΔQ 上 0.3 的偏移使限制移动约 0.3 个损失百分点（PDL）和 0.6 个（PD）。这是一种*敏感性*，不是误差棒。

验证。

  • ΛCDM 和衰变模型在 Γ = 0 时，Q 上的差别在 0.011 以内。
  • 线性计算与 halofit 的比较，在所测试的点上使 ΔQ(2.01) − ΔQ(0) 改变 −0.04。这是一项敏感性核查。它不能证明非线性配方对衰变模型有效。
  • CLASS 和 CAMB 在 ΛCDM 下，Q 相差约 0.35。ω_b、ω_c 和 H₀ 的偏移低于参照不确定度的 0.27 倍。

背景。 对寿命的名义限制在数值上大于已发表的限制。Alvi 及其同事（2022）得到 246 Gyr。Bucko、Giri 和 Schneider（2023）得到 288 Gyr。但数据、似然和统计方法都不同。因此无法说哪个约束更强。

5. 星系团

  • 这一约束涉及平均质量密度。 所施加的关系 ρ_c/ρ_b = 3√3 涉及整个宇宙的平均密度。仅凭它，既不能固定粒子数之比，也不能固定某个确切位置的密度之比。它也不给出每个*晕*单独的质量收支。晕是星系或星系团周围的暗物质云。
  • 重子比例。 不计大质量中微子。于是，重子在重子与冷暗物质总量中的比例是 1/(1 + 3√3) = 0.161。
  • X-COP。 它是一组研究得很充分的星系团。我们考察有恒星质量的五个系统的子样本（Eckert 及其同事 2022）。对其中四个系统，半径 R₅₀₀ 内的*流体静力学*重子比例从 0.141 到 0.165。流体静力学的意思是在假定热气体处于平衡的条件下计算。星系团 A2319 给出 0.185。它被标记为受*流体静力学偏差*强烈影响。这是一个粗略的比较。没有任何似然分析能把固定比值与 ΛCDM 的值 0.157 分开。
  • X-COP 还发现，星系的 RAR 不能描述星系团中的加速度关系。 重子总收支相符，并不能解决这个问题，这是另一个问题。
  • 仅有星系的晕是不够的。 在星系团中，气体比例是 f_gas = 0.12-0.14，恒星比例是 f_* = 0.015-0.025。于是，每单位恒星质量需要 33-58 单位的暗质量。由 RAR 对 100 kpc 内球形星系的估计只给出 4.9-16。这对 3×10¹¹ 和 3×10¹⁰ M☉ 之间的恒星质量成立。M☉ 是太阳的质量。所以把星系内部的贡献加起来是不够的。不过，这并不决定星系团的全部质量如何分布。

6. 假设和 MM 解读（诠释）

明确表述的假设。

  • 我们通过引力感受到冷暗物质。它的密度将代表隐藏扇区的物质，这种物质有自身的内部相互作用。这种物质不同于计入 ω_b 的可见重子。
  • 它的粒子质量、无量纲耦合和热历史仍未指定。
  • 另外，施加了 ρ_c/ρ_b = 3√3。
  • 用 MM 的话说，隐藏扇区是一个“镜像”，在自身的定律中是正常的，其常数相对于我们的常数来解读。哪些常数不同以及如何不同，在这条记录中保持一般性。

为什么它不能是完全相同的副本。

  • 假设引力以同样的方式作用于一切。那么，一个与我们的扇区温度相同的标准模型副本，与对辐射密度的限制不相容。
  • 在年轻的宇宙中，电子和正电子湮灭，也就是转变为光子：能量非常高的光，伽马射线。在这次电子-正电子湮灭之后，副本的光子和中微子会贡献 ΔN_eff ≈ 7.4。ΔN_eff 衡量相对于预期多出来的辐射。
  • 不过，相同的常数并不强迫温度相同。
  • 而且这一论证并不直接适用于下面所设定的辐射选择性耦合。
  • 碰撞、冷却和可能的盘形成需要单独建模。

第 9 节的例子。 它满足散射和残余电离这两个近似的屏蔽不等式。它并没有展示一个在宇宙学和天体物理学中可行的隐藏扇区。固定比值的 ΛCDM 核查检验的是这种参数化，而不是一般隐藏扇区的所有性质。

什么是共享的，什么不是。

  • 隐藏的光和隐藏扇区的内部力不作用于我们。
  • 这一解读还设定，隐藏辐射不作为我们宇宙膨胀的源。仅靠电磁上的分离并不意味着这一性质。这里没有实现这种选择性耦合的协变引力模型。

多少，在哪里。

  • 其数量受到平均比值 3√3 的约束。这个约束不说明它在空间中如何分布。
  • 在宇宙学拟合中，产生引力的成分由正常的稳定冷暗物质代表。这是一种*受限的* ΛCDM 拟合。它并不表明所提出的隐藏扇区能再现所需的动力学。对平均宇宙和它的*扰动*都没有表明。扰动是结构由之诞生的微小密度差异。

作为单一定域对象两种解读的 RAR。

  • 取一个球对称的重子质量。定义三个量：L = 2GM_b(<r)/(c²r)，S = r/R_H 和 a_MM = c²/(2R_H)。这里 M_b(<r) 是半径 r 内的重子质量。R_H 是*哈勃半径*：按哈勃定律，空间膨胀以光速带走星系的距离。
  • 按这些定义，L/S = g_bar/a_MM。
  • 经验 RAR 的自变量是 y = g_bar/a₀ = (a_MM/a₀)(L/S)。今天（z = 0），取所采用的 H₀ 和 SPARC 归一化，a_MM/a₀ = 2.73。
  • 总径向场中的额外比例是 exp(−√y)，也就是额外部分除以总场。
  • MM 把重子贡献和额外贡献诠释为同一对象的两种解读。这一诠释并不提供 RAR 的动力学机制。它也不去除宇宙学计算中假定的引力相互作用。对 RAR 的形状及其弥散的定量描述仍然开放。

密度的形式。

  • 取一个集中的球形重子质量，在其外部、RAR 的深区考察。主导的等效暗密度是 ρ_D ≃ √[a₀ ρ̄_b(<r)/(12πGr)] = κ√[ρ̄_b(<r) ρ_crit/S]。
  • 这里 ρ̄_b(<r) = 3M_b/(4πr³) 是半径 r 内的*平均*重子密度，不是 r 这一点的密度。
  • 如果 a₀ = a_MM，则 κ 恰好为 1/3，对测量的 a₀ 则为 0.20。
  • 这是在所述几何中对假定的 RAR 的一种渐近改写。它不是一条独立的密度定律。

一个有限的储库（有条件的）。

  • 假设我们再给一个孤立系统一个有限的暗储库 M_D,max。并假设把它的外场当作球形处理，重子质量 M_b 是集中的。
  • 那么，所采用的 RAR 在半径 r_es = √(GM_b/a₀)/ln(1 + 1/q_max) 处耗尽这个储库，其中 q_max = M_D,max/M_b。
  • 选择 M_D,max = 3√3·M_b,collected 需要另一条规则来说明哪些重子已被聚集。
  • 文本中的例子。 M_b = 6×10¹⁰ M☉ 和聚集的 1.6×10¹¹ M☉ 给出 r_es ≈ 120 kpc。在 300 kpc 处，速度将是 113 km s⁻¹ 而不是 177。这些数字假定储库是满的，并且 300 kpc 内只有 6×10¹⁰ M☉ 产生引力的重子。星系周围的其他重子会改变它们。
  • 与孤立星系弱透镜（Mistele 及其同事 2024）的比较将是可能的。但只有在储库被独立定义之后。

归一化。

  • 字面值 a_MM = cH₀/2 = 3.27×10⁻¹⁰ m s⁻² 是 SPARC 值的 2.73 倍。在这条记录中，a₀ 取自数据。
  • 可以对太阳附近的垂直场作一次*玩具式*的代数重新标度，也就是非常简化的重新标度。用经验归一化得到约 66 M☉ pc⁻²，用字面归一化得到 92。
  • 这不是自洽的银河系质量模型，也不用作定量检验。

融通。 支持这一解读的理由是，单一的诠释连接了通常被分开处理的问题。这一理由的强度，取决于有多少联系变成了定量的。今天四个中有两个是定量的。

8. 第 1 部分：MM 代数为隐藏扇区提供了什么

它从何而来。 这一部分取自一份早先未发表的草稿。程序模块在三个*测试库*上重新计算所述的量。

读这张表要用的两个词。 在 MM 代数中有*闭合模式*：模型中自我闭合的部分，就像网络的循环。*已声明的转译*是事先预注册的一种选择，说明如何把作者的一个想法写进公式。*对易子*衡量两个操作能否交换而不改变结果。如果它为零，一个就不干扰另一个。

陈述地位
一个已声明的转译保护闭合模式对易子残差处于数值精度（最大元素低于 4×10⁻¹⁵）；严格不变性是在所述定义下的代数主张（ESITO_12）
闭合模式与所有其他模式一样有重量单位分解（Σεᵢ = H）
对我们的光不可见必须是假定的每个闭合循环都在二阶上响应边连接（最小响应 0.0036-0.033）
一个完整的中性副本与重量相容；只保护一个副本的循环不成立ESITO_13
MM 2.29 的八态支架有两个质量相等的等价副本在支架中推出（ESITO_18）
一个不由光子携带的守恒公共数对携带该数非零总量的粒子对，禁止只衰变为光子
两种光的分离在已声明的定域算符类中，在不连通的光网络上得到；在 60 个随机图上核查；把通道分组是不够的（解读重新出现，最高达 25.5 %）；光子之间的一个小联系会在大距离上重新打开通信

如何读其中几行。

  • 闭合模式与所有其他模式一样有重量：在代数中，它们的权重像所有其他模式的权重一样进入总和（Σεᵢ = H）。把它们解读为真实的质量是一种诠释（见下文）。
  • 对我们的光不可见必须是假定的：仅靠代数不能保证这一点。如果连接到我们的网络，每个闭合循环都会在二阶上有少许响应。所以不可见性是一个假定。
  • 两种光的分离：如果两种光的网络不连通，它们就保持分离。把通道分组是不够的。而光子之间的一个小联系就足以在大距离上重新打开通信。

两点提醒。

  • 代数中相等的权重并不决定宇宙中有多少物质，也不能推出 3√3。把它们等同于真实的引力质量是一种诠释。
  • 被略去的内容。 早先草稿中定量的 1 TeV 候选者。它已被第 6 节的一般解读取代。

9. 一个算出的特例：单一的共同标度因子

映射。 试一个简单的情况：隐藏扇区的所有量都用单一因子 A 由我们的量得到。

  • 长度：ℓ_eff = ℓ'/A。时间：t_eff = t'/A。质量：m_eff = A m'。
  • 光速 c、普朗克（Planck）常数 ħ 和电磁常数 α 不变。
  • 定义 x = T'_γ/T_γ，即隐藏光子的温度与我们的光子温度之比。于是有效温度比是 Ax。
  • 由此得 ρ_eff = A⁴ρ' 和 (σ/m)_eff = A⁻³(σ/m)'。这里 ρ 是密度，σ/m 表示粒子每单位质量碰撞的多少。
  • 要在物理世界中应用这一映射，还需要关于共享几何和引力耦合的规则。

一个屏蔽区域。 一种示例性的屏蔽要求两个条件：

  • (σ/m)_eff ≤ 1 cm² g⁻¹，采用对冷中性氢的估计。它的意思是隐藏粒子很少碰撞。
  • 残余电离比例 x_e ≤ 0.01，采用近似的复合趋势。它的意思是剩下的等离子体非常少。

这些选择给出 A ≳ 850 和 x ≲ 520/A³。于是隐藏中微子和辐射可以忽略。这定义了一个*形式上的*屏蔽区域。它不是一个已被证明可行的参数窗口。

  • 与 Cyr-Racine 和 Sigurdson 估计的一致涉及的是趋势。他们的公式本身的不确定性可达十倍。
  • 有些东西没有计算：三体反应（在整个区域都重要；Gurian 及其同事 2022）、隐藏核合成、碰撞中的电离和集体等离子体效应（Lasenby 2020；DeRocco 和 Giffin 2025）。

结果如何。

  • 取 A = 1000 和 x ≈ 5.2×10⁻⁷，这是示例性的上边缘。在那里得到 η' ≈ 0.023：每个重子约 44 个光子。这个值在区域内会变化。
  • 在所考虑的例子中，具有我们的重子与光子之比的副本不能通过所采用的屏蔽。没有确立任何与观测相符的范围。
  • 隐藏质子读作 A·m_p：在 A = 1000 时为 0.94 TeV。这是一个示例性的换算。

这就是这条记录让相对常数保持一般性的原因。

10. 这项工作可能怎样被证明是错的

两个定量假设有事先声明的不成立阈值，用于未来数据的检验。在查看新结果之前，必须完成标明日期的分析规范。

  • 比值。 将使用 DESI 最终 BAO、Simons Observatory 和补充的 Planck 数据，按预注册的方式分析，Σm_ν 自由。如果它们给出 T_B ≥ 9，固定比值 3√3 在已声明的模型中不成立。
  • 这里没有预测这一数据组合的敏感性。
  • 我们作高斯（Gauss）近似。如果误差 σ(ω_c/ω_b) 约为 0.035 或 0.032，真实比值 5.30 或 5.10 名义上会达到 T_B = 9。真正的探测能力需要专门的预测。
  • a₀(z) 的形状。 如果预注册的全局形状检验给出 p < 0.0027，所指定的哈勃率定律在该检验中不成立。该检验对每个均匀样本使用一个自由归一化，对其所有分箱相同。并且使用已声明的系统误差处理。
  • 这些结果涉及指定的定量假设，并在其已声明的假定之内。
  • 其他结果会对指定的版本或假定构成挑战。
  • 衰变的证据会对带稳定冷暗物质的版本构成挑战。
  • 星系团并合的动力学可能对带无碰撞晕的指定实现构成挑战。
  • 微观物理计算可能排除隐藏扇区的指定实现。
  • 这些不是额外预注册的不成立阈值。

词汇表

  • a₀。 RAR 的加速度尺度：对近邻星系（SPARC）约为 1.20 × 10⁻¹⁰ m s⁻²。
  • BAO（重子声学振荡）。 星系分布中留下的一个典型距离，用作宇宙标尺。
  • 重子。 普通物质：主要是质子和中子。
  • 分箱（bin）。 一组距离相近的星系，用单一的值来概括。
  • CDM。 冷暗物质：它的粒子运动缓慢。
  • χ²（chi-squared）。 一个误差分数：它越低，模型就越贴近数据。
  • 星系团。 由引力维系在一起、浸没在非常热的气体中的一大群星系。
  • CMB（宇宙微波背景）。 宇宙最古老的光，由 Planck 卫星测量。
  • 融通（consilience）。 一个想法把通常被分开处理的不同事实放在一起。
  • 协变。 写成对每个观测者都成立的形式，这是相对论的要求。
  • 衰变。 一种粒子转变为其他粒子；这里指暗物质转变为暗辐射。
  • ΔN_eff。 年轻宇宙中相对于预期多出多少辐射。
  • dex。 对数标度上的十倍因子。
  • 拟合。 选择模型中的数字，使其尽可能贴近数据的计算。
  • 晕。 星系或星系团周围的暗物质云。
  • 隐藏扇区、“镜像”。 具有自身粒子和自身力的物质，与我们只共享引力。
  • ΛCDM。 标准宇宙学：恒定的暗能量（Λ）和冷暗物质（CDM）。
  • 透镜效应。 光被所遇到的质量弯曲。
  • 寿命。 粒子衰变之前的典型时间；这里是 Γ⁻¹。
  • 似然。 衡量模型贴近数据程度的量。分数 χ² 和 Q 的方向相反：它们越低，模型就越贴近数据。
  • 唯象。 因为能描述数据而选择，不是由理论推出的。
  • 前瞻性和回溯性。 前瞻性检验使用尚未到来的数据；回溯性检验使用已经存在的数据。
  • RAR（径向加速度关系）。 星系中观测到的加速度与仅由重子给出的加速度之间逐点的联系。
  • 红移（z）。 光在旅途中被拉长的程度：z 越大，我们看得越远，回看的时间也越早。
  • 预注册。 在看到将用来检验一个假设的数据之前写下并标明日期的假设。
  • 屏蔽。 这里指隐藏扇区碰撞很少、几乎不留等离子体的条件。
  • σ（sigma）。 一次测量的典型误差。
