始める前に：必要な言葉

暗黒物質。 銀河と銀河団は奇妙な動きをします。目に見える質量より多くの質量があるかのようです。宇宙全体の歴史もそれを必要とします。この余分な質量を*暗黒物質*と呼びます。暗黒物質は光を出さず、吸収もしません。私たちはその引力を通してしか気づきません。

バリオン。 通常の物質は*バリオン*でできています。星、ガス、惑星、そして私たち自身がこの物質でできています。バリオンの大部分は陽子と中性子です。

Ω と ω。 Ω_b は宇宙のどれだけの部分がバリオンでできているかを表します。Ω_c はどれだけの部分が冷たい暗黒物質でできているかを表します。小文字の ω_b と ω_c は同じ量に決まった数を掛けたものです。その数は今日の膨張に結びついています。比 ω_c/ω_b は Ω_c/Ω_b に等しくなります。

比 3√3。 この研究では、暗黒物質が宇宙の平均で通常の物質の 3√3 倍であることを課します。3√3 は約 5.196 です。

標準的な宇宙論、ΛCDM。 宇宙の歴史を表すモデルのうち、最もよく使われているものです。暗黒エネルギー（Λ）と冷たい暗黒物質（CDM、cold dark matter の略）を含みます。*冷たい*とは、その粒子がゆっくり動くことを意味します。

Planck と DESI。 Planck は人工衛星です。宇宙マイクロ波背景放射（CMB）、つまり宇宙で最も古い光を測定しました。この光は宇宙がとても若かったときに出発しました。DESI は銀河の大規模なサーベイです。バリオン音響振動（BAO）を測定します。これは銀河の分布に刻まれた典型的な距離です。宇宙の定規の役目をします。

赤方偏移 z。 遠い銀河の光は、宇宙が膨張するあいだに引き伸ばされます。このずれを z と書きます。z が大きいほど銀河は遠くにあり、より過去の姿が見えています。

RAR と a₀。 円盤銀河では、各点で二つの加速度を比べます。観測された*加速度 g_obs は星とガスの運動から得られます。バリオンだけの加速度 g_bar は、目に見える物質にニュートンの法則を当てはめて得られます。この二つのつながりを*動径加速度関係、RAR と呼びます。RAR にはただ一つのスケール a₀ があります。近傍の銀河では約 1.20 × 10⁻¹⁰ m s⁻² で、これがこの研究で使う SPARC の値です。

当てはめと尤度。 モデルをデータに*当てはめる*とは、モデルの数を選ぶことです。モデルができるだけデータによく従うように選びます。それがどれだけうまくいくかを測るのが*尤度*です。ここでは二つの誤差の点数、χ²（*カイ二乗*と読みます）と Q を使います。低いほど、モデルはデータによく従っています。

σ。 測定の典型的な誤差です。

登録。 仮説は、検証に使うデータを見る前に書き留めて日付をつけたとき、*登録された*と言います。

手短に

数学的物質性（MM）は著者の枠組みです。このレコードは、MM が示唆する暗黒物質の一つの読みが、いくつもの問題を同時に扱えるかを問います。数を与える部分は公開データと比較します。

各部分は別々の調査です。 四つあります。宇宙論的な比の当てはめ、RAR の進化の当てはめ、崩壊の解析、隠れたセクターの構成です。同時尤度も、すべてをつなぐ完全な力学モデルもありません。

明示した仮説（第 6 節）。

  • 私たちが重力を通して感じる冷たい暗黒物質の密度は、*隠れたセクター*の物質である、とします。この物質は固有の内部相互作用をもちます。ω_b に数えられる目に見えるバリオンとは別のものです。
  • MM の言葉では、それは「鏡」の通常の物質です。自らの法則の中では普通の物質であり、その定数は私たちの定数に対して読まれます。
  • その粒子の質量、無次元の結合定数、熱的な歴史は未指定のままです。*結合定数*は力の強さを表します。*無次元*とは、単位のない純粋な数であることを意味します。
  • それとは別に、宇宙論的な平均密度の比 ρ_c/ρ_b = 3√3 を課します。

イメージをつかむための、日常の例です。違う周波数に合わせた二台のラジオは互いに邪魔をしません。一方には他方が聞こえません。しかしどちらも同じテーブルの上に重さをかけています。ここでは、隠れたセクターと私たちのセクターは光を通しては互いを*感じ*ませんが、重力では引き合います。

本文がすぐに述べる三つの補足です。

  • もう一つの公準。 この解釈は、隠れた*放射*が私たちの宇宙膨張の源として働かないことも公準とします。これは二つの光が別々であることからは導かれません。これを実現する完全な*共変*モデルはありません。共変とは、相対性理論が求めるとおり、すべての観測者に対して成り立つ形で書かれていることを意味します。
  • 同一のコピーは除外されます。 重力がすべてに同じように働くとしましょう。すると、同じ温度の私たちのセクターのコピーは放射を加えすぎます。ΔN_eff ≈ 7.4 です。これは測定によって除外されます。隠れたセクターの衝突、冷却、円盤は別に研究しなければなりません。
  • 一つの例では足りません。 ただ一つのスケール因子を使った具体例は、二つの近似的な*スクリーニング*の不等式（散乱と残留電離）を満たします。これは、そのような隠れたセクターが本当に機能しうることを示してはいません。完全な計算はありません。

データとの整合性チェック。 プログラム python riproduci.py は、745 件のチェックの成功を報告します。代数的な恒等式、数値計算、アーカイブされた宇宙論の結果についての整合性チェックです。宇宙論的な尤度の最小化は、このプログラムでは繰り返しません。

  1. 比 Ω_c/Ω_b = 3√3 = 5.196。
  2. ニュートリノ質量の和 Σm_ν = 0.06 eV の平坦な ΛCDM を使います。
  3. ω_cdm = 3√3·ω_b を課します。データは Planck 2018（lite TTTEEE、low-ℓ の TT と EE）と DESI DR2 BAO です。点数 Q でのコストは T_B = 0.17 です。Planck のレンズ再構成を加えると 0.23 です。計算はプログラム CLASS と Cobaya で行います。
  4. これほど小さなコストは、課した比がデータと一致していることを意味します。
  5. 比を自由にすると、当てはめは ω_c/ω_b = 5.22 と 5.21 を与えます。
  6. これは*遡及的*な整合性の評価です。すでに存在していたデータを使っています。独立した*前向き*テスト、つまりこれから得られるデータでのテストではありません。特定の将来のデータでの前向きテストは登録されています。
  7. RAR の加速度スケールは、MUSE-DARK III の四つのビンで赤方偏移とともに増えます。 *ビン*とは、距離が同程度の銀河のグループです。
  8. 三つの法則（定数、ハッブル率、宇宙年齢の逆数）のうち、H(z) が最も低い χ² を与えます。
  9. この当てはめが絶対的にどれだけ良いかは、グラフの誤差棒の読み方に強く依存します。誤差棒が 1σ なら χ² = 5.48 です。95 % なら χ² = 21.04 です。どちらの場合も自由度は三つです。
  10. ほかの単純な形でも同じくらい良くなります。z ≈ 2 の銀河はこの法則と緊張関係にあります。
  11. H(z) は*現象論的*な仮説（データを記述するから選んだもの）として保持し、将来のデータのために登録します。
  12. （ほぼ）すべての暗黒物質が一定の割合で暗黒放射に変わる崩壊への選好はありません。計算したプロファイルでは、最も低い値は Γ = 0、つまり崩壊なしのところにあります。慣例の閾値は ΔQ = 2.71 です。そこでの*共動*の損失に対する名目上の暫定的な限界は、レンズ再構成ありで約 2.6 % です。なしでは 3.8 % です。*共動*とは、宇宙とともに大きくなる体積の中で数えることを意味します。このため、膨張による単なる希釈は損失に数えません。
  13. 銀河団。 固定した比は、バリオンと冷たい暗黒物質の和に対して 0.161 のバリオン割合を与えます。これは大質量銀河団のバリオン収支とおおまかに一致します。ただし銀河の RAR は銀河団（X-COP）を記述しません。この問題は残ります。

この読みがつなごうとする問題（第 7 節）。四つあります。第一は暗黒物質とバリオンの比です。第二は a₀ の宇宙論的なスケールです。第三は直接検出の信号がないことです。第四は暗黒物質のふるまいです。宇宙論では*冷たい*ものとしてふるまい、銀河では RAR に従います。これらのつながりの位置づけはさまざまです。課した数値的な仮説、現象論的な当てはめ、定性的な仮定です。ほかの研究プログラムも、これらの問題の組み合わせを扱っています。この読みの論拠は、この*コンシリエンス*、つまり一つの考えが多くをまとめていることにあります。そして、その論拠が強まるのは、より多くのつながりが定量的になるときだけです。

この研究はどのようにして誤りとなりうるか（第 10 節）。二つの定量的な仮説があり、将来のテストのために不成立の閾値をあらかじめ明示しています。

未解決のこと。

  • 隠れたセクターの力学：熱的な歴史、プラズマ、衝突。
  • 弾丸銀河団の詳細。衝突した銀河団の組です。
  • 理論から得られる a₀。MM の文字どおりの値 cH₀/2 は測定値の 2.73 倍です。
  • RAR の導出。
  • 隠れた放射が重力を及ぼさない共変モデル。

1. 物理学者に見覚えのあるもの

これらの部分は、すでに知られている道具と考えを使っています。

  • 比 ω_c/ω_b を固定した ΛCDM の当てはめ。 標準的な尤度とプログラムを使います。Planck 2018、DESI DR2、CLASS、Cobaya です。比を固定することは、二つのパラメータのあいだのただ一つの線形の制約です。
  • 動径加速度関係（McGaugh、Lelli、Schombert 2016）：g_obs = g_bar/(1 − exp(−√(g_bar/a₀)))。そしてそれが時間とともに変わるかという問い（MUSE-DARK III、Alcock 2026）。a₀ が cH₀/2π に近いことは、Milgrom による古い指摘です。
  • 暗黒放射に崩壊する暗黒物質。 プログラム CLASS では «dcdm» と呼ばれています。Audren ら 2014、Poulin ら 2016、Alvi ら 2022、Bucko、Giri、Schneider 2023 がこれについて書いています。
  • 通常の物質が暗黒物質として現れる、隠れたセクターや鏡セクター：
  • Kolb、Seckel、Turner 1985；
  • 鏡物質（Berezhiani、Foot、Ciarcelluti）；
  • manyfold universe（Arkani-Hamed、Dimopoulos、Dvali、Kaloper）；
  • Randall-Sundrum 幾何における質量の再スケーリング；
  • 原子状暗黒物質（Kaplan ら 2010；Cyr-Racine と Sigurdson 2013）。

2. 比 3√3

設定。

  • モデル。 平坦な ΛCDM。質量 0.06 eV のニュートリノ一種類と N_ur = 2.0328。これにより、ニュートリノの実効的な種類の数は N_eff ≈ 3.046 となります。CAMB プログラムとの比較のためにこのままにしています。小さなスケールでの構造の成長のレシピである Halofit を使います。
  • パラメータ。 どちらの当てはめも ln(10¹⁰A_s)、n_s、100θ_s、ω_b、τ、A_planck を動かします。*自由な*モデルは ω_cdm も動かします。D-B モデルは代わりに ω_cdm = 3√3·ω_b を課します。
  • データ。 二つの組み合わせです。
  • PD = Planck 2018 lite TTTEEE + low-ℓ TT + low-ℓ EE + DESI DR2 BAO（13 点）；
  • PDL = PD + Planck 2018 のレンズ再構成。*レンズ*とは、背景の光が出会う物質によって曲げられることです。
  • 統計量。 Q = Σχ² + ((A_planck − 1)/0.0025)²。使う統計量は、実行の前に日付つきのハッシュとともに書き留めました。T_B = Q(D-B) − Q(free) です。比を課すと点数がどれだけ悪くなるかを表します。
  • あらかじめ定めたバンド。 T_B ≤ 4：整合。4 < T_B < 9：緊張。T_B ≥ 9：明示したモデルでの否定的な結果。
  • 自由な参照。 第 4 節の、精密化したプロファイルの点 Γ = 0 です。崩壊する暗黒物質で実行しますが、崩壊は切ってあります。Q で 0.011 以内で ΛCDM と等価です。

注意点。

  • 値は見つかった最小点からの数値的な推定であり、大域的な最小点として保証されたものではありません。 最小点を探すプログラムは、すべての中で最も低いのではない最小点で止まることがあります。
  • PD の制約つき当てはめの二つの開始点は Q で 0.30 異なり、これは報告したペナルティより大きな値です。
  • ほかの実行（corse_6/：L0_PDL；Γ = 0 で終わった DD_PD）で見つかった最も低い自由な ΛCDM の最小点は、T_B = 0.26 と 0.24 を与えます。
  • コストの出どころ。 Planck の high-ℓ の部分（背景放射の細かな部分）は 0.9-1.5 悪くなります。一方 DESI は 0.5-0.7 良くなります。
  • クロスチェック。 CAMB による以前の当てはめ（Planck + DESI DR2）は +0.04 を与えました。
  • 限界。
  • Σm_ν は固定しました。
  • 自由な比の不確かさはここでは定量化していません。
  • ここでは何も 3√3 を導いていません。
  • 将来のデータのための登録はパッケージの中にあります（*研究の進め方*の節）。

3. RAR のスケールと赤方偏移

データ。

  • Alcock（2026）が表にした MUSE-DARK III の四つのビンです。Ciocan ら（2026）の図 3 から*デジタル化*されました。つまり、値はグラフから一点ずつ読み取られたものです。
  • SPARC（近傍の銀河の集まり）による今日のアンカー点：1.20 ± 0.02 ± 0.24。振幅の単位は 10⁻¹⁰ m s⁻² です。
  • 誤差棒の問題。 このグラフは、灰色の誤差棒の信頼水準を明示していません。出典は全サンプルの当てはめに 95 % の区間を使い、同じ手順をビンに適用しています。そこで両方の読みを保持します。c68（誤差棒を 1σ とする）と c95（誤差棒を 95 % とする）です。どちらも、当てはまりの良さをもとに選んではいません。

扱い。 Ω_m = 0.315、Ω_Λ = 0.685 の平坦な宇宙を使います。χ² は、デジタル化されたビンを独立したものとして扱います。ビンには、モデル化と較正の共通の不確かさもあります。この近似はそれらを完全には表していません。

示していること。

  • デジタル化された四つのビンは、増えていくスケールを優位とします。
  • パラメータが一つの三つの法則の中では、H(z) が最も低い χ² を与えます。基準 ΔAICc は、年齢の逆数の法則に対して H を優位とする 9.85 です。ただし、これらのモデルは*入れ子*ではありません。一方は他方の特殊な場合ではありません。このため、この数は σ に換算できません。
  • c95 の読みでは、H(z) はほかの二つより良いものの、当てはまりは良くありません。*相対的*な選好（どちらがより良いか）と*絶対的*な適切さ（本当に良いかどうか）は分けて考えます。

示していないこと。

  • H だけではありません。 データを見た後で選んだ形でも同じくらいかそれ以上に良くなります。χ² 1.20 の (1+z)^¾、2.39 の 1 + ln(1+z) です。
  • H はべき法則ではありません。 実効的な対数の傾きは、z = 0 から 1 のあいだで 0.84、両端のビンのあいだで 1.11 です。
  • 再スケーリング。 a₀ のすべての値にどの z でも等しい同じ数を掛けても、振幅は変わりますが進化は変わりません。ただし、星の質量の共通の系統誤差が、必ずしも正確にこのように伝わるわけではありません。
  • H と年齢の形は近いものです。 振幅を当てはめると、二つの法則は z = 0.5 と 2.5 のあいだで 0.062 dex しか違いません。（一 dex は対数目盛での十倍の因子です。）

緊張があるところ。

  • z ≈ 2 では、A = 1.39 の H の法則は a₀ = 4.21 を与えます。Milgrom（2017）は Genzel ら（2017）の銀河を論じました。この a₀ では、それらの銀河の暗黒物質の割合は測定値をかなり上回ります。例示的なチェックです。
  • KMOS3D のバリオンのタリー–フィッシャー関係を見ます。同じ円運動の速度では、バリオン質量は z ≈ 0.9 より z ≈ 2.3 で大きくなります。法則 V_f⁴ = G M_b a₀ では、増えていく a₀ は逆の効果をもたらします。これは定性的な緊張であり、a₀ の変わり方を直接測ったものではありません。

MM 2.42 とのつながり。 MM 2.42 は年齢の逆数の法則を登録していました。誤差について述べた仮定のもとで、この法則はこれらのビンに H(z) より悪く当てはまります。もとの登録は変わりません。その再評価は、そのレコードのバージョン 2.42.1 にあります。ここでは H(z) を、将来検証すべき現象論的な仮説として保持します。

4. 一様な崩壊への制限

モデル。

  • ほぼすべての冷たい暗黒物質が、一定の割合 Γ で暗黒放射に*崩壊*します。つまり変わります。プログラム CLASS では dcdm モデルです。ごく一部 ω_cdm = 10⁻⁵ は、技術的な理由で安定なまま残ります。方程式の書き方の一つである*同期ゲージ*のために必要です。
  • t_i から今日までに失われる共動の割合は F = 1 − exp[−Γ(t₀ − t_i)] です。表では t_i ≈ 0 と CLASS の t₀ を使います。t_i を再結合の時点に取っても、丸めた限界は一つも変わりません。
  • *寿命*は Γ⁻¹ です。
  • 崩壊生成物は重力を及ぼします。 このため、この解析は、仮説によって共有の重力場に寄与しない成分への消失を制限するものではありません。

5. 銀河団

  • 制約は平均質量密度に関するものです。 課した関係 ρ_c/ρ_b = 3√3 は、宇宙全体の平均密度に関するものです。それだけでは粒子数の比を定めません。特定の場所の密度の比も定めません。そして*ハロー*ごとの別々の質量収支も与えません。ハローとは、銀河や銀河団を取り巻く暗黒物質の雲です。
  • バリオン割合。 質量をもつニュートリノは数えません。すると、バリオンと冷たい暗黒物質の合計に対するバリオンの割合は 1/(1 + 3√3) = 0.161 です。
  • X-COP。 よく研究された銀河団のグループです。星の質量がわかっている五つの系の部分サンプル（Eckert ら 2022）を見ます。四つの系では、半径 R₅₀₀ 内の*静水圧*バリオン割合は 0.141 から 0.165 です。静水圧とは、高温のガスが平衡にあると仮定して計算したことを意味します。銀河団 A2319 は 0.185 を与えます。これは*静水圧バイアス*の影響を強く受けているとされています。おおまかな比較です。固定した比を ΛCDM の値 0.157 と区別する尤度解析はありません。
  • X-COP は、銀河の RAR が銀河団の加速度関係を記述しないことも見いだしています。 バリオンの総収支が合うことは、別の問題であるこの問題を解決しません。
  • 銀河のハローだけでは足りません。 銀河団では、ガスの割合は f_gas = 0.12-0.14、星の割合は f_* = 0.015-0.025 です。すると星の質量一単位あたり 33-58 単位の暗黒質量が必要です。球状の銀河の 100 kpc 以内についての RAR からの見積もりは 4.9-16 しか与えません。これは 3×10¹¹ から 3×10¹⁰ M☉ の星の質量で成り立ちます。M☉ は太陽の質量です。このため、銀河の内側の部分の寄与を足し合わせるだけでは足りません。ただし、これは銀河団の全質量がどう分布しているかを決めるものではありません。

6. 仮説と MM の読み（解釈）

明示した仮説。

  • 私たちは冷たい暗黒物質を重力を通して感じます。その密度は、固有の内部相互作用をもつ隠れたセクターの物質を表す、とします。この物質は ω_b に数えられる目に見えるバリオンとは別のものです。
  • その粒子の質量、無次元の結合定数、熱的な歴史は未指定のままです。
  • それとは別に ρ_c/ρ_b = 3√3 を課します。
  • MM の言葉では、隠れたセクターは「鏡」です。自らの法則の中では普通のものであり、その定数は私たちの定数に対して読まれます。どの定数がどのように違うかは、このレコードでは一般的なままにしています。

なぜ同一のコピーではありえないのか。

  • 重力がすべてに同じように働くとしましょう。すると、私たちのセクターと同じ温度の標準模型のコピーは、放射密度の限界と両立しません。
  • 若い宇宙では、電子と陽電子が対消滅しました。つまり光子、非常に高いエネルギーの光であるガンマ線に変わりました。この電子–陽電子対消滅の後、コピーの光子とニュートリノは ΔN_eff ≈ 7.4 の寄与をします。ΔN_eff は、期待される放射に比べて余分な放射を測ります。
  • ただし、同一の定数が同一の温度を強いるわけではありません。
  • また、この議論は、後で公準とする放射の選択的な結合には直接当てはまりません。
  • 衝突、冷却、円盤の形成の可能性については、別のモデル化が必要です。

第 9 節の例。 散乱と残留電離についての二つの近似的なスクリーニングの不等式を満たします。宇宙論と天体物理学で機能する隠れたセクターを示すものではありません。比を固定した ΛCDM のチェックが検証するのはそのパラメータ化であり、一般的な隠れたセクターのすべての性質ではありません。

共有されるものと共有されないもの。

  • 隠れた光と隠れたセクターの内部の力は、私たちには作用しません。
  • この読みは、隠れた放射が私たちの宇宙膨張の源として働かないことも公準とします。電磁気的な分離だけでは、この性質は導かれません。この選択的な結合を実現する共変な重力モデルは、ここにはありません。

どれだけ、どこに。

  • 量は平均の比 3√3 によって制約されます。この制約は、それが空間にどう分布するかを述べていません。
  • 宇宙論的な当てはめでは、重力を及ぼす成分を、通常の安定な冷たい暗黒物質で表します。これは*制限された* ΛCDM の当てはめです。提案する隠れたセクターが必要な力学を再現することを示すものではありません。平均的な宇宙についても、その*摂動*についても示していません。摂動とは、構造が生まれるもとになる密度の小さな違いです。

一つの局所的な対象の二つの読みとしての RAR。

  • 球対称のバリオン質量を考えます。三つの量を定義します。L = 2GM_b(<r)/(c²r)、S = r/R_H、a_MM = c²/(2R_H) です。ここで M_b(<r) は半径 r の内側のバリオン質量です。R_H は*ハッブル半径*、つまりハッブルの法則によって空間の膨張が銀河を光の速さで遠ざける距離です。
  • これらの定義で L/S = g_bar/a_MM となります。
  • 経験的な RAR の引数は y = g_bar/a₀ = (a_MM/a₀)(L/S) です。今日（z = 0）、採用した H₀ と SPARC の規格化では a_MM/a₀ = 2.73 です。
  • 全動径場に占める余分な割合は exp(−√y) です。つまり余分な部分を全場で割ったものです。
  • MM は、バリオンの寄与と余分な寄与を、同じ対象の二つの読みと解釈します。この解釈は RAR の力学的な機構を与えるものではありません。また、宇宙論の計算で仮定している重力相互作用を取り除くものでもありません。RAR の形とその散らばりの定量的な記述は未解決のままです。

密度の形。

  • 集中した球状のバリオン質量をとり、その外側を RAR の深い領域で見ます。主要な等価暗黒密度は ρ_D ≃ √[a₀ ρ̄_b(<r)/(12πGr)] = κ√[ρ̄_b(<r) ρ_crit/S] です。
  • ここで ρ̄_b(<r) = 3M_b/(4πr³) は半径 r の内側の*平均*バリオン密度であり、点 r での密度ではありません。
  • a₀ = a_MM なら κ = 1/3 ちょうどで、測定された a₀ では 0.20 です。
  • これは、述べた幾何における仮定した RAR の漸近的な書き換えです。独立した密度の法則ではありません。

有限のリザーバー（条件つき）。

  • 孤立した系に、さらに有限の暗黒のリザーバー M_D,max を与えるとしましょう。そして、その外側の場を、集中したバリオン質量 M_b をもつ球状のものとして扱うとしましょう。
  • すると、採用した RAR は半径 r_es = √(GM_b/a₀)/ln(1 + 1/q_max) でそのリザーバーを使い果たします。ここで q_max = M_D,max/M_b です。
  • M_D,max = 3√3·M_b,collected と選ぶには、どのバリオンが集められたかを述べる別の規則が必要です。
  • 本文の例。 M_b = 6×10¹⁰ M☉ と、集められた 1.6×10¹¹ M☉ は r_es ≈ 120 kpc を与えます。300 kpc では、速度は 177 ではなく 113 km s⁻¹ になります。これらの数は、リザーバーが満杯で、300 kpc 以内の重力を及ぼすバリオンが 6×10¹⁰ M☉ だけであることを仮定しています。銀河のまわりのほかのバリオンはこれらの数を変えます。
  • 孤立銀河の弱い重力レンズ（Mistele ら 2024）との比較は可能になるでしょう。ただし、リザーバーが独立に定義されてからのことです。

規格化。

  • 文字どおりの値 a_MM = cH₀/2 = 3.27×10⁻¹⁰ m s⁻² は、SPARC の値の 2.73 倍です。このレコードでは a₀ はデータから取っています。
  • 太陽近傍の鉛直方向の場について、*トイ*の、つまり非常に単純化した代数的な再スケーリングを行うことができます。経験的な規格化では約 66 M☉ pc⁻²、文字どおりの規格化では 92 を与えます。
  • これは銀河系の自己整合的な質量モデルではなく、定量的なテストとしては使いません。

9. 計算した特殊な場合：ただ一つの共通のスケール因子

対応づけ。 単純な場合を試します。隠れたセクターのすべての量を、ただ一つの因子 A で私たちの量から得る場合です。

  • 長さ：ℓ_eff = ℓ'/A。時間：t_eff = t'/A。質量：m_eff = A m'。
  • 光の速さ c、プランク定数 ħ、電磁気の定数 α は変わりません。
  • x = T'_γ/T_γ を、隠れた光子の温度と私たちの光子の温度の比と定義します。すると実効的な温度の比は Ax です。
  • ここから ρ_eff = A⁴ρ' と (σ/m)_eff = A⁻³(σ/m)' が得られます。ここで ρ は密度、σ/m は単位質量あたり粒子がどれだけ衝突するかを表します。
  • この対応づけを物理的な世界に適用するには、共有の幾何と重力の結合についての規則も必要です。

スクリーニングの領域。 例示的なスクリーニングは二つの条件を求めます。

  • (σ/m)_eff ≤ 1 cm² g⁻¹：冷たい中性水素についての見積もりを用います。隠れた粒子があまり衝突しないことを意味します。
  • 残留電離割合 x_e ≤ 0.01：再結合の近似的な傾向を用います。プラズマがごくわずかしか残らないことを意味します。

これらの選択は A ≳ 850 と x ≲ 520/A³ を与えます。すると、隠れたニュートリノと放射は無視できます。これは*形式的な*スクリーニングの領域を定めます。成立しうると示されたパラメータの窓ではありません。

  • Cyr-Racine と Sigurdson の見積もりとの一致は傾向についてのものです。彼らの式自体、最大で十倍の不確かさがあります。
  • 計算していないものがあります。三体反応（領域全体で重要；Gurian ら 2022）、隠れた元素合成、衝突中の電離、集団的なプラズマ効果（Lasenby 2020；DeRocco と Giffin 2025）です。

得られること。

  • 例示的な上端である A = 1000、x ≈ 5.2×10⁻⁷ をとります。そこでは η' ≈ 0.023、つまりバリオンあたり約 44 個の光子です。この値は領域の中で変わります。
