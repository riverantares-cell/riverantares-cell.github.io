数学的物質性（MM）シリーズのバージョン 2.58、2026 年 10 月。 これは MM 2.54（DOI 10.5281/zenodo.23418156）の続きです。そこでは暗黒物質と通常の物質の比 Ω_c/Ω_b = 3√3 が登録されました。使ったデータには宇宙マイクロ波背景放射（CMB）が含まれていました。この研究は次に、広連星についての MM 2.56（DOI 10.5281/zenodo.23506401）の連鎖に入力を与えます。

始める前に：必要な言葉

宇宙の最初の数分。 最初の数分間、宇宙は極めて高温でした。陽子と中性子が結びつき、最初の軽い原子核をつくりました。この過程を*ビッグバン元素合成*、略して BBN と呼びます。

  • 重水素（D）は、原子核の中性子が一つ多い水素です。
  • ヘリウム 4（⁴He）は、陽子二つと中性子二つをもちます。
  • リチウム（Li）はさらに重い原子核で、ごくわずかな量だけつくられました。

重水素がどれだけできたかは、通常の物質がどれだけあったかに依存します。このため、今日測定される重水素は、宇宙に通常の物質がどれだけあるかを教えてくれます。

ω_b と ω_c。 ω_b は宇宙に通常の物質がどれだけあるかを測ります。通常の物質はバリオンでできています。ω_c は冷たい暗黒物質がどれだけあるかを測ります。Ω_c/Ω_b はそれらの比です。

比 3√3。 この研究では、暗黒物質が通常の物質の 3√3 倍であることを課します。式では ω_c = 3√3·ω_b = 5.196·ω_b です。標準的な宇宙論である ΛCDM では、ω_c はこれと違って自由です。

BAO と音響地平線。 若い宇宙では、物質は音波が通り抜ける気体のように振動していました。これらの波は、銀河の分布に典型的な距離を残しました。バリオン音響振動（BAO）です。通常の物質が光から離れた*ドラッグ期*までに波が進んだ距離を、音響地平線 r_d と呼びます。宇宙の定規の役目をします。DESI は、これらの距離を測定する銀河の大規模なサーベイです。

ハッブル定数 H₀。 今日、宇宙がどれだけの速さで膨張しているかを表します。単位は km s⁻¹ Mpc⁻¹ で、距離一メガパーセクあたりのキロメートル毎秒です。測定は互いに一致していません。背景放射（Planck）からは 67.36 が得られます。近くの星（Riess ら）からは 73.04 が得られます。

a₀。 *動径加速度関係*における銀河の加速度スケールです。この関係は、銀河で観測される加速度を、目に見える物質だけの加速度と結びつけます。ここでは a₀ = cH₀/6 と読みます。c は光の速さです。

χ²、σ、二つの z。 χ²（*カイ二乗*と読みます）は誤差の点数です。低いほど、モデルはデータによく従っています。Δχ² は二つのモデルの差です。σ は典型的な誤差です。注意してください。この本文では、文字 z には二つの意味があります。

  • *赤方偏移*としての z は、銀河がどれだけ遠いかを表します。z が大きいほど、より遠く、より過去を見ていることになります。
  • *z スコア*としての z は、ある値が別の値から σ のいくつ分離れているかを表します。たとえば z = −0.38 は、典型的な誤差の 0.38 倍だけ下という意味です。

辞書。 ここでは BBN を*辞書*として使います。実験室で測定された数を宇宙論的な量に翻訳します。実験室の数とは、核反応、中性子の寿命などです。

事前分布。 計算に最初に与える情報です。たとえば、ω_b はある誤差をもって約 0.02218 である、といったものです。

手短に

五段階の連鎖。

  • 標準的な元素合成は、測定された重水素（および主たる辞書ではヘリウム）とともに、ω_b を制約します。
  • ω_c = 3√3·ω_b を課します。すると、DESI DR2 の 13 の BAO 距離を、平坦な ΛCDM モデルより宇宙論的パラメータが一つ少ない状態で読むことになります。
  • フィットの代償は Δχ² = 0.09 だけです。H₀ = 68.52 ± 0.59 km s⁻¹ Mpc⁻¹ を与えます。これは BAO + BBN からすでに知られている値です。
  • すると a₀ = cH₀/6 = 1.110·10⁻¹⁰ m s⁻² です。近くの銀河の集成である SPARC の値から −0.4σ のところにあります。
  • 逆向きに： BAO だけで、3√3 とともに、D/H = (2.40 ± 0.31)·10⁻⁵ を予測します。測定値は 2.51 です。これは予測的なチェックですが、比のテストから独立してはいません。

DR2 のあとの最初の DESI リリースについてのテストを、そのデータが出る前に、ここで登録しています。

何であり、何でないか。 これは一つの読み、データを知ったうえで選ばれた 3√3 の整合性チェックです。導出ではありません。その結果が関わるのはその読みであり、MM の枠組みではありません。

1. 連鎖

  1. 重水素 → ω_b。 標準的な元素合成（BBN）が辞書の役目をします。実験室のデータの関数です。まず核反応の*断面積*、つまり二つの原子核がどれだけ反応しやすいかです。その中には LUNA が測定した反応 d(p,γ)³He があります。次に中性子の寿命、G、N_eff、T_γ です。主たる辞書は D と ⁴He を使います。重水素だけの辞書（D-4）はチェックとして使います。
  2. × 3√3 → ω_c。 ω_c = 3√3·ω_b = 5.196·ω_b。ΛCDM では ω_c は自由なはずです。
  3. → 音響地平線 r_d と H₀。 ω_b と ω_c が固定されると、r_d が固定されます（プログラム CLASS が計算します）。すると DESI DR2 の BAO は、ただ一つの宇宙論的パラメータ H₀ を自由なまま残します。ω_b は、BBN の事前分布で制約された、フィットされるパラメータのままです。
  4. → a₀ = cH₀/6 → 銀河（SPARC）と広連星（MM 2.56 の連鎖）。

CMB のデータはフィットに入っていません。 レベル 2 の一つのチェック（T4、第 5 節）だけが、あとから結果を Planck と比較します。

いくつかの行の読み方です。

  • D/H は、水素の原子核一個あたりの重水素の原子核の数です。10⁵ D/H = 2.527 は、水素の原子核十万個につき重水素の原子核が 2.527 個あるという意味です。星の少ない遠方のガス雲の光の中で測定されます（12 系）。
  • Y_p は、最初の数分でつくられたヘリウム 4 の質量割合で、約 0.245 です。
  • 中性子の寿命は二つの方法で測定されます。*ボトル*法では、中性子を容器に閉じ込めて、いくつ残っているかを数えます。*ビーム*法では、飛んでいる中性子のビームを観測します。二つの方法は異なる値を与えます。たとえば、ボトルでは 878.3 s、ビームでは 887.7 s です。
  • 比較のための H₀： Planck は 67.36、Riess らは 73.04、Breuval らは 73.17 を与えます。

3. 方法（レベル 1）

モデル。

  • 平坦な ΛCDM で、N_eff = 3.044 です。質量 0.06 eV のニュートリノが一つあります。背景放射の温度は T_γ = 2.7255 K です。
  • 音響地平線 r_d は、プログラム CLASS 3.4.1 が (ω_b, ω_c) の値のグリッド上で計算します。グリッドの点のあいだは内挿します。距離は独自の積分プログラムで計算します。

二つのフィット。 点数は χ² = χ²_BAO + ((ω_b − ω_b,D)/σ_D)² で、全部で 14 項です。

  • ΛCDM： ω_b、ω_c、h が自由（自由度 11）。
  • MM： ω_c = 3√3·ω_b で、ω_b と h が自由（自由度 12）。

事前分布。

  • 平坦：h ∈ [0.55, 0.85]、ω_c ∈ [0.085, 0.155]。
  • ω_b ∈ [0.0196, 0.0249]。r_d のグリッドの端で、D-1 の中心から少なくとも 4.7σ 離れています。
  • ありうる値の分布は、4 本のチェーンをもつメトロポリス・サンプラーから得ています。収束のチェックは良好です（分割したチェーンでも R̂ ≤ 1.0007、ESS ≥ 11,800）。

辞書。すべて前もって固定されています。

  • D-1、主たるもの。
  • D-2、Cooke の D/H を使った同じもの。
  • D-3、PDG 2026。
  • D-4、重水素のみ：PRyMordial の表を通した PDG 2026 の D/H、ガウス尤度の ln V 項つき。
  • D-5、LUNA 以前の Cooke 2018（歴史的なもの）。

検証。すべて通りました。

  • r_d の内挿は CLASS と 0.00003 Mpc 以内で、距離は 1.3·10⁻⁶ 以内で一致します。
  • BAO だけで Ω_m = 0.2975 ± 0.0087、h·r_d = 101.53 ± 0.74 を与えます。DESI は、その式 17 で 0.2975 ± 0.0086 と 101.54 ± 0.73 を与えています。
  • ΛCDM + BBN は H₀ = 68.55 ± 0.60 を与えます。DESI は、その式 19 で 68.51 ± 0.58 を与えています。

読み方です。

  • 比の代償。 比 3√3 を入れても、点数は 10.282 から 10.369 に上がるだけです。Δχ² = 0.087 です。この値の登録済みのゾーンは *1σ 以内で整合*です。パラメータの少ないモデルに報いる ΔAIC と ΔBIC の基準もあります。これらは負で、比を固定したモデルをわずかに優位としています。
  • 自由にした比。 ΛCDM では 5.282 ± 0.228 となり、3√3 から +0.38σ です。
  • H₀。 比を固定すると 68.52 ± 0.59 となります。ΛCDM では 68.56 ± 0.60 で、ほとんど同じです。
  • a₀。 (1.110 ± 0.010)·10⁻¹⁰ m s⁻² となります。SPARC と比べて z = −0.38 です。H₀ = 73.04 なら z = −0.07 となるはずです。
  • ヘリウム。 Y_p は 0.2468 となり、測定から +0.6σ です。D-1 の辞書では独立したチェックではありません。D-1 がすでにヘリウムを使っているからです。
  • 重水素のみ（D-4）。 Δχ² = 0.023、H₀ = 68.72 ± 0.60、Y_p = 0.2469。ここではヘリウムは独立したチェックになり、うまく合っています（+0.6σ）。
  • 感度。 辞書を（D-1 から D-5 まで）変えると、Δχ² は 0.02 から 0.42 まで、H₀ は 67.99 から 68.72 まで変わります。

逆向きの読み。

  • ΛCDM では、BAO だけでは ω_b を固定できません。一方、ω_c = 3√3·ω_b があれば固定できます。
  • 結果は ω_b = 0.02316 ± 0.00178、H₀ = 69.4 ± 1.7 で、BBN からの情報はまったく使っていません。
  • 標準的な辞書を通して、これは D/H = (2.40 ± 0.31)·10⁻⁵ を予測します。
  • 測定値は 2.508 ± 0.029 で、z = −0.34 です。
  • D/H は BAO のフィットに入っていません。しかし、このチェックは Ω_c/Ω_b のテストと同じ BAO と同じ制約を使っています。したがって、それから独立してはいません。

数が意味すること。

  • 連鎖は整合しています。BAO は、パラメータが一つ少ない状態で、ΛCDM と同じくらいよく読まれています。
  • H₀ はすでに知られている BAO + BBN の値です。整合であり、新しい数ではありません。
  • 今日、この制約は H₀ を狭めません（0.60 に対して 0.59）。データがすでにこの比の近くにあるからです。
  • a₀ = cH₀/6 は SPARC と整合していますが、決定的ではありません。SPARC の系統誤差 20 % は H₀ = 73 も許します。
  • MM 2.56 の広連星の連鎖は H₀ = 67.4 を使っています。1.1 km s⁻¹ Mpc⁻¹ の差は、そこで明示された感度の範囲（67.4-73.04）の中にあります。2.56 のプロトコルは変わりません。

5. 時間についての前提の読み（レベル 2）

前提。 MM の枠組みの一つの前提は、最初の数分の標準的な説明を、現在において行われる読みとして扱います。この読みでは、すべての過程に共通の一つの時間があり、客観的な始まりはありません。

翻訳。 この前提を、測定できる量へと六つの仕方で翻訳しました。翻訳は計算の前に登録されました。プログラム PRyMordial を NACRE II の反応率と LUNA で実行しました。63 の核反応の完全なネットワークを使いました。

  • T2b、同じ温度で、重力をおよぼす放射をもつ隠れた鏡セクター。 私たちの世界のコピーで、固有の光をもち、それが私たちの光と同じように重さをもちます。多くの放射を加えることになります。e⁺e⁻ 対消滅の前は ΔN_eq = 6.14、あとは 7.44 となります。対消滅とは、電子と陽電子が光に変わった時期です。重水素は +10/+11σ、ヘリウムは +20/+23σ となります。調べた二つの場合について、この読みは成り立ちません。 鏡セクターの完全な熱史はシミュレートしていません。この結果は、隠れた放射は重力をおよぼさないという MM 2.44 の仮定と一致します。
  • T3、中性子の寿命。 三つの値を試します。ボトル（878.3 s）、ビーム（888.0 s）、J-PARC（877.2 s）です。重水素はほとんど変わりません。ボトルの値を支持する弱い示唆があります（Δχ² = 1.2）。ヘリウムは τ_n = 870 ± 15 s を選びます。
  • T4、今日の一つのバリオン光子比。 ω_b を重水素だけから得ます：0.02242 ± 0.00056。CMB の値 0.02230 ± 0.00021 と比較します。整合しています：z = +0.20。

リチウム。

  • 成り立つどの読みでも、予測されるリチウムは測定値の約 3.5 倍です。リチウムは、銀河系のハローの、金属の少ない古い星で測定されます。
  • 差は、ログが z を計算しているところで、理論誤差 15 % として 4.3-4.6σ です。
  • リチウムに基づいて作られた翻訳はなく、どの翻訳もリチウムを読みません。
  • これは見るべき測定事実として残ります。PDG は、星で測定された値を、厳密には下限として扱っています。

連鎖にとって変わるもの：何もありません。 成り立つ翻訳は、レベル 1 の辞書をそのままにします。T2b は調べた場合について成り立ちません。T3 は中性子の寿命を開いたままにし、すでに使っている値への弱い示唆があります。

7. 何が既知で、何がこの解析に固有か

すでに知られていること。 多くの研究が、CMB なしの BAO + BBN から H₀ をすでに得ています。

  • Addison ら 2018（66.98 ± 1.18）；
  • Cuceu ら 2019（67.6 ± 1.1）；
  • Schöneberg、Lesgourgues、Hooper 2019；
  • Schöneberg ら 2022（67.6 ± 1.0；ShapeFit で 68.3 ± 0.7）；
  • DESI DR2（68.51 ± 0.58）。

Krolewski、Percival、Woodfinden 2024（arXiv:2403.19227）は、別の道で BBN から H₀ を得ています。銀河の分布の中で*測定された*バリオン割合を使っています。その誤差はより大きいものです（67.1 +6.3/−5.3）。この研究の H₀ は、最初のグループの解析の BAO + BBN の値です。

この解析に固有なもの。

  • 比 q = Ω_c/Ω_b = 3√3 を、測定するのではなく課しています。パラメータが一つ少なくなります。
  • これにともなって、さらに二つの部分があります。第一は、BAO から重水素への逆向きの読みです。第二は、a₀ = cH₀/6 および広連星の連鎖とのつながりです。
  • 的を絞った検索では、この制約を BAO と BBN と一緒に使った解析は見つかりませんでした。ただし、完全な調査ではありません。

主張しないこと。

  • 3√3 は導出されていません。データを知ったうえで選ばれた読みです（等級 B*）。
  • CMB を入れると、3√3 は Planck から約 2σ のところにあります（MM 2.44 と 2.54）。この比較はこの連鎖の外にあります。
  • Verlinde の創発重力は、Ω_b = 4/81 なら同じ比を与えます（MM 2.54）。

8. これがどのように誤りとなりうるか

  • ブロック D が、DR2 を超える DESI のデータで Δχ² > 9 を与える場合。 このとき、読み ω_c = 3√3·ω_b は BAO + BBN を読まないことになります。
  • cH₀/6 から遠い g† の精密な測定（ブロック A）。
  • D/H の平均、または反応 d(p,γ)³He と d+d の率が、D-1 の誤差を超えてずれる場合。 これは ω_b を動かし、したがって連鎖全体を動かします。D-5 の辞書は、LUNA 以前の反応率を使うことがどれだけの重みをもつかを示しています。
