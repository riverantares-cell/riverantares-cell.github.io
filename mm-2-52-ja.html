1. この研究は何であり、何でないか

問い

標準模型は、重力を除く、粒子とそれらのあいだの力を記述する理論です。非常によく機能しています。しかし、多くの異なる部品をもっています。異なる力、異なる電荷、色、質量です。この研究の問いは次のものです。一つの読みの規則が、標準模型の*構造*に共通の意味を与えることはできるでしょうか。

構造とは、次の五つのことを指します。

  • どんな力があるか；
  • 粒子がどんな電荷をもつか；
  • 「色」がいくつあるか；
  • なぜ荷電弱カレントは粒子の一方の「手」にしか作用しないのか；
  • 質量はどこから来るのか。

この研究はデータから MM へと進み、決して逆には進みません。標準模型の各部品について、次の順序で述べます。

  • 測定された事実；
  • MM の読み；
  • 二つが整合するか、つまり一致するか；
  • 同じことを行う、他者によってすでに公表された構成；
  • 何があればその読みが整合しなくなるか。

結果

標準模型のゲージセクターのいくつかの選ばれた構造は、MM の共通の解釈を受け入れます。粒子の一つの世代の電荷のパターンについても同じです。ただし、これは第 3 節に挙げるいくつかの追加の仮説のもとで成り立ちます。合う部品は四つです。

  • 三つの色と、互いに相互作用する八つのグルーオンモード（グルーオンは強い力を運びます）；
  • 電弱力の四つのボソン、質量のない光子、ツリーレベルでの ρ = 1（第 4.5 節で説明します）；
  • 1/3 や 2/3 のような分数電荷と、中性のニュートリノ、中性の中性子；
  • 格子上のただ一種類の軽いディラック粒子。そこから、射影によって一つの「手」（ワイル・セクター）が選ばれます。テストした U(1) 背景では、その較正された指数はトポロジカル電荷と一致します。

これらの言葉は一つずつ説明していきます。今のところは、これらが四つの別々のチェックであることを知っていれば十分です。チェックは別々の構成に関するものです。それらを一つのカイラルゲージ理論にまとめることは、まだ確立されていません。

パラメータは読まれません。 パラメータとは、理論がそれ自体では固定しない数です。ここでは、データから取るか、開いたままにしています。

  • 弱混合角 θ_W；
  • スケール v；
  • 質量；
  • クォークとニュートリノの混合；
  • 強い CP の角度 θ̄。

何でないか

  • 標準模型の導出ではありません。 ここで使う構成はすべて既知のものです。
  • Wilson の格子ゲージ理論；
  • グラショウ–ワインバーグ–サラム模型；
  • パティ–サラムの電荷パターンと、Furey の個数演算子による構成；
  • ギンスパーグ–ウィルソン関係と、Neuberger のオーバーラップ演算子；
  • Kaplan のドメインウォール。

第 2 節は、何よりも先にそれらを挙げています。数学的な先取権は主張しません。 この研究は、この数学を最初に発見したとは言っていません。

  • MM に固有なのは読みの規則だけです。これらの構成に共通の意味を与える規則です。この規則とともに、登録済みのチェックがあります。規則がどこでデータに合い、どこで合わないかです。
  • これらのチェックによって、実験で MM を標準模型と区別できるようになるわけではありません。

主張をどう区別しているか

本文は四種類の主張を区別しています。

  • 他者による公表された結果（第 2 節）。
  • 読み。 著者の前提を物理の言葉に翻訳したものです。翻訳が著者の言葉に加えたものには、翻訳者による追加であることが記されています（第 3 節）。

3. 読みの規則を物理の言葉で

前提は、幾何学の公理のような、著者の出発点です。2026 年 10 月 15 日には十個ありました。それ以前からのものもあります。MM の本からのものと、2026 年 9 月 27 日からのものです。ここでは物理の言葉で述べます。著者の正確な言葉は、イタリア語で、元の登録の中にだけあります。それらの背後にある描像の非公式な説明も、言葉の説明つきであります。しかし、チェックの中でその説明に依存するものはありません。

規則を一文で

粒子と力は異なる対象ではありません。同じ構造の異なる読みです。

理解するために、格子を想像してください。方眼紙の交点のような、空間の中の点のグリッドです。隣り合う二点のあいだには、正方形の辺のようなリンクがあります。各読みは次の三つを割り当てます。

  • 格子の各リンクに、関わる読みの輸送。輸送は、粒子がある点から次の点へ移るときにどう変わるかを表します。光については位相、つまり時計の針の位置のような回転の角度です。弱い力については二つの単位です。色については三つの読みです；
  • 各フェルミオン、つまり物質の各粒子に、二つのもの。共有する読みの数（これが電荷です）と、読まれる手（これがカイラリティです）；
  • ヒッグス場に、二つの手を結ぶ射影。この射影が質量です。

カイラリティは右手と左手の違いのようなものです。同じ形ですが鏡像で、重ね合わせることができません。粒子にも「左巻き」の形と「右巻き」の形があります。

規則の部分

規則には R1 から R6 までの六つの部分があります。三列目には、物理の言葉への翻訳が著者の言葉に加えたものがあります。

読み翻訳による追加
R1三つの内部の読み。 フェルミオンの内部には三つの二値の読み、つまりイエス／ノー型の読み（取られる／取られない）があります：2³ = 8 状態。色は、どの読みが関わるかを表します。リンクに沿った輸送はそれらを混ぜることができます。ユニタリな 3×3 行列です。三つの読みが同等であること、任意のユニタリ行列がそれらを混ぜうること。輸送が C³ 上の選ばれた複素体積形式を保つこと。これにより det U = 1 が課され、U(3) ではなく SU(3) となります。
R2共有された読みからの電荷（規則 R-Q）。|Q| = N_shared/3。N_shared は色の三重項（クォーク）では 1 または 2、一重項（レプトン）では 0 または 3 です。共役な状態は反対の電荷をもちます。三重項と一重項の区別は追加された規則です。そこにはすでにクォークとレプトンの区別が含まれています。
R3三つの世代。 同じ三つ組の読みを、反対側から見ると、三つの世代を与えます。色の数が世代の数に等しいこと。読まれるのは数だけで、質量は読まれません。
R4光と弱い力。 光はリンク上の位相です（MM 2.27）。弱い力は同じ輸送で、リンク上で二つの単位が混ざります。一つは完全な単位で、もう一つはわずかに小さい単位です。U(2) = [SU(2) × U(1)]/Z₂ の行列です。「わずかに小さい単位」が二重項の第二の状態であること。
R5質量とヒッグス。 フェルミオンの質量は、その二つの手を結ぶ射影です。ヒッグス場は、一つのスケール v をもって、この射影が起きる場所です。ヒッグスの質量はその場の自己結合から来ます。低温での電弱スケールは固定された構造的パラメータです。「自己共鳴」が四次結合 λ であること。「歴史」が、経過した時間（読み L8-b）としてではなく構造（読み L8-a）として読まれること。
R6読みの行為としての一つの手。 荷電フェルミオンでは、電弱対称性の破れのあと、左巻き成分と右巻き成分がディラック場をなします。荷電弱カレントは左巻き成分に作用します。光は両方に作用します。読みは違いを、場ではなく射影演算子に置きます。格子上では、軽い種には双子がいます。読みのレベルが格子スペクトルの「丘」の底より上で、最初の尾根より下にあるとき、双子はセルのスケールに押しやられます。二つの成分は異なる電弱表現をもち、湯川結合は構成の一部として残ります。射影演算子だけではそれらを割り当てません。窓 0 < m₀ < 2r は構成の条件であり、前提の帰結ではありません。著者は「丘の頂上を越える」と言いました。それを「谷の底を越える」と読むのは、翻訳者が与えた比喩の新しい解釈です。ニュートリノがディラック型かマヨラナ型かは開いたままです。

表のための言葉をいくつか。行列は、別の数の列を変換する数の表です。ユニタリとは、回転のように長さを保つことを意味します。SU(3)、SU(2)、U(1) は、強い力、弱い力、電磁力の三つの力の対称性の群の名前です。det U = 1 は行列の行列式についての条件で、SU(3) を U(3) から区別するものです。三重項は、クォークの三つの色のように、一緒に変換する三つの状態のまとまりです。一重項は単独の状態です。二重項は、弱い力における電子とニュートリノのような組です。

4. 地図を部品ごとに

では、標準模型の部品を一つずつ見ていきましょう。各部品には同じ項目があります。データ、読み、チェック、整合するかどうか、誰がすでに行っていたか、何が読まれないかです。括弧の中のラベル（P2a や G1 など）は、登録済みチェックの名前です。第 6 節の表でそれらを見つけるのに役立ちます。

4.1 一つの世代の電荷（登録済みチェック P2a–P2c）

  • データ。 粒子の電荷は 0、±1/3、±2/3、±1 です。中性子と水素原子は中性です。たとえば、u クォークの電荷は 2/3、d クォークは −1/3、電子は −1 です。
  • 読み。 R1 + R2、つまり規則 R-Q です。電荷は、共有された読みを数えて 3 で割ったものです。
  • チェック。 理論の力はアノマリーのないものでなければなりません。ここでアノマリーとは、古典物理学から量子物理学に移るときに現れる欠陥です。それが力の対称性に及ぶと、理論はもはや無矛盾ではありません。右巻きニュートリノ ν_R とディラック質量をもつ、アノマリーのない世代を考えましょう（MM 2.38）。そこでは、電荷は一つの自由な数に依存します。クォーク二重項のハイパーチャージ Y_Q です。式は次のとおりです。q_u = Y_Q + 1/2、q_d = Y_Q − 1/2、q_ν = 1/2 − 3Y_Q、q_e = −1/2 − 3Y_Q。四つのアノマリーは Y_Q のすべての値で消えます。一方、規則 R-Q はちょうど二つの値だけを認めます。Y_Q ∈ {−1/6, +1/6} です。それらを見つけるために、−3 と 3 のあいだの、分母 60 までのすべての分数を試しました。さらに厳密解もあります。
  • Y_Q = +1/6 は標準模型です。ニュートリノ 0、電子 −1、u 2/3、d −1/3、中性子 0、水素 0。
  • Y_Q = −1/6 は同じ内容で、二つの変更があります。Q → −Q とします。そして、すべての二重項の二つの成員を入れ替えます。u ↔ d、ν ↔ e とその右巻きの相手、ヒッグスとその共役、湯川結合です。色は変わりません。これはあとから確かめられました。ラベルのつけ替えの登録された形（3 ↔ 3̄ をともなう Q → −Q）は誤っていました。
  • ν_R がなければ、規則は何も加えません。アノマリーがすでに Y_Q = 1/6 を固定しており、規則はそれを認めます。
  • 整合：はい。 ν_R があると、規則は、アノマリーだけでは自由なままの電荷を固定します。
  • すでに占められている場所。 パティ–サラムと SO(10) も、ν_R があるとき電荷を固定します。また Furey（2016）は、同じ 8 状態の空間で、個数演算子から電荷のパターンを得ています。R-Q はそれらのモデルの導出ではありません。クォークとレプトンの区別を含む、追加された規則です。
  • 読まれないもの。 微細構造定数、つまり電磁力の強さの値。湯川結合。

4.2 三つの読みの代数（登録済みチェック T-A）

R1 の 8 状態は、それぞれオンかオフの三つのスイッチで記述できます。数学的には、スイッチをオンまたはオフにする三つの演算子 ε_i（i = 1, 2, 3）を使います。すべての状態の空間は、三モードのフォック空間と呼ばれます。C³ の外積代数です。MM 2.27 のレコードのフェーズ 2.29 や Furey（2016）と同じ構成です。五つのチェックは次のとおりです。

  • A1。 演算子はフェルミオンの基本的な規則（正準反交換関係）に従います。厳密で、誤差 0 です。
  • A2。 個数演算子 N のありうる値は {0, 1, 1, 1, 2, 2, 2, 3} です。したがって N/3 は 0、1/3（三回）、2/3（三回）、1 を与えます。これらはちょうど電荷です。技術的な注です。アーカイブされた規約では、Σ ε_i†ε_i は空の読みを数え（3 − Σb）、N_shared = Σ ε_i ε_i† です。査読者は、ログの中のセクター N = 1 と N = 2 のラベルが演算子に対して入れ替わっていることを指摘しました。スペクトルとカシミールの値は変わりません。
  • A3。 ε_i†ε_j の組み合わせは九つあります。これらは N と交換します。つまり、電荷を変えません。そのトレースのない部分は、色の代数である su(3) を生成します。カシミールは状態のまとまりを特徴づける数です。一つおよび二つの読みのセクター（共役な二つの三重項）では 4/3、ほかの二つでは 0 です。
  • A4。 フェーズ 2.29 のスピン生成子は S_i = −(i/2) C_j C_k です。これらは N と交換しません（‖[S_i, N]‖ = 1）。条件つきで述べると、これらのスピン生成子は、この電荷をもつ内部の添字には作用できません。スピンと電荷が交換する表現が必要です。通常は別々の因子を使います。
  • A5。 十五の積 C_iC_j、K_iK_j、C_iK_j は N のパリティ、つまり N が偶数か奇数かを保存します。これらは次元 15 の代数を生成します。偶のセクターと奇のセクター（1 + 3 と 3 + 1）で既約です。訂正（査読者による。再確認済み）。これらの生の積は、非コンパクトな形である so(3,3) ≅ sl(4,R) を生成します。エルミートな生成子 (C_i, iK_i) では、代数は次元 15 のコンパクトな su(4) となり、4 → 3 + 1 です。これはパティ–サラムのパターン、つまり第四の色としてのレプトンです。完全なパティ–サラム模型ではありません。弱い因子、物理的な生成子の同定、力学が欠けています。

4.5 電弱ボソン：リンク上の二つの単位（登録済みチェック E1–E4）

4.6 一つの軽い手（登録済みチェック O1–O5、H1–H2）

  • データ。
  • 荷電弱カレントは左巻きフェルミオンに作用します。ミューオン崩壊のパラメータがそう言っています（PDG 2025、レビュー 57、表 57.1）。90 % の限界は次のとおりです。|g^V_LL| > 0.960、|g^V_RR| < 0.017、|g^V_LR| < 0.023、|g^V_RL| < 0.105。言葉で言えば、「左-左」の係数は大きく、右手が関わる係数は非常に小さいのです。

  • O1。 ギンスパーグ–ウィルソン関係 γ5D + Dγ5 = Dγ5D は、両方のセットで 9e-16 まで成り立ちます。これはマシン精度です。

  • 壁。 ドメインウォールは、粒子が閉じ込められうる境界です。新しい谷の中で壁の状態を探しました（登録済みチェック T-D）。半周期で余分な状態が見つかりました。しかし、使った数え上げの方法は壁の状態を切り分けません。幅 0.08 の窓をもつ射影演算子のトレースを使っていました。そのためバルクの状態も拾っていました。このため、D1 は満たされなかったと報告しています。あとから行った診断は、最初の描像を与えます。
  • 2.40 のパラメータ（θ₀ = 0.2 > r = 0.15）では、これらの状態の一部は壁の上に、質量 ≈ 0.013 で存在します；
  • テストした値 θ₀ = 0.1 < r では、選ばれた状態はほとんどがバルクの状態です。

用語集

  • 代数、群。 対称性を記述する二つの数学的な方法です。群は変換を含み、代数はそれらの「非常に小さい」形を含みます。代数、群、力は区別しなければなりません。
  • アノマリー。 量子物理学に移るときの、古典物理学の対称性の破れです。力の対称性（ゲージ対称性）に及ぶと、理論は無矛盾でなくなります。そこではアノマリーはあってはなりません。
  • ボソン。 整数のスピンをもつ粒子です。光子、グルーオン、W、Z は力を運びます。ヒッグスもボソンですが、それらのようには力を運びません。
  • カイラリティ、手。 二つの手のような、左か右かです。同じ形ですが鏡像です。
  • フェルミオン。 物質の粒子です。クォークとレプトンです。
  • 丘。 ウィルソン項 r Σ(1 − cos k_μ) です。k = 0（谷）でゼロで、π に等しい成分を n 個もつ角に尾根 2rn があります。
  • 指数。 演算子の左と右のゼロモードの差です。
  • 格子。 方眼紙の交点のような、空間の中の点のグリッドです。
  • リンク。 格子の隣り合う二点のあいだの線分です。
  • リンク輸送。 場の内部成分を格子の一点から次の点へ運ぶ行列です。光では位相、弱い力では 2×2、色では 3×3 です。
  • オーバーラップ。 軽い粒子を一つだけ残し、双子をセルのスケールに押しやり、手のあいだの対称性をギンスパーグ–ウィルソン形式で格子の上に保つ構成です。
  • プラケット。 格子の小さな正方形です。プラケット作用は、小さな正方形ごとに一つの寄与を足し合わせます。
  • 前提。 公理のような、著者の出発点です。
  • 読み。 MM では、登録された観測です。ここでは、力が場にどう作用するか、どの成分とどの手に作用するかを指します。
  • 読みのレベル m₀。 オーバーラップの質量パラメータです。軽い種は、ウィルソン項が m₀ より小さいものです。
  • 登録済み。 計算の前にファイルに書かれ、指紋を与えられたということです。
  • 標準模型。 粒子と、強い力、弱い力、電磁力の理論です。
  • ツリーレベル。 仮想粒子なしの、最初の、最も単純な計算のレベルです。
  • 双子、二重子。 格子によって強いられる（ニールセン–二宮）、余分な軽い種です。本物の粒子のこだまのようなものです。
  • 巻き付き W。 写像がその行き先を何回包み込むかの数です。指に巻いた輪ゴムのようなものです。技術的には、ブリルアン・トーラスから SU(2) または U(n) への写像の三次元の巻き付き数です。SU(2) ≅ S³ では写像の次数です。±I が正則値のとき、局所的な有効ハミルトニアンから定義された、準エネルギー 0 と、別に π でのノードのカイラリティの和に等しくなります。
