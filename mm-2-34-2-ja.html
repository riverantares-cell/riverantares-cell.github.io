手短に

コンパクトな星とは

星は自分自身の重力でまとまっています。星の内部の物質の圧力が外向きに押し、星を平衡に保ちます。中性子星は、非常に強く押しつぶされた、死んだ星です。太陽とほぼ同じ質量が、都市ほどの大きさの球に入っています。

コンパクト度 C は、星がどれだけ押しつぶされているかを表します。比 GM/(Rc²) で計算します。ここで M は質量、R は半径、G は重力定数、c は光の速さです。質量が大きく半径が小さいほど、C は大きくなります。

ブーフダール限界

アインシュタインの一般相対性理論（GR と書きます）には、有名な限界があります。Buchdahl が 1959 年に見つけたものです。これは静的な星、つまり静止していて、完全流体でできていて、密度が外側に向かって増えない星について成り立ちます。そのような星は 4/9 よりコンパクトにはなれません。その値を超えると、中心の圧力が無限大でなければならなくなります。

別の規則

この研究は、静的な球形の星の内部について別の規則を調べます。この規則は二つの数を結びつけます。

  • ラプス関数 N は時計の進みを表します。質量の近くでは時計は遅く進みます。N は 1 より小さくなります。
  • 等方的共形因子 ψ は、地図上のある区間に実際どれだけの空間があるかを表します。質量の近くでは、同じ区間を覆うのにより多くの定規が必要です。

規則は次のとおりです。

N = 2/ψ − 1。

真空中の一つの球形の天体については、この関係は厳密に成り立ちます。これはシュヴァルツシルト計量、つまり球形の質量のまわりの何もない空間についてのアインシュタインの解を、等方座標で書いたものの性質です。

これを物質の内部にも課すと、方程式の中で変わるのは一つのことだけです。圧力はもはやラプス関数の源として働きません。 GR では、圧力は質量と少し似た形で重力に寄与します。ここでは、時計の進みについてはもはや寄与しません。

得られた計量をアインシュタイン方程式で読んでみましょう。すると、流体のほかに余分な応力があるように見えます。これを非等方な有効応力と呼びます。非等方とは、すべての方向で同じではないという意味です。

物質の内部での GR との違いは小さく、p/ρ の程度です。ここで p は圧力、ρ はエネルギー密度です。普通の星では p/ρ はごくわずかです。だから違いは中性子星でしか現れません。

結果

  • 一様な密度、つまりどこでも同じ密度の場合、星の系列はコンパクト度 2^(1/3) − 2^(−1/3) ≈ 0.466 で終わります。これは厳密な式です。GR では限界は 4/9 ≈ 0.444 です。密度が外側に向かって減る場合、最大値はより低くなります（後の表を参照）。
  • 一様な密度で、コンパクト度が 0.15 から 0.23 の間のとき、中心に必要な圧力は GR より 7–12% 低くなります。
  • 現実的な核物質の状態方程式を二つ使うと、最大質量は約 5% 上がります。半径の変化は約 0.1 km です。これは NICER の測定の現在の誤差より小さい値です。この二つの状態方程式では、GR も規則も星 PSR J0437−4715 と整合します。そして星 PSR J0740+6620 については、どちらも Salmi らの 68% 区間より小さい半径を与えます。

この規則は仮定であり、導出ではありません。そしてまだ理論でもありません。作用もダイナミクスもないからです。 作用とは、ある理論のすべての方程式がそこから得られる式のことです。ダイナミクスとは、ものごとが時間とともにどう変わるかを示すものです。

なぜこの規則なのか

真空中の一つの天体については、ラプス関数は等方的共形因子だけで決まります。N = 2/ψ − 1 です。シュヴァルツシルト計量は質量に M/r を通してだけ依存します。だから同じ式がどの質量 M についても成り立ちます。

この研究の仮定は、同じ式が物質の内部でも成り立つというものです。GR では、ハミルトニアン拘束はエネルギー密度だけから ψ を与えます。一方、圧力はラプス関数の方程式に入ります。したがって N = N(ψ)、つまり N を ψ だけの関数とすることを課すと、ラプス関数の源から圧力が取り除かれます。ハミルトニアン拘束と流体の方程式は変わりません。

この規則は、ある非形式的なイメージから著者に示唆されたものです。そのイメージでは、ある場所のラプス関数はその場所の共形因子だけで決まります。物質の内部応力には依存しません。関心のある読者のために、このイメージは別の文書で説明されています。計算のどの部分もこのイメージには依存していません。

中性子星は、圧力がエネルギー密度に匹敵する唯一の静的な天体です。だから、この規則を検証にかけられる場所は中性子星です。

方程式

等方座標と、静的な球形の星を使います。計量は ds² = −N²dt² + ψ⁴(dr² + r²dΩ²) です。G = c = 1 となる単位を使います。ρ は静止した観測者が測る全エネルギー密度です。方程式は三つあります。

  1. ハミルトニアン拘束（一般相対性理論と同じ）： ∇²ψ = −2πρψ⁵。密度が空間をどう曲げるかを示します。
  2. 規則（GR のラプス方程式 ∇²(Nψ) = 2πNψ⁵(ρ + 6p) の代わりに置きます）：N = 2/ψ − 1、つまり ψ + Nψ = 2。
  3. 物質： エネルギーと運動量の保存 ∇_μT^μν = 0 に従う完全流体です。つまり p′ = −(ρ + p)N′/N で、表面では p = 0 です。言葉で言えば、星の各層が平衡にあるということです。

記号 ∇² はラプラシアンと呼ばれます。ある点の値が、近くの点の平均とどれだけ違うかを測ります。

規則はどこから来るのか、何を仮定しているのか

等方座標では、シュヴァルツシルト計量は ψ = 1 + M/2r、N = (1 − M/2r)/(1 + M/2r) です。だから、どの M についても N = 2/ψ − 1 です。ラプス関数が等方的共形因子だけの関数だと仮定しましょう。すると真空の GR は、その関数をただ一通りに定めます。

変数の選び方は重要です。 面積座標を使うこともできます。その座標では、同じ議論から N²g_RR = 1 が得られます（Jacobson 2007）。物質の内部では、この関係は p_r = −ρ を強制し、コンパクト度 1/2 までを許します。この研究の結果は等方の規則の性質です。等方の変数は著者の選択です。これは仮定です。空間の計量を共形平坦とし、ψ を物理的な変数とし、規則を物質の内部にも課しています。ψ は星全体にわたって拘束を積分して得られます。だから規則は二つの場の間の点ごとの関係です。局所的な状態方程式ではありません。

一つの天体だけ。 これらはすべて厳密な球対称について成り立ちます。二つの質量で試してみましょう。ψ = 1 + a₁/|x − x₁| + a₂/|x − x₂| です。この ψ は調和関数です。ある瞬間に静止している二つの天体についての Brill–Lindquist の共形因子です。N = 2/ψ − 1 とすると、この静的な計量は真空解ではありません。曲率を測るリッチテンソルがゼロになりません。ある開いた領域で a₁a₂ の程度の項をもちます。この項は、二つの質量のどちらかを取り除くと消えます。

ここから言えること

流体の圧力は場の方程式に入りません。計量は、したがってその有効応力も、ρ だけで定まります。

同じ計量をアインシュタイン方程式で読んでみましょう。この計量は非等方な有効応力をもちます。動径方向の圧力 p_r（外向き）は接線方向の圧力 p_t（表面に沿う向き）と異なり、p_t > p_r です。ニュートン極限、つまり重力が弱い場合にすでに、中心での有効な動径応力は流体の圧力の半分です。有効応力と流体の応力との差は、それ自体で保存され、エネルギー密度はゼロです。

これは静的な方程式の現象論的な閉包であり、まだ理論ではありません。 作用もダイナミクスもありません。現象論的な閉包とは、方程式を完結させて計算を可能にする実用的な規則のことです。

局所と大域。 星から遠く離れると ψ → 1 + M_ADM/2r、N → 1 − M_Komar/r となります。M_ADM と M_Komar は、遠方から全質量を測る二つの仕方です。全空間で積分すると ∫∇²(ψ + Nψ) d³x = 4π(M_Komar − M_ADM) となります。GR では、積分の中の量 2πψ⁵[N(ρ + 6p) − ρ] は物質の内部でゼロではありません。しかしその積分はゼロです。遠方で平坦になる定常な時空では Komar 質量と ADM 質量が一致するからです（Beig 1978）。一方、規則はこの量を点ごとにゼロにします。GR では収支が合うのは全体についてだけですが、ここではすべての点で合います。

関連する理論

ほかの提案にも、真空では GR を（宇宙定数を除いて）変えず、物質の内部だけを変えるものがあります。

  • Eddington に着想を得た Born–Infeld 重力（Bañados と Ferreira 2010）。その中性子星は Pani、Cardoso、Delsate（2011）が調べました。
  • Palatini f(R) 重力（Olmo 2011）。

これらの理論は、二つの点でこの研究の規則と異なります。第一に、それらは作用から導かれますが、規則には作用がありません。第二に、それらの内部は結合に依存します。Born–Infeld 重力では κ、Palatini f(R) では関数 f です。一方ここでは、等方の変数をいったん選ぶと（上で述べた仮定です）、物質の内部での N と ψ の関係は真空解が定めたものです。規則には結合定数がありません。状態方程式は入力のままです。一様な密度の場合、これはただ一つの値 0.466 を与えます。

違いはどこから来るのか

これらの変数では、ψ の源はエネルギー密度だけです。GR でも規則でも同じです。これは同じハミルトニアン拘束によるものです。唯一の違いはラプス関数の方程式です。

GR では圧力はラプス関数の源です。共変な形では D²N = 4πN(ρ + 3p) と書きます。上で使った平坦なラプラシアンの形では ∇²(Nψ) = 2πNψ⁵(ρ + 6p) となります。ここでは逆に、ラプス関数は ψ から決まるので、圧力はその源ではありません。

これは実際には何を意味するのでしょうか。GR では圧力が重力の引力を増やします。圧力が増えれば重力が増え、さらに多くの圧力が必要になります。規則のもとでは圧力はもはやラプス関数の源ではなく、圧力による重力の引力は少なくなります。すると同じ星は、平衡を保つのに中心でより少ない圧力で済みます。そして与えられた状態方程式は、少しだけ多くの質量を支えます。

二つの星の系列は、異なる理由で終わります。GR では、一様密度の星の系列は 4/9 で終わります。そこで必要な中心圧力が無限大になります。規則のもとでは、中心のラプス関数がゼロに達するところ、ψ_c = 2 で、0.466 で終わります。そこでも圧力は無限大になります。

この効果は相対的に p/ρ の程度です。どんな物質にも存在します。しかし太陽や地球では p/ρ はごくわずかで、GR と規則はその精度で一致します。p/ρ が数十パーセントに達するのは中性子星だけです。測定できるほど二つが分かれるのは、そこだけです。

星の系列はどこで終わるのか

次々とよりコンパクトな星を作っていくことを想像してください。遅かれ早かれ系列は終わります。ある点を超えると、星は平衡を保てません。

一様な密度については、GR でも規則でも一つのことが成り立ちます。積 (ρ + p)N が一定です。だから、中心の圧力が無限大になるのは、ちょうど中心のラプス関数がゼロに達するときです。GR では圧力がラプス関数の源です（平坦なラプラシアンの形では ρ + 6p）。だから圧力が戻ってきて幾何に作用します。一方、規則のもとでは N は ψ で定まり、ψ は ρ だけで決まります。系列は ψ_c = 2 で終わります。これは N = 2/ψ − 1 ≥ 0 となる値の範囲の端です。ψ_c = 2 では中心のラプス関数はゼロです。そこでは時計が止まります。

一様な密度：厳密な式。 拘束は n = 5 のレーン–エムデン方程式です。解は ψ = ψ_c(1 + 2πρψ_c⁴r²/3)^(−1/2) です。ここで ψ_c は中心の値です。外部とつなぐと ψ_R = ψ_c^(2/3) が得られます。コンパクト度は C = GM/(Rc²) = 2(ψ_R − 1)/ψ_R² で、R は面積半径です。

  • GR のブーフダール限界 C = 4/9 は ψ_R = 3/2（ψ_c = 1.8371）に対応します。
  • 限界 ψ_c = 2 は C_max = 2^(1/3) − 2^(−1/3) = 0.46622 を与えます。次のようにも言えます。表面を離れる光の赤方偏移が z = 2.847 です（GR では 2）。赤方偏移とは、光が星の重力から抜け出すときにどれだけ引き伸ばされるかを表します。この値は、非等方な星についての Ivanov の限界値より下にあります。接線方向の圧力に課すエネルギー条件に応じて、3.842 または 5.211 です。
  • 流体の圧力に p_c ≤ ρ を要求しましょう。すると y = ψ_c^(1/3) について方程式 y³ + 2y − 4 = 0 が得られます。つまり C = 0.40427 です（GR では 3/8）。これは一様な密度についてだけ成り立ちます。
  • 中心での有効な動径応力は p_r/ρ = (ψ_c − 1)/(3(2 − ψ_c)) です。

Buchdahl の仮説とのつながり。 Andréasson（2008）の定理があります。これは二つの条件 p_r ≥ 0 と p_r + 2p_t ≤ ρ のもとで、静的な球形の GR の解について成り立ちます。そのとき、密度の変化の仕方に何の要求もなしに 2m/r ≤ 8/9 です。ここでは p_r ≥ 0 です。だから 4/9 を超えるには、トレース条件 p_r + 2p_t ≤ ρ を破らなければなりません。これは中心で ψ_c > 3/2、つまり C > 0.3615 のときに起こります。GR 自身の一様な星も、C > 5/18 で同じ条件を破ります。星を Buchdahl の仮説の外に出しているのは非等方性です。有効応力についての優勢エネルギー条件は ψ_c > 7/4（C > 0.4289）で満たされなくなります。しかし 4/9 を超えるのに、これは必要ではありません。

現実的な状態方程式と NICER

状態方程式とは。 状態方程式は、ある密度で物質がどれだけの圧力を生むかを示します。スポンジと石を考えてください。押しつぶすと、スポンジはすぐに縮み、石は抵抗します。中性子星の核物質には独自の「硬さ」があり、まだよくわかっていません。科学者はいくつかの可能な状態方程式を使っています。SLy、APR4 などです。「より硬い」ものほど強く抵抗します。

計算にどう入るか。 上と同じ三つの方程式を使います。ただし、冷たい核物質についての現実的な状態方程式 ε(p) を使います。ここで ε は全エネルギー密度で、上で ρ と呼んでいたものです。したがって次のようになります。

  • ψ はハミルトニアン拘束 ∇²ψ = −2πεψ⁵ から得られます（ε は全エネルギー密度）。
  • N = 2/ψ − 1 です。
  • p は保存則から得られます。p′ = −(ε + p)N′/N です。

すでに行っていた人：Buchdahl の 1964 年の仮定

物質の内部での関係 N = 2/ψ − 1 は新しいものではありません。

  • Buchdahl の選択。 1964 年に Buchdahl は、指数 5 のエムデンのポリトロープの相対論版を探していました。ポリトロープとは星の簡単なモデルです。Buchdahl は等方座標を選び、ψ = 1 + f、N = (1 − f)/(1 + f) としました（彼の式 2.2）。これはまさに N = 2/ψ − 1 です。彼の理由は上で述べたものと同じでした。外部のシュヴァルツシルト計量がこの形をしているということです（彼の式 2.3）。
  • 彼の計算。 次に彼は、物質が完全流体であることを要求しました。圧力の等方性、つまり圧力がすべての方向で等しいことから、f f″ − 3f′² − f f′/r = 0 が得られます（彼の式 2.7）。解は f = (A + Br²)^(−1/2) です（彼の式 2.8）。
  • A = 0 ではシュヴァルツシルトの外部解に戻ります。
  • A > 0 では彼の n = 5 の解になります。半径は無限大で、質量は有限です。

パッケージのプログラムの一つがこの計算をやり直しています。バージョン 2.34 は 4/9 の限界について Buchdahl（1959）を引用していましたが、この論文は引用していませんでした。

この研究が違っている点。 Buchdahl は、計量が完全流体をともなうアインシュタイン方程式の解であることを要求します。これで残るのは彼の n = 5 の族だけです。一方ここでは、この関係はどんな密度プロファイルについてもラプス関数の方程式の代わりになります。

  • 物質は依然として完全流体で、圧力は保存則から決まります。
  • 星の半径は有限です。
  • 捨てられているのは有効応力、つまり計量をアインシュタイン方程式で読んで得られる応力の等方性です。その有効応力は非等方です。

一様な密度での厳密な最大値 2^(1/3) − 2^(−1/3)、五つのプロファイル、現実的な状態方程式は、この第二の選択の帰結です。

ほかの先行研究。 2026 年 10 月 7 日に行った新規性チェックで見つかったものです。

  • ψ = 1 + f の形の Buchdahl の解の計量は、Delgaty と Lake（1998）のカタログの項目「Buch2」です。
  • 一様密度の星の共形因子は、ハミルトニアン拘束の n = 5 のレーン–エムデン解です。Baumgarte、Ó Murchadha、Pfeiffer（2007）が、ラプス関数なしの初期データとして調べました。
  • Puttasiddappa、Bretón、Pérez Bergliaffa（2026）は、ブーフダール限界を超えるものも含めて、一様密度の非等方な星を作っています。彼らの星では、非等方性は一定の係数で ρ k^μ∇_μP_r に比例します。この研究の星はその族には入りません。対応する比が半径に沿って変わるからです。

新しい結果

厳密な式で表した有効応力。 どんな密度プロファイルでも、規則の任意の配位をアインシュタイン方程式で読んでみましょう。記号計算により次が得られます。

  • ρ_eff = ρ。
  • トレース S = p_r + 2p_t = ρ(ψ − 1)/(2 − ψ)。
  • p_r = −ψ′[(rψ)′ − 1]/[2πrψ⁵(2 − ψ)] ≥ 0。

トレース条件 p_r + 2p_t ≤ ρ は、ちょうど ψ ≤ 3/2 のところで成り立ちます。

増えない密度についての限界値。 密度が外側に向かって増えない規則のすべての配位は、C < 12/25 = 0.48 を満たします。証明は三つのステップからなります。

  1. q = ρψ⁵ は増えません。だから m̃ = −r²ψ′ として、m̃(r)/r³ は増えません。
  2. これから ψ_c − ψ_R ≥ (ψ_R − 1)/2 が導かれます。
  3. 中心のラプス関数は正でなければならないので ψ_c < 2 です。これから ψ_R < 5/3 が得られます。

いくつかの注記です。

  • 初期データ。 この限界値が使っているのは、ハミルトニアン拘束と ψ_c < 2 だけです。
  • 非増加の条件がなければ、薄い殻は C = 1/2、つまり 2M/R → 1 に近づきます。
  • 状態方程式。 バロトロピックな状態方程式から作られる星では、密度は自動的に増えません。
  • 数値チェック。 どの階段状プロファイルも一様な場合の値 2^(1/3) − 2^(−1/3) = 0.46622 を超えません。この値は真の最大値についての予想のままです。
  • ランダムに選んだ 120 個の非増加の階段状プロファイルのうち、最大は 0.4662163 です。
  • 二段のプロファイルについての局所最適化は、一様なものをふたたび見つけます。このプログラムは、査読者の役割を担う AI アシスタントが独立に書きました。

ポストニュートン展開で見た内部。 ポストニュートン展開とは、ニュートンの重力への補正を段ごとに計算する仕方です。ポストニュートンの次数では、空間の計量は二つの理論で同じです。一方、ラプス関数は次を与えます。

  • GR では −g₀₀ = 1 − 2U + 2U² − 4Φ₂ − 6Φ₄。
  • 規則では −g₀₀ = 1 − 2U + 2U² − 5Φ₂。

ここで U、Φ₂、Φ₄ は「ポテンシャル」、つまり物質の分布の仕方で決まる数です。二行目は二通りに読むことができます。

  • GR の中で読む場合。 計量は GR のもので、トレースが最低次で S = ρU/2 である有効応力をもちます。すべてのポストニュートンパラメータは GR のものです。規則は物質についての言明になります。しかし、その物質は非局所的です。ψ を通して、ある点の応力は、r の内側と外側を含む配位全体の密度と、無限遠での ψ の規格化に依存します。これは、r の内側に含まれる物質だけに依存する Hernández と Núñez（2004）の状態方程式より強い非局所性です。
  • p を物理的な圧力とする場合。 すると規則は物質の内部での重力の修正として働きます。いくつかのパラメータが得られます。
  • ξ = 0 が強制されます。球の外では Φ_W に 1/r⁴ の項があり、これを打ち消すほかのポテンシャルはなく、規則の外部は厳密にシュヴァルツシルトです。モンテカルロ、つまり乱数を使うチェックがあります。
  • 残りの係数を合わせると β = γ = 1、ζ₃ = 0、ζ₂ = 1/2、ζ₄ = −1 が得られます。
  • 不変な作用から導かれるすべての理論は α₃ = ζᵢ = 0 をもちます（Lee、Lightman、Ni 1974）。
  • 連星パルサーは |α₃ + ζ₂| < 4×10⁻⁵ を課し、したがって ζ₂ を制限します（Will 2014）。強い場では |ζ̂₂| < 1.3×10⁻⁵ です（Freire と Wex 2024）。
  • したがって、この読みでは、規則は作用から導かれるどの計量理論の静的極限でもなく、これらの限界値と整合するどの計量理論の静的極限でもありません。 成り立たない：規則を修正重力とみなす読みです。
  • さらに、Will（1976、2014）の議論により、どんな妥当な理論でも 6ζ₄ = 3α₃ + 2ζ₁ − 3ζ₃ です。すると ζ₃ = 0 のもとで ζ₄ = −1 は 3α₃ + 2ζ₁ = −6 を要求することになりますが、|α₃| < 4×10⁻²⁰ です。

用語集

  • 作用。 ある理論のすべての方程式がそこから得られる式。この研究の規則には作用がありません。
  • 非等方。 方向によって異なること。非等方な応力は、外向きと表面に沿う向きとで押し方が異なります。
  • 結合エネルギー。 物質を一つひとつ数えた質量と、星全体の質量との差。
  • ブーフダール限界。 GR では、密度が増えない完全流体の星は C = 4/9 を超えられません。
  • 因果的。 状態方程式が因果的であるとは、物質の中の音が光より速く進まないことです：dp/dε ≤ 1。
  • 閉包、規則。 GR のラプス方程式の代わりに、物質の内部にも課した関係 N = 2/ψ − 1。
  • コンパクト度 C。 星がどれだけ押しつぶされているか：C = GM/(Rc²)。
  • 共形因子 ψ。 ある場所で、地図上の区間に実際どれだけの空間があるかを、非常に遠い場所と比べて表す数。質量の近くでは、同じ区間により多くの定規が必要です。
  • 状態方程式。 ある密度で物質がどれだけの圧力を生むか、つまりどれだけ「硬い」かを示す規則。
  • 一般相対性理論（GR）。 アインシュタインの重力理論。
  • ラプス関数 N。 ある場所の時計が、遠くの時計と比べてどれだけ遅く進むかを表す数。
  • M☉。 単位として使う太陽の質量。
  • 中性子星。 非常に強く押しつぶされた、死んだ星。太陽とほぼ同じ質量が、都市ほどの大きさの球に入っています。
  • NICER。 国際宇宙ステーションに載っている、パルサーの質量と半径を測る装置。
  • ポストニュートン。 ニュートンの重力への補正を段ごとに計算する仕方。
  • パルサー（PSR）。 規則的なパルスを発する、回転する中性子星。
  • 転回点。 星の系列に沿った質量の最大値。GR では、その点を超えると星は安定ではありません。ダイナミクスをもたない規則にとっては、指標にすぎません。
