1. 物質の外（真空中）での規則

では、ある厳密な数学的規則を見ましょう。この規則は、質量のまわりの何もない空間で成り立ちます。

物理学では、計量とは距離と時間の測り方を定める規則のことです。地図を思い浮かべてください。縮尺は、紙の上の一センチメートルが実際の何キロメートルにあたるかを教えてくれます。星の近くでは、重力が距離と時計の進みの両方を変えます。

時間とともに変わらない物体を考えます。これを静的といいます。形は完全な球です。これを球対称といいます。私たちは等方座標を使います。これは、各点ですべての方向に同じようにふるまう測定のグリッドです。形をつぶすことはありません。

このグリッドでは、定規は空間部分 ψ⁴(dr² + r²dΩ²) で表されます。ここで ψ（プサイ）は一つの数です。共形因子または奥行きと呼ばれます。これは、ある場所で地図の一区間に実際にどれだけの空間があるかを、非常に遠い場所と比べて示します。質量の近くでは、同じ区間を覆うのにより多くの定規が必要です。時計の進みは別の数 N で表されます。これはラプス関数、つまり進みと呼ばれます。その場所の時計が遠くの時計と比べてどれだけ遅く進むかを示します。便宜上、物理学者は重力定数と光速を 1 とおきます（G = c = 1）。

アインシュタインの一般相対性理論では、二つの式が成り立ちます。質量 M の外の何もない空間の、距離 r のところで成り立ちます。第一の式は ψ = 1 + M/2r です。第二の式は二つの数の積に関するもので、Nψ = 1 − M/2r です。この二つの式は調和です。調和関数とは滑らかな分布のことです。何もない点のどこにも盛り上がりをつくりません。空気の真ん中でヒーターが一つもついていない部屋の温度を思い浮かべてください。

ψ と Nψ を足しましょう。+M/2r と −M/2r の二つの項は打ち消し合います。残るのは次の式です。

ψ + Nψ = 2

この関係はシュヴァルツシルト計量で厳密に成り立ちます。これは、球形の質量のまわりの何もない空間についてのアインシュタインの解です。相対性理論は全質量を遠方から二通りに測ります。それらはモノポール M_ADM と M_Komar と呼ばれます。ここでは両者は同じ値 M を与えます。M_ADM = M_Komar = M です。

逆も、中心が一つの場合には成り立ちます。これは厳密な式で確かめられます。ψ = 1 + a/r をとります。進み N = 2/ψ − 1 を課します。これは ψ + Nψ = 2 の別の書き方です。すると、質量 M = 2a の等方的シュヴァルツシルト計量がちょうど得られます。太陽系では、重力のモデルを検証するために二つのパラメータが使われます。γ（ガンマ）と β（ベータ）と呼ばれます。この外部空間では、どちらも厳密に 1 です。γ = β = 1 です。

しかしこの規則は、球の形が失われる複数の質量の場合には拡張できません。点 x₁ と x₂ にある二つの質量で試してみましょう。ψ = 1 + a₁/|x − x₁| + a₂/|x − x₂| と書きます。この ψ はやはり調和です。しかし、ここで静的な進み N = 2/ψ − 1 を課します。すると、アインシュタインの真空方程式はもはや満たされません。曲率はリッチテンソルという数学的対象で測ります。真空ではこれはゼロのはずです。ところがここではゼロになりません。二つの質量の積に比例する残余（a₁a₂ のオーダー）が残ります。この残余は空間の開いた領域に存在します。二つの質量の一方を取り除いたときにだけ消えます。技術的な注：この二中心の ψ はブリル–リンドクィストの共形因子です。一般相対性理論では、時間対称な一つの初期時刻に静止している二つのブラックホールを表します。ここで成り立たないのは別のものです。静的な進み N = 2/ψ − 1 を時間的に固定したままにする読みです。

したがって、関係 ψ + Nψ = 2 は厳密な球対称のときにだけ成り立ちます。この研究の領域：静的、球対称、物体は一つ。

2. 五行で見るモデル

計算の前に、モデルの五つの構成要素を見ましょう。モデルはこれらを使って、カウントから空間をつくります。

  1. レジスタ。 レジスタはカウントのリスト c ∈ ℕ^K です。K = 4 個のカテゴリーに分かれています。各カテゴリー k には少なくとも一つのカウントがあります（c_k ≥ 1）。すべてのカウントの和が n です。具体例：4 列のノートです。列には、通り過ぎる車の色（赤、青、緑、黄）に応じて印をつけます。レジスタの状態は確率分布で表されます。これはディリクレ事後分布と呼ばれます。エビデンスの値 E(c) = log[(K−1)! ∏_k c_k! / (Σ_k c_k + K − 1)!] をもちます。エビデンスは、まさにそのカウントのリストを観測する確率がどれほどかを測ります。
  1. サンプリングとフィッシャー距離。 レジスタは一様にランダムに抽出されます。確率の空間（単体と呼ばれます）の上でフィッシャー測度を使います（Amari と Nagaoka 2000）。実際には、釣鐘曲線（ガウス分布 g）で 4 個の乱数を生成します。次に p = g²/|g|² を計算します。それから、多項分布と呼ばれる規則でカウントを抽出します。c = 1 + Multinomial(n − K, p) です。二つのレジスタの間の距離は定規では測りません。フィッシャー距離 d(p, p′) = 2 arccos Σ_k √(p_k p′_k) で測ります。二つのレジスタは、4 列の割合が似ていれば近くにあります。とても簡単に見分けられれば遠くにあります。統計的な区別のしやすさを距離として使う考えは Wootters（1981）にさかのぼります。情報幾何が物理的空間の幾何であるという考えは Caticha のものです（2005、2016、2019。第 9 節を参照）。
  1. レジスタ間のつながり。 二つのレジスタ i と j は重みで結ばれます。この重みは規格化されたベイズ重なりと呼ばれます。w_ij = exp[E(c_i + c_j) − ½E(2c_i) − ½E(2c_j)] です。この重みは、二つのレジスタが一つのカウントにどれだけうまく収まるかを測ります。各レジスタは自分自身との重みが 1 です（自己重み 1）。残すのは近くのレジスタの間のつながりだけです。近くとは、ゆらぎの典型的な幅の 3.5 倍以内という意味です。幅の一つ分は座標 2√(c/n) で 2/√n です。
  1. グラフ上の演算子。 つながったレジスタはネットワークをつくります。これはグラフと呼ばれ、道路で結ばれた町のネットワークのようなものです。ネットワークの上に数学的な演算子を定義します。これは値がノードから隣のノードへどう変わるかを測ります。規格化グラフラプラシアン L = I − D^(−1/2) a D^(−1/2) です。ここで W は重み w_ij の表です。d は W の行の和です。そして a = d⁻¹Wd⁻¹ です。D は a の行の和です。
  1. 静的な応答。 最も一様なレジスタに点状のソース δ を置きます。4 列がほぼ等しいレジスタです。時間的に動かない応答を求めます。方程式 L G = δ を、ソースのまわりの半径 0.7 の球（フィッシャー球）の中で解きます。この半径の外では G = 0 とおきます。値 0.7 は数値計算上の選択です。得られるポテンシャルは φ = D^(−1/2) G です。

このグラフは三次元の空間、つまりレジスタの状態の空間に存在します。なぜ三次元なのでしょうか。カテゴリーは K = 4 個です。しかし最初の三つの割合がわかれば、四つ目は決まります。実際、合計は 100 % でなければなりません。したがって 4 − 1 = 3 個の自由度が残ります。この抽象的な空間には距離があります。それを物理的空間の距離と同一視することは、枠組みの前提です。第 3 節の前提 P3 です。計算で証明された結果ではありません。

第 3 節では、同じ枠組みの三つの概念を加えます。レジスタの有効密度、線に沿って見たレジスタの像、レジスタの断片化です。第 7 節では別の試験系を使います。それはその節で説明します。

3. 数え上げの前提から数 ψ と N へ

では、重力の二つの数がカウントのレジスタからどのように読み取られるかを見ましょう。それは空間の奥行き ψ と、時計の進み N です。

はっきりさせるために、各ステップには角括弧のラベルをつけます。

  • [C] は、手または計算機で計算されたものを示します。
  • [P] は前提、つまり理論的枠組みが仮定する出発点を示します。
  • [S] は、いくつかの可能な代案の中から行った選択を示します。
  • [T] は、カウントと重力を結ぶ唯一の移行公準を示します。

このステップの連鎖全体は静的です。時間的に変わりません。その法則は読みの数 T が非常に大きいときに成り立ちます。これを多数の読みの極限といいます。1/T に比例する小さな補正があります。

3.1 基本的な恒等式 [C]

まず純粋に数学的な性質から始めましょう。二つの釣鐘曲線に関するものです。中心が同じ、ぼやけた二つの光の点を想像してください。それらは D 次元の空間にあります。二つの等方ガウス分布 p₀ と p_x で表されます。

  • 第一の分布の分散は s₀² です。分散はぼやけの幅の二乗です。これは遠方の観測者の分解能を表します。
  • 第二の分布の分散は s_x² です。これは観測されるその場所の分解能を表します。

二つの点の重なりは、それらの積の積分 Λ_ab = ∫ p_a p_b です。b から a の方を見た規格化された重なりは ℓ(a→b) = Λ_ab/Λ_bb です。二つの幅の比を q = s₀²/s_x² と呼びます。

計算の結果は次のとおりです。

  • ℓ(0→x) = (2/(1+q))^(D/2)
  • ℓ(x→0) = (2q/(1+q))^(D/2)

次元が D = 2、つまり平面のときに、注目すべきことが起こります。指数 D/2 は 2/2 = 1 になります。すると二つの重なりの和は次のようになります。 2/(1+q) + 2q/(1+q) = 2(1+q)/(1+q) = 2（q のどんな値に対しても）。

よく使われる別の統計的な道具があります。相対エントロピー、またはカルバック–ライブラー（KL）ダイバージェンスと呼ばれます。この道具では、二つの向きの和は定数になりません。KL(0‖x) + KL(x‖0) = (D/2)(q − 1)²/q です。この節の残りでは、二つの重なり ℓ がなぜ奥行き ψ と積 Nψ に対応するのかを述べます。

3.2 五つの前提 [P]

MM の枠組みの公理を示します。公理とは、証明されていない基本原理のことです。ここでは明確な形で書きます。

  • P1（時計）。 新しい読み、つまり新しいカウントが何度も届きます。そのたびに、ある場所のレジスタが少し更新されます。その場所の固有時とは、そこにとどまる時計が示す時間です。固有時は読みごとに、この小さな更新のフィッシャー長さだけ進みます。読みはどこでも同じ頻度で届きます。時間を統計的なゆらぎの大きさで測るのは、2011 年の Caticha の考えです（エントロピー的時間）。Ipek、Abedi、Caticha が 2018 年に、Ipek と Caticha が 2020 年にこれを局所的なものにしました。ただし彼らの研究では、進み N はすでに幾何から与えられています。ゆらぎを定めるのが進みなのです。ここでは向きが逆です。カウントが進み N を定めます。これは第 9 節で見ます。
  • P2（像）。 視点が二つあります。質量の近くの場所と、遠方の観測者です。二つは同じもの、つまり百分率での組成が同じレジスタを記述します。しかし集めた読みの数が違います。二つは像を見ることで自分たちの記述を比べます。像は、両者を結ぶ視線に垂直な平面に射影されたものです。遠くから見た球を思い浮かべてください。平らな円盤が見えます。したがって、この比較は二次元（D = 2）で行われます。
  • P3（距離）。 空間の物理的距離は、レジスタの断片化の尺度です。断片化は、レジスタのコピーがレジスタの状態の空間でどれだけ移動し広がったかを示します。
  • P4（質量）。 レジスタのコピーの数、つまりその倍数が、物体の質量です。いくつものコピーの効果は足し合わされます。
  • P5（吸収）。 コピーがある場所に届きます。そこで、二つの視点の共同状態、つまり一つにまとめられた状態に吸収されます。この共同状態は完全なままです。部分の合計は全体をなし続けます。

3.3 時計：N = τ₀/τ_x [C]

では、カウントの多い時計がなぜよりゆっくり時を刻むのかを見ましょう。

レジスタの有効密度は数 τ = T + 1 です。T は集めた読みを表します。+ 1 は出発時のカウント（事前の擬似カウント）を考慮したものです。新しい読みが届くと、レジスタの状態は平均してどれだけ動くでしょうか。水のタンクを思い浮かべてください。タンクに一リットルしかなければ、もう一杯のコップの水で水位は大きく変わります。これがカウントの少ない場合です。千リットルあれば、同じコップの水では水位はほとんど動きません。これがカウントの多い場合です。

新しい読みの平均ステップを、局所的なフィッシャー計量で計算しましょう。これは二乗平均平方根のフィッシャーステップです。レジスタの百分率組成がどうであっても、ちょうど √(K − 1)/τ になります。K = 4 個のカテゴリーについて、式による計算は厳密です。計算機シミュレーションでは 0.23 % 以内で成り立ちます。すべての組成について 0.35 % 以内で同じです。有限のフィッシャー–ラオ距離も、どのカテゴリーにも多くの読みが入っているときには一致します。

場所 x の時計のステップを、遠方の観測者 0 のステップと比べましょう。場所 x の密度は τ_x です。遠方の観測者の密度は τ₀ です。二つのステップの比は τ₀/τ_x です。これは計算機で 0.3 % 以内で確かめられています。組成が等しいときは、ディリクレ分布の分散の比も、ちょうど同じ結果を与えます。

ここで前提 P1 を使います。遠くの時計と比べたその場所の時計の進みが、ラプス関数 N です。そしてそれはちょうどこの比です。

N = τ₀/τ_x

読みが多いところでは τ_x は大きくなります。すると読みごとのステップは小さくなります。そしてその場所の時計はよりゆっくり進みます（N < 1）。この法則の形を見ましょう。進み N は、遠くで測った量と、その場所で測った同じ量の比です。この形は、熱の物理学で有名なトルマン–エーレンフェスト関係 T_loc N = T_∞ と同じです（Tolman と Ehrenfest 1930）。ここでは温度 T の代わりに、読みの密度 τ があります。

3.4 奥行き：ψ = 2τ_x/(τ_x + τ₀) [C、多数の読みの極限]

では第二の数 ψ を計算しましょう。二つのレジスタの像を平らなスクリーン上で比べて計算します。

二つのレジスタの確率分布 Dir(τp) をとります。フィッシャー座標 y = 2√p を使います。それらを、その場所と遠方の観測者を結ぶ視線に垂直な平面に射影します。前提 P2 がこれを求めています。次に、その場所から遠方の観測者の方を見た規格化された重なり L⊥(x→0) = ∫f_x f₀ / ∫f₀² を計算します。

計算は、射影された真のディリクレ像について行いました。像は計算機でサンプリングしたもので、ガウス近似の式は使っていません。結果は式 2τ_x/(τ_x + τ₀) と一致します。

  • 遠方の観測者の読みが T₀ = 100 のときは 0.44 % 以内で一致します。
  • T₀ = 300 のときは 0.10 % 以内です。
  • T₀ = 1000-3000 のときは 0.03-0.04 % 以内です。

差は 1/T のオーダーの小さな補正です。結果は 0.1 % 以内で視線の方向によりません。それだけではありません。互いに逆向きの二つの向きの比 ∫f₀²/∫f_x² は τ₀/τ_x に近づきます。こうして第 3.3 節と同じ進み N が、独立な第二の道筋で再び得られます。では平面に射影しなかったらどうでしょうか。状態の三次元空間全体で重なりをとったらどうでしょうか。その場合、式は変わります。指数が 1 ではなく 3/2 になります。

[S] 明示された選択。 空間の奥行き ψ を、その場所から見た方向つきの重なりと同一視します。ψ = 2τ_x/(τ_x + τ₀) です。二つの視点を同じように扱う対称な式をなぜ使わないのでしょうか。対称な比較では、どちらの読みが多く、どちらが少ないかを区別できないからです。数学的には、それは相対差 z = (τ_x − τ₀)/(τ_x + τ₀) の偶関数です。対称な式では、一次の範囲で空間の曲がりが見えません。γ = 0 になってしまいます。観測がこれに反するので、これは成り立たない読みです。そこで方向つきの重なりを選びます。これは読みの超過に線形に応答し、プラスの符号とマイナスの符号を区別します。

3.5 一つの共同カウントの二つの取り分 [C]

では N と ψ を組み合わせましょう。規則 ψ + Nψ = 2 がどんな単純な意味をもつかを見ます。

第 3.4 節で見た多数の読みの極限にとどまります。二つの数を 2 で割ります。

  • ψ/2 = τ_x/(τ_x + τ₀) は場所 x の読みの割合です。二つの視点の共同の総数（τ_x + τ₀）の中の、場所 x の取り分です。
  • Nψ/2 = (τ₀/τ_x) · τ_x/(τ_x + τ₀) = τ₀/(τ_x + τ₀) は遠方の観測者 0 の読みの割合です。同じ総数の中の、遠方の観測者の取り分です。

架空の数での例です。二人の子どもがシールを持ち寄って共同のアルバムをつくります。一人目がシールの 60 % を入れました（ψ/2 = 0.60）。すると二人目は残りの 40 % を入れたことになります（Nψ/2 = 0.40）。二つの取り分の和は 1、つまりアルバムの 100 % です。2 を掛けましょう。ψ + Nψ = 2 が言っているのはこれだけです。二つの取り分の和は一になる、ということです。

これが、シュヴァルツシルト関係について提案する読みです。物質の外でも物質の中でも成り立ちます（第 4 節）。第 11 節では、これを交換の保存則としても読みます。等方座標では、空間の幾何学的な形は平坦です。空間の計量の情報はすべてスケール因子 ψ の中にあります。これはまさに、情報幾何だけでは自由なままだった局所スケールです（Caticha 2016；第 9 節）。

3.6 ソース：断片化が 1/r のふるまいを与える [C]

ここまで、ある場所の読みの密度 τ_x について話してきました。しかし、なぜ質量の近くでは読みが多いのでしょうか。そしてなぜこの超過はちょうど 1/r、つまり距離の逆数で減っていくのでしょうか。

K = 4 個のカテゴリーをもつレジスタの断片化を追います。コピーは離れていきます。読みごとに精度を失っていきます。この過程は、三次元のフィッシャー空間の等方ブラウン運動とちょうど同じようにふるまいます。ブラウン運動とは、あらゆる方向への小さな歩幅のランダムウォークです。水の分子にぶつかられる花粉の粒を思い浮かべてください。このウォークの内部時計 s は、フィッシャーステップの二乗の和です。

テストでは計算機でシミュレーションした 60,000 本のチェーンを使います。運動は 1.8-5 % 以内ですべての方向で同じ（等方的）です。各方向の分散は 1.4 % 以内で s に等しくなります。

各ステップで、コピーがその場所に残すものに重みをつけます。重みは失われた精度 Δs です。すると、ソースから距離 r のところに堆積する量は法則 1/(2πr) − B に従います。計算の規約を固定すれば、手で調整するパラメータはありません。規約とは、フィッシャー座標、時計 s、接する空間のユークリッド体積、最小の停止閾値 n_min です。この幾何学的な計算は、メートルやキログラムのような物理単位での G の値を与えません。距離 r = 0.005 から r = 0.04 の間で、シミュレーションの点を式と比べます。比の平均は 0.998 です。どの距離のバンドも 3 % を超えてずれません。定数 B は、カウントが尽きると断片化が止まることから生じます。これは最大時間 s_max で起こります。プロファイル全体は関数 [1/(2πr)] erfc(r/√(2s_max)) で表されます。

数学では、1/(2πr) は三次元のブラウン運動のグリーン関数です。3D 空間のランダムウォークが残す平均の痕跡です。MM の枠組みが加えるのは一つのことです。4 カテゴリーのレジスタの統計的な断片化が、まさにその歩幅で、そのブラウン運動とちょうど同じようにふるまう、ということです。

[S] 明示された選択。 明示された選択は二つあります。レジスタがカウントを失う仕方と、堆積に与える重み Δs です。以前のテストでは、各読みは Δs なしで同じ重みをもっていました。そのテストは登録済みの傾き 1/r に届かず、その読みは成り立たなくなりました。前提 P3 により、レジスタの空間の距離 r は物理的距離です。前提 P4 により、n 個のコピーは n 倍の量を堆積させます。

3.7 物理学との接合：公準 T [T]

これで部品はそろいました。最後の橋が欠けています。ステップ 3.3-3.6 には、断片化が堆積させた尺度を、定数 G を含む物理的な数 ψ にどう変換するかを述べるものが何もありません。この変換は公準であると公然と宣言します。

公準 T（移行）。 各堆積は、遠方の観測者からその場所へカウントの取り分を移します。ψ − 1 = Σᵢ wᵢ です。距離 rᵢ にある各質量 mᵢ について、移される取り分は wᵢ = Gmᵢ/(2rᵢc²) です。係数は実験で較正します。定数 G は測定されるのであって、計算されるのではありません。取り分は常に正のままです（Σᵢ wᵢ < 1）。質量 M の物体が一つだけの場合は、半径 r > GM/(2c²) の外にとどまる必要があります。

公準 T の動機は前提 P5 にあります。吸収されたコピーは、実際、完全なままの共同状態の部分を配分し直します。しかし公準 T は必ずしも P5 から導かれるわけではありません。カウントを足して総数を計算し直しても、やはり完全な状態が得られます。

公準によって移される量は、等方半径 r で書いて w = GM/(2rc²) です。一次では −Φ/2c² と一致します。一次とは、質量から遠く、場が弱いという意味です。ここで Φ = −GM/r はニュートンの重力ポテンシャルです。

Erik Verlinde は創発重力についての有名な論文を書きました。その最初の版（プレプリント：2010 年の arXiv:1001.0785v1、式 3.16 と第 4 節）には、まさにこの量 −Φ/2c² があります。そこでは情報のビットごとの細部の損失を測っています。これは coarse graining（粗視化）と呼ばれます。0 から 1 の間の数です。ブラックホールの事象の地平面の上でだけ 1 になります。

学術誌に掲載された版（JHEP 04 (2011) 029、式 3.12 と第 4 節）では、Verlinde は同じものを −2Φ/c² と書いています。これは面積座標と呼ばれる標準的な座標で地平面の上で 1 になります。その座標では、地平面の半径は r = 2GM/c² です。一方、私たちの等方座標では、ブラックホールの地平面は r = GM/(2c²) にあります。そしてちょうどそこで、私たちの取り分 w は 1 に達します。このとき ψ = 2、N = 0 となり、時計は止まります。この正確な値は、公準 T を等方半径で書くという選択から来ています。最初の近似を超えて Verlinde の式と恒等であることから来ているのではありません。

公準 T では、なぜ読みの超過の尺度としてちょうど ψ − 1 を選んだのでしょうか。読みの超過 (τ_x − τ₀) は、四つの自然な仕方で参照値と比べることができます。そのすべてに同じことを求めます。遠距離でニュートンの重力を与えなければならない、ということです。つまり u = GM/(rc²) に比例させます。表は四つの選択それぞれで何が起こるかを示します。

3.8 公準 T から導かれること [C]

公準の直接の帰結を見ましょう。まず物体が一つの場合、次に二つの場合です。

  • 物体が一つ。 ψ = 1 + GM/(2rc²) です。取り分は完全です（第 3.5 節）から、N = 2/ψ − 1 です。これはちょうど等方的シュヴァルツシルト計量です。γ = β = 1 が成り立ちます。質量の外では、軌道は一般相対性理論のものです（プログラム perielio.py が計算します）。たとえば水星の近日点の移動は同じ結果になります。
  • 物体が二つ。 和 ψ = 1 + Σᵢ Gmᵢ/(2rᵢc²) は、アインシュタインの真空方程式の一つを厳密に満たします。ハミルトニアン拘束と呼ばれるものです。ある時刻の空間の曲率を支配します。これは Brill と Lindquist（1963） の有名な初期データ、つまり一瞬静止した二つのブラックホールです。重要な注：読み S1 では、この拘束は満たされないでしょう。S1 は取り分ではなく生のカウントを足します。
  • 二つの物体は静止したままではいません。 進みの規則 N = 2/ψ − 1 を物体が二つの場合に拡張しましょう。すると静的な真空方程式の全体は満たされません。空間のテンソル E_ij = R_ij − D_iD_jN/N はゼロではありません。物理学的には、これは当然のことです。一般相対性理論でも、静止させて放した二つの質量は静止したままではいません。互いに向かって落ち始めます。したがって静止した二つの物体は、最初のスナップショットにすぎません。そのあとはすべてが時間的に変化しなければなりません。ここで E_ij は直接に測定される力ではありません。そして私たちの静的な連鎖は、運動の法則、つまり力学をまだ含んでいません。

3.9 第 3 節のまとめ

何をしたのか、何をしていないのかを正直にまとめましょう。この研究では、シュヴァルツシルト計量はゼロから導かれていません。それは公準 T を通して入ってきます。断片化の 1/r のふるまい（第 3.6 節）と対応の選択 S4 とともに入ってきます。数え上げの連鎖が本当に与えるのは次の三つです。

  1. 二つの量の数学的な形：密度の比としての N、取り分としての ψ。
  2. 次のように読まれる関係 ψ + Nψ = 2：ある総数の二つの取り分の和は一になる。
  3. レジスタのブラウン的な断片化が生み出す 1/r の法則。

4. 物質の中：現象論的な閉包であり、まだ理論ではない

ここまで星の外の何もない空間にとどまってきました。では星の物質の中に入りましょう。規則 ψ + Nψ = 2 がそこでも成り立つとしたら、何が変わるかを見ます。

第 3 節の読みでは、この関係は一つのことを言っています。共同カウントの二つの取り分の和は一になる、ということです（第 3.5 節）。これを物質の中でも有効に保つことは、この完全性を一点ごとに課すことを意味します。星のガスの真ん中でもです。

まず通常の一般相対性理論が何をするかを見ましょう。静的な星を等方座標でとります。主な方程式は二つあります。その中で ρ は物質の質量エネルギー密度、p は流体の圧力です。

  1. 空間についてのハミルトニアン拘束：∇²ψ = −2πρψ⁵。
  2. 時間についてのラプス方程式：∇²(Nψ) = 2πNψ⁵(ρ + 6p)。

記号 ∇² はラプラシアンと呼ばれます。ある点の値が近くの点の平均からどれだけずれているかを測ります。二つのアインシュタイン方程式を足しましょう。次の式が得られます。

∇²(ψ + Nψ) = 2πψ⁵[N(ρ + 6p) − ρ]

星の中では、この結果はゼロではありません。小さいけれども存在する量で、ポストニュートン一次のものです。では、この効果を星の体積全体で足し合わせましょう。数学では体積積分をとるといいます。ある定理（発散定理）により、結果は表面を通る流束になります。それは ψ と N の遠方でのふるまいだけで決まります。ψ → 1 + M_ADM/2r、N → 1 − M_Komar/r です。次の式が得られます。

∫ ∇²(ψ + Nψ) d³x = 4π(M_Komar − M_ADM)

一般相対性理論では、どの静的な星でも、二つの全質量 M_Komar と M_ADM は厳密に等しくなります。Beig が 1978 年にこれを証明しました。Tolman 1930 も参照してください。したがって、この全積分はゼロです。簡単に言うと、一般相対性理論では、星の中の和 ψ + Nψ は一点ごとには 2 にとどまりません。しかし星全体で足し合わせると、効果は打ち消し合います。物質の中で ψ + Nψ = 2 を保つことは、一般相対性理論が星全体について全体としてしか保証しないことを、一点ごとに課すことを意味します。

変数の選択は仮定である

この規則は等方因子 ψ について書かれています。つまり空間の計量は ψ⁴δ_ij という形をしています。これは明確な選択であり、仮定です。通常の面積座標では、真空中の類似の性質は g_tt g_rr = −1 になります。Jacobson が 2007 年にこれを研究しました。この式を物質の中で課すと、異なる結果になるでしょう。

何を置き換え、何を代償とするか

私たちのモデルは星の中で次のようにはたらきます。

  1. ハミルトニアン拘束 ∇²ψ = −2πρψ⁵ を保ちます。
  2. アインシュタインのラプス方程式を、代数的な規則 N = 2/ψ − 1 で置き換えます。
  3. 流体の圧力を、エネルギーと運動量の保存則からとります。この法則は、星のどの層も崩壊せずにつり合っていなければならないことを述べます。dp/dr = −(ρ + p) d ln N/dr です。

この一手の代償は何でしょうか。流体の圧力は、重力場を生み出す方程式にもはや入りません。 物質の中の幾何は、アインシュタイン方程式が要求するようには、もはや流体によって全面的に生み出されません。このため物質の中では、この提案は静的な方程式の現象論的な閉包です。現象論的な閉包とは実用的な規則です。方程式の系を閉じ、計算を可能にします。まだ完全な理論ではありません。

理想的な星、つまり密度が一様で ρ がどの点でも同じ星について数値を見ましょう。

  • アインシュタインテンソルの時間に関わる部分は、ちょうど密度を与えます。−G^t_t/8π = ρ です。
  • 一方、空間に関わる部分は流体の圧力 p を与えません。星の中心で、幾何は流体の圧力の約半分を*見ます*。弱い場では G^r_r/8π = G^θ_θ/8π ≈ 0.50 p_c です。
  • 表面に向かうと、差は非等方的になります。つまり方向によって変わります。動径方向（外向き）と接線方向（表面に沿う向き）で異なります。接線方向の部分は正です。

相対論の物理学者がこの星をアインシュタイン方程式で読むとします。するとこう言います。星の中には、通常の流体のほかに余分な非等方応力がある、と。この応力はそれだけで保存されます。そしてエネルギー密度はゼロです。

これは星の物理学の有名な限界に関わります。星はブラックホールに崩壊する前に、どこまでコンパクトになれるのでしょうか。コンパクト度は比 C = GM/(Rc²) で測ります。ここで M は星の質量、R は半径です。

  • 1959 年に Buchdahl は限界を証明しました。一般相対性理論で、等方的な完全流体で、密度が外に向かって増加しない場合に成り立ちます。コンパクト度は決して C = 4/9 ≈ 0.4444 を超えられません。超えれば中心の圧力が無限大になってしまいます。
  • 2008 年に Andréasson はより一般的な定理を証明しました。非等方的なものも含め、どんな静的な球状の物質にも成り立ちます。非等方的な球は 1974 年に Bowers と Liang が研究していました。常に 2m/r ≤ 8/9、つまり C ≤ 4/9 が成り立ちます。ただしエネルギーについて二つの条件が必要です。動径方向の圧力が負でないこと：p_r ≥ 0。圧力の和が密度を超えないこと：p_r + 2p_t ≤ ρ。

そこで、コンパクト度が 4/9 より大きい私たちのモデルの星をとりましょう。それを一般相対性理論で読むと、Andréasson の二つの条件の一方を破らなければなりません。余分な非等方応力を通して破ります。したがって物質の中では、このモデルは一般相対性理論に単純な仮説を一つ足したものではありません。

最大コンパクト度の限界を一つの式で

固有密度が一様な星をとります。ハミルトニアン拘束は天体物理学で知られた方程式になります。指数 n = 5 のレーン–エムデン方程式です。これは式 ψ = ψ_c(1 + br²)^(−1/2) で厳密に解けます。ここで ψ_c は中心での値です。表面（r = R）で内部と何もない外部空間をつなぎます。ψ_R = ψ_c^(2/3) が得られます。

可能な星の族は、中心が取り分の最大値 ψ_c = 2 に達したところで終わります。これは N_c = 0、つまり星の中心で時間が止まっていることを意味します。そこで最大コンパクト度はちょうど次の値です。

C_max = GM/(Rc²) = 2^(1/3) − 2^(−1/3) ≈ 0.4662。これに対してブーフダール限界は 4/9 ≈ 0.4444 です。

実際の星のコンパクト度では何が起こるか

違いを見るのに極限まで行く必要はありません。天文学者は典型的なコンパクト度 C = 0.16、0.19、0.22 の中性子星を観測しています。これらのコンパクト度をもつ一様密度の星をとります。私たちのモデルが星を支えるのに必要な中心の圧力は、一般相対性理論のものより低くなります。それぞれ 7.4 %、9.3 %、11.4 % 低くなります。

もちろん、中心から地殻まで同じ一様な密度というのは、実際の中性子星としては現実的ではありません。核物質の現実的な状態方程式を使うことはできます。そうすると、星の質量と半径を結ぶ曲線はずれるでしょう。このずれの計算は研究の次のステップです。ここではまだ行っていません。中心から外に向かって減少する他の密度プロファイルは、同じ著者の別のレコード MM 2.34（Zenodo）で研究されています。エネルギー条件もそこで研究されています。

10. 動く時計（展望；バージョン 2.36.1 で追加）

では重力を離れましょう。コピーの数え上げが、平坦な空間で速い時計が遅くなることにどのように理由を与えるかを見ます。

第 3 節では、質量の近くに静止している時計について話しました。今度は一定の速さで動く時計をとりましょう。重力のない平坦な時空を動きます。ここではカウントに基づく読みが、アインシュタインの特殊相対性理論の時間の遅れを生み出します。

時計の出発の事象と到着の事象を想像してください。この二点の間に、光線が四辺形を描きます。これは光のダイヤモンド、または因果ダイヤモンドと呼ばれます。光の方向に沿ったダイヤモンドの二つの辺は a = cΔt − Δx と b = cΔt + Δx です。ここで Δt は実験室で経過した時間です。Δx は時計が進んだ距離です。

ここで MM の枠組みのさらに二つの前提がはたらきます。

  • P6（第二のつながり）。 運動の基本的な一歩では、光の辺に沿った二つのカウントは互いに素です。二つの整数は、3 と 5 のように 1 以外の公約数をもたないとき互いに素です。コピーはそれらの公倍数のところで生まれます。したがって辺が a と b のダイヤモンドには、積 ab = gcd(a, b)·lcm(a, b) に等しい数のセルが含まれます。ここで gcd は最大公約数、lcm は最小公倍数です。
  • P7（あらかじめ割り当てられた場所がない）。 空間の場所は、コピーが届く前には存在しません。あらかじめ固定された場所のグリッドは、特別な基準系、つまり動かない*エーテル*を定めてしまいます。そこで計算機シミュレーションでは、コピーを時空の体積の中に独立にランダムに分布させます。これは実用上の仮定です。前提 P7 はその動機を与えますが、数学的な意味で課すわけではありません。

[S] 明示された選択。 動く時計はダイヤモンドの中のコピーの数を読みます。光の互いに逆向きの二つの向きを掛け合わせて組み合わせます。これが積の規則です。したがって動く時計が示す時間は積の平方根 √(ab) です。一方、実験室に静止した時計の時間は二つの辺の平均 (a + b)/2 です。

数学にはとても単純な規則があります。算術平均は常に幾何平均より大きい。 唯一の例外は二つの辺が等しい場合（a = b）、つまり静止した時計です。そして二つの平均の比は、ちょうどアインシュタインの時間の遅れの因子です。 私たちが選んだ数での例です。a = 2、b = 8 とします。算術平均は (2 + 8)/2 = 5 です。幾何平均は √(2 × 8) = √16 = 4 です。実験室で 5 が経過する間に、動く時計は 4 を示します。式で書くと次のようになります。

√(ab) / ((a + b)/2) = √(1 − v²/c²)

時計が光の格子の上で一歩ずつどう進むかを見ましょう。静止した時計は (1, 1) の対称なステップをとります。辺 a と b が互いに素なステップは分割できません。(0, 0) から (a, b) への線分は、その内部にちょうど gcd(a, b) − 1 個の格子点を含みます。最大公約数が 1 のとき、内部の点はゼロです。これは 3600 組の数について例外なく確かめられました。動く時計は基本ステップごとに空間を (b − a)/2 だけ進みます。

登録済みの結果についての注。 テスト M1 から M5 を実行する前に、厳しい全体基準が定められていました。M1 と M5 の一方でも閾値に届かなければ、鎖のカウントによって時間の遅れが確かめられたとは見なさない、というものです。この全体基準は満たされませんでした。3+1 次元のテスト M5 は、速さ v = 0.8 で固定された許容誤差 6 % を超えました。理由は、細いダイヤモンドに残るコピーの数が約 780 個と少ないことです。一方、同じ固有時、つまり同じコピーの数での比較は合格しました。有限サイズの効果の分析は、結果を見たあとで行いました。

11. 交換としての関係と、到達確率としての堆積（バージョン 2.36.2 で追加）

この節では二つのステップを踏みます。第一に、規則 ψ + Nψ = 2 を連続的な交換として読みます。この交換は遠方の観測者の測定単位を守ります。第二に、移された取り分 w を到達確率として読みます。

11.1 この関係が二次で定めるもの [C]

11.2 交換としての読み [P, S, C]

物理学では、なぜちょうど積 (1 + w)(1 − w) = 1 − w² が現れるのでしょうか。これに理由を与える著者の前提を示します。

[P] 前提 P8（交換）。 光は記述の配置の変化です。基準となる遠方の観測者の読みの単位は安定しています。それを安定に保つために、記述の分数部分は連続的に量子を交換します。量子とは基本的なパケット、つまりその単位の分数です。

[S] 明示された形式化。 前提 P8 を三つの同一視によって式に翻訳します。

  1. 分数を交換する二つの部分は、第 3.5 節の二つの取り分 ψ/2 = (1 + w)/2 と Nψ/2 = (1 − w)/2 です。それぞれが w/2 だけ、互いに逆向きに動きます。一方は w/2 増え、他方は w/2 減ります。
  2. 遠方の観測者の単位は安定しています。これは二つの取り分の和が一定のままであることを意味します。ψ + Nψ = 2。
  3. 光は配置の変化です。時間と長さの局所単位の積を読みます。Nψ² = ψ · Nψ です。

[C] 帰結。 この三行から直ちに Nψ² = (1 + w)(1 − w) = 1 − w² が導かれます。第 11.1 節で観測が要求した項 −w² は、こうして生じます。固定された和を積を通して読むことからです。特に、二つの取り分が統計的に独立であるとは仮定していません。確率論では、二つの事象は独立なときに掛け合わされます。ここでは逆に、二つの取り分は最も強く従属しています。一方が渡すものは、ちょうど他方が受け取るものです。

それだけではありません。二つの取り分の比 ψ / (Nψ) = 1 / N は、ちょうど 1 + z と一致します。これは、その場所で放射され遠くで受け取られる光の重力赤方偏移（redshift）です。数 w は二つの取り分の間の不均衡を測ります。これは移された割合 w/2 の二倍です。次の項で見るように、理想的なブラウンモデルでは w は到達確率でもあります。

論理的な位置づけ。 P8 は前提です。三つの同一視はその明示された翻訳です。第 3.5 節と同様に、二つの取り分の和は構成上一になります。P8 はこの事実を交換として読みます。しかしここでは運動方程式、つまり交換が時間の中でどう起こるかの力学は与えません。この読みを星の中で一点ごとに保つと、第 4 節の閉包が再び得られます。

11.3 到達確率として読む堆積 [C]

では、重力と、ランダムウォークが標的に当たる確率とのつながりを見ましょう。

三次元空間のブラウン運動をとります。決して止まらずに歩きます。半径 ε の小さな標的の球から距離 r のところ（r ≥ ε）で出発します。遅かれ早かれその小さな球に触れる確率はどれほどでしょうか。古典的な定理が答えます。Kakutani 1944 で、ℝ³ の正則な標的について成り立ちます。この到達確率はちょうど ε / r です。

この式を、第 3.6 節の堆積 1/(2πr) と比べましょう。二つの数の違いは固定された定数 2πε だけです。では公準 T（第 3.7 節）を見ましょう。移される取り分は w = GM/(2rc²) であると述べています。取り分 w が、すべての距離 r について到達確率 ε/r とちょうど一致するのはいつでしょうか。標的の半径が次の値のときです。

ε = GM / (2c²)。これはちょうど、等方座標でのブラックホールの地平面の半径です。

したがって公準 T の係数は、ちょうど等方的な地平面の半径です。太陽では約 738 m です。地球では 2.2 mm です。それらは物体の中心にある仮想の標的です。平坦な幾何（ユークリッド計量 δ）を基準にとりましょう。それに対して、関数 w = ε/r は調和です。地平面の球 r = GM/(2c²) の上で 1 です。無限遠で 0 に落ちます。したがって w は、平坦な空間のブラウン経路が地平面の球に達する厳密な確率です。

では、ブラウン運動が星やブラックホールの空間の曲がった幾何の中を歩くとしたらどうでしょうか。この幾何は計量 ψ⁴δ で表されます。その曲がった空間では、ブラウン運動の演算子は ½Δ_g です。そこでは関数 w はもはや調和ではありません。実際、Δ_g w = 2ψ⁻⁵|∇w|² であり、ゼロではありません。では曲がった幾何で、地平面の上で 1、無限遠で 0 となる調和関数は何でしょうか。計算すると 1 − N = 2w/(1 + w) です。

1 − N は地平面に落ちる確率です。すると、その一に対する補数、つまり N は明確な意味をもちます。 時計の進み N（ラプス関数）は、空間の曲がった幾何の中のブラウン経路が、地平面に一度も触れずに無限遠へ逃げる確率です。

一般相対性理論では、静的な真空のラプス関数 N が空間の計量で調和関数であることが知られています。これは深い数学的性質です。たとえばブラックホールの一意性定理の証明に使われます（Bunting と Masood-ul-Alam 1987）。そして Bray の有名な質量–容量不等式（2001）で地平面の*容量*を定めます。手短に言うと、次のようになります。

  • ユークリッドの読み、つまり平坦な読みでは、不均衡 w が地平面に到達する確率です。
  • 空間の曲がった読みでは、N が無限遠へ逃げる確率で、1 − N が地平面に到達する確率です。

これらの主張は何もない外部空間（r ≥ GM/(2c²)）で成り立ちます。地平面は吸収境界として扱います。そして経路には無限の時間があります。太陽や地球のような通常の物体では、地平面は物質の中に埋もれているはずです。そこでは標的は仮想のものにすぎません。この読みは理想化された外部の場を記述します。

12. よくある質問への回答（予想される質問）

注意深い読者が抱きそうな批判的な質問を七つ挙げます。それぞれに直接の回答をつけます。

  1. 重なりはどの分布の間で計算するのですか。なぜ相対エントロピーを使わないのですか。

その場所の分布と遠方の観測者の分布、つまりディリクレ分布の間で計算します。それらを、両者を結ぶ視線に垂直な平面に射影します（第 3.4 節）。読みが多いと、これらの点は丸く（等方的に）なり、幅は 1/τ です。規格化された重なりを使うのは、互いに逆向きの二つの向きの和が固定された定数、平面では 2 になるからです。一方、相対エントロピーでは和は点ごとに変わります（第 3.1 節）。その場所から見た向きをとるのは、明示された選択です。

  1. 物質の外では、規則 ψ + Nψ = 2 は自明な帰結にすぎないのではありませんか。真空中のラプラス方程式は線形です。

そのとおりです。 物質の外では、この関係は真空中の一般相対性理論の単純な性質です。モデルの新しい物理的内容は物質の中にあります（第 4 節）。

  1. 一般共変な形、つまりどんな座標系でも有効な形はどれですか。一般に、ψ と N はどの量から読み取るのですか。

今のところ一般共変な形はありません。ただし、私たちの限られた領域、つまり静的で球対称な領域では、ψ と N は曖昧さなく定義されています。N は静的な時間の流れを示す静的キリングベクトルの長さ（ノルム）です。ψ⁴ は空間の計量のスケール因子です。実際、球対称な三次元空間はどれも、平坦なグリッドに因子 ψ⁴ を掛けたものとして書けます。

  1. 物理的空間は三次元なのに、なぜ重なりの式で D = 2 次元を使うのですか。

比較が、視線に垂直なスクリーンに射影された像の上で行われるからです（前提 P2）。状態の三次元空間全体では指数 3/2 が現れます。すると和はもはや 2 になりません（第 3.4 節）。この研究は、この重なりを直接測定する実験室の装置を特定していません。

  1. 星の中ではどのアインシュタイン方程式を捨てるのですか。エネルギー条件はどうなるのですか。

一般相対性理論のラプス方程式を捨てます。ハミルトニアン拘束は保ちます。圧力は静水圧平衡、つまり保存から得ます。このため流体の圧力はもはや重力場を生み出しません。一般相対性理論の眼鏡を通して見ると、星には余分な非等方応力があります。コンパクト度が 4/9 を超えると、この応力は Andréasson（2008）の条件 p_r ≥ 0 または p_r + 2p_t ≤ ρ の一方を破らなければなりません。一様密度の星では、それでも流体の圧力は正のままです。そして中心から表面へなめらかに減少します。エネルギー条件はレコード MM 2.34 で詳しく研究されています。

  1. 公準 T では、なぜ S3 ではなく規格化 S4 を選ぶのですか。

どちらも γ = β = 1 を与えるので、今日の太陽系のテストに合格します。しかし S4 はすべての次数でシュヴァルツシルト計量を正確に再現します。一方、S3 は三次でそれからずれます。S4 の選択は、一般相対性理論を外部の指針となる基準として使っています。MM の前提が課すものではありません。

  1. 推論は循環していませんか。つまり、最後に見つけるためにシュヴァルツシルトを最初に入れているのではありませんか。

シュヴァルツシルトが入る点は公然と宣言されています。公準 T と選択 S4 で入ります（第 3.7 節）。連鎖の他のステップはすべて数学的な形を計算します。密度の比、二つの視点の間の取り分、ブラウン運動による 1/r の堆積です。これらの形は重力の計量を含んでいません。
