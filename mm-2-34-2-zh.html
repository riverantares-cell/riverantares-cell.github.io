简而言之

什么是致密星

恒星靠自身的引力维系在一起。恒星内部物质的压强向外推，使恒星保持平衡。中子星是一颗死亡的恒星，被压得非常紧。它的质量大约与太阳相当，却集中在一个城市大小的球体里。

致密度 C 说明一颗恒星被压得有多紧。它用比值 GM/(Rc²) 来计算。这里 M 是质量，R 是半径，G 是引力常数，c 是光速。质量越大、半径越小，C 就越大。

Buchdahl 极限

在爱因斯坦（Einstein）的广义相对论（我们写作 GR）中，有一个著名的极限。Buchdahl 在 1959 年发现了它。它对这样的恒星成立：静态（也就是静止不动）、由理想流体构成、密度不向外增加。这样的恒星不可能比 4/9 更致密。超过这个值，中心压强就必须是无穷大。

一条不同的规则

这项工作研究静态球形恒星内部的一条不同规则。这条规则把两个数联系在一起。

  • 时移函数 N 说明时钟的快慢。在质量附近时钟走得更慢：N 小于 1。
  • 各向同性共形因子 ψ 说明地图上的一段实际上有多少空间：在质量附近，需要更多的直尺才能铺满同样的一段。

这条规则是：

N = 2/ψ − 1。

对真空中的单个球形物体，这个关系精确成立。它是施瓦西（Schwarzschild）度规的一个性质，也就是爱因斯坦关于球形质量周围空旷空间的解，用各向同性坐标写出时的性质。

把它也强加在物质内部，只会改变方程中的一件事：压强不再是时移函数的源。在 GR 中，压强对引力有贡献，有点像质量。在这里，对时钟的快慢来说，它不再有这种贡献。

我们用爱因斯坦方程来解读由此得到的度规。这时，看起来就像有流体再加上一个额外的应力，称为各向异性有效应力。各向异性的意思是它在各个方向上并不相同。

物质内部与 GR 的差别很小，量级为 p/ρ。这里 p 是压强，ρ 是能量密度。在普通恒星中 p/ρ 极小。这就是差别只在中子星中出现的原因。

结果

  • 对均匀密度（也就是处处相同的密度），恒星序列终止于致密度 2^(1/3) − 2^(−1/3) ≈ 0.466。这是一个精确公式。在 GR 中，极限则是 4/9 ≈ 0.444。如果密度向外减小，最大值会更低（见后面的表）。
  • 对均匀密度，在致密度 0.15 到 0.23 之间，中心所需的压强比 GR 低 7–12%。
  • 用两个现实的核状态方程，最大质量上升约 5%。半径变化约 0.1 km。这小于 NICER 测量目前的误差。用这两个状态方程，GR 和这条规则都与恒星 PSR J0437−4715 相容。对恒星 PSR J0740+6620，二者给出的半径都低于 Salmi 等人的 68% 区间。

这条规则是一个假设，不是推导。它也还不是一个理论：没有作用量，也没有动力学。 作用量是一个公式，一个理论的所有方程都由它得出。动力学说明事物如何随时间变化。

为什么是这条规则

在真空中，对单个物体，时移函数只取决于各向同性共形因子：N = 2/ψ − 1。施瓦西度规只通过 M/r 依赖于质量。所以同一个公式对每个质量 M 都成立。

这项工作的假设是，同一个公式在物质内部也成立。在 GR 中，哈密顿约束仅由能量密度给出 ψ。而压强进入时移函数的方程。因此，强加 N = N(ψ)，也就是让 N 只是 ψ 的函数，就去掉了压强作为时移函数之源的作用。哈密顿约束和流体方程保持不变。

这条规则是由一幅非正式的图景启发作者的。在这幅图景中，某一地点的时移函数只取决于该地点的共形因子。它不取决于物质的内部应力。这幅图景在另一份文件中说明，供想了解的读者参考。计算中没有任何内容依赖于它。

中子星是压强与能量密度可比的唯一一类静态天体。所以它们是可以检验这条规则的地方。

方程

我们使用各向同性坐标和静态球形恒星。度规是 ds² = −N²dt² + ψ⁴(dr² + r²dΩ²)。我们使用 G = c = 1 的单位。ρ 是静态观测者测得的总能量密度。共有三个方程。

  1. 哈密顿约束，与广义相对论相同： ∇²ψ = −2πρψ⁵。它说明密度如何使空间弯曲。
  2. 这条规则，取代 GR 的时移方程 ∇²(Nψ) = 2πNψ⁵(ρ + 6p)：N = 2/ψ − 1，也就是 ψ + Nψ = 2。
  3. 物质： 服从能量和动量守恒的理想流体，∇_μT^μν = 0。也就是 p′ = −(ρ + p)N′/N，在表面 p = 0。用文字说：恒星的每一层都处于平衡。

符号 ∇² 称为拉普拉斯（Laplace）算子。它衡量一点上的值与附近各点的平均值相差多少。

这条规则从何而来，假设了什么

在各向同性坐标中，施瓦西度规有 ψ = 1 + M/2r 和 N = (1 − M/2r)/(1 + M/2r)。所以对每个 M 都有 N = 2/ψ − 1。假设时移函数只是各向同性共形因子的函数。那么真空 GR 只能以一种方式确定这个函数。

变量的选择很重要。 人们也可以使用面积坐标。在面积坐标中，同样的论证给出 N²g_RR = 1（Jacobson 2007）。在物质内部，这个关系迫使 p_r = −ρ，并允许致密度达到 1/2。这项工作的结果是各向同性规则的性质。各向同性变量是作者的选择。这是一个假设：空间度规被取为共形平坦的，以 ψ 作为物理变量，并且规则也被强加在物质内部。ψ 是通过对约束在整颗恒星上积分得到的。所以这条规则是两个场之间的逐点关系。它不是一个定域的状态方程。

只有一个物体。 这一切都对精确的球对称成立。我们试试两个质量：ψ = 1 + a₁/|x − x₁| + a₂/|x − x₂|。这个 ψ 是调和的。它是两个在某一瞬间静止的物体的 Brill–Lindquist 共形因子。用 N = 2/ψ − 1，静态度规不是真空解。它的里奇（Ricci）张量（衡量曲率的量）不为零。在一个开区域中，它有一个 a₁a₂ 量级的项。去掉两个质量中的任何一个，这一项就消失。

它意味着什么

流体压强不进入场方程。度规以及它的有效应力，仅由 ρ 确定。

我们用爱因斯坦方程来解读同一个度规。它有各向异性的有效应力：径向压强 p_r（向外）不同于切向压强 p_t（沿表面），且 p_t > p_r。在牛顿（Newton）极限下，也就是在弱引力下，中心的有效径向应力就已经是流体压强的一半。有效应力与流体应力之差自身守恒，能量密度为零。

这是静态方程的一种唯象闭合，还不是一个理论： 没有作用量，也没有动力学。唯象闭合是一条实用的规则，它补全方程，让我们能够进行计算。

定域与全局。 远离恒星时 ψ → 1 + M_ADM/2r，N → 1 − M_Komar/r。M_ADM 和 M_Komar 是从远处测量总质量的两种方式。在整个空间上积分，得到 ∫∇²(ψ + Nψ) d³x = 4π(M_Komar − M_ADM)。在 GR 中，积分内的量 2πψ⁵[N(ρ + 6p) − ρ] 在物质内部不为零。但它的积分为零，因为对在远处变得平坦的稳态时空，科马尔（Komar）质量和 ADM 质量相同（Beig 1978）。而这条规则逐点地把这个量设为零。在 GR 中，收支只在总体上相抵；在这里，每一点上都相抵。

相关的理论

另一些提议也让 GR 在真空中保持不变（至多差一个宇宙学常数），只改变物质内部：

  • 爱丁顿（Eddington）启发的玻恩–英费尔德（Born–Infeld）引力（Bañados 和 Ferreira 2010）；它的中子星由 Pani、Cardoso 和 Delsate（2011）研究；
  • 帕拉蒂尼（Palatini）f(R) 引力（Olmo 2011）。

这些理论在两方面不同于这项工作的规则。第一：它们由一个作用量得出，而这条规则没有作用量。第二：它们的内部依赖于一个耦合：玻恩–英费尔德引力中的 κ，帕拉蒂尼 f(R) 中的函数 f。而在这里，一旦选定各向同性变量（一个假设，上面已说明），物质内部 N 与 ψ 的关系就是真空解所确定的那个关系。这条规则没有耦合常数。状态方程仍然是输入。对均匀密度，这给出单一的值：0.466。

差别从何而来

在这些变量中，无论在 GR 中还是用这条规则，ψ 的源都只有能量密度。这是通过同一个哈密顿约束实现的。唯一的差别是时移函数的方程。

在 GR 中，压强是时移函数的源。用协变形式写作 D²N = 4πN(ρ + 3p)。在上面使用的平直拉普拉斯形式中，它变成 ∇²(Nψ) = 2πNψ⁵(ρ + 6p)。而在这里，时移函数由 ψ 得出，所以压强不是它的源。

这在实践中意味着什么？在 GR 中，压强增加引力的拉力。压强越大，引力越强，就需要更大的压强。用这条规则，压强不再是时移函数的源，由压强带来的引力拉力就更小。于是同一颗恒星在中心只需要较小的压强就能保持平衡。一个给定的状态方程也能支撑稍多一点的质量。

两个恒星序列因不同的原因而终止。在 GR 中，均匀密度恒星的序列终止于 4/9，在那里所需的中心压强变为无穷大。用这条规则，序列终止于中心时移函数达到零的地方，ψ_c = 2，致密度为 0.466。在那里压强也变为无穷大。

这个效应的相对量级是 p/ρ。它存在于任何物质中。但在太阳或地球中 p/ρ 极小，GR 和这条规则在这个精度上是一致的。只有在中子星中 p/ρ 才达到百分之几十。只有在那里，二者才有可测量的差别。

恒星序列在哪里终止

设想一颗接一颗地构造越来越致密的恒星。这个序列迟早会终止：超过某一点，恒星就无法保持平衡。

对均匀密度，无论在 GR 中还是用这条规则，有一件事都成立：乘积 (ρ + p)N 是常数。所以中心压强恰好在中心时移函数达到零时变为无穷大。在 GR 中，压强是时移函数的源（平直拉普拉斯形式中的 ρ + 6p）。所以压强会反过来作用于几何。而用这条规则，N 由 ψ 确定，ψ 只取决于 ρ。序列终止于 ψ_c = 2。这是 N = 2/ψ − 1 ≥ 0 成立的取值范围的边缘。在 ψ_c = 2 时，中心的时移函数为零：在那里时钟停止。

均匀密度，有精确公式。 这个约束是 n = 5 的莱恩–埃姆登（Lane–Emden）方程。它的解是 ψ = ψ_c(1 + 2πρψ_c⁴r²/3)^(−1/2)。这里 ψ_c 是中心的值。与外部衔接得到 ψ_R = ψ_c^(2/3)。致密度是 C = GM/(Rc²) = 2(ψ_R − 1)/ψ_R²，其中 R 是面积半径。

  • GR 的 Buchdahl 极限 C = 4/9 对应于 ψ_R = 3/2（ψ_c = 1.8371）。
  • 极限 ψ_c = 2 给出 C_max = 2^(1/3) − 2^(−1/3) = 0.46622。也可以这样说：离开表面的光的红移是 z = 2.847（在 GR 中是 2）。红移说明光在爬出恒星引力时被拉伸了多少。这个值低于 Ivanov 对各向异性恒星给出的上界：3.842 或 5.211，取决于对切向压强施加的能量条件。
  • 我们要求流体压强满足 p_c ≤ ρ。于是得到方程 y³ + 2y − 4 = 0，其中 y = ψ_c^(1/3)。也就是 C = 0.40427（在 GR 中是 3/8）。这只对均匀密度成立。
  • 中心的有效径向应力是 p_r/ρ = (ψ_c − 1)/(3(2 − ψ_c))。

与 Buchdahl 假设的联系。 有一个 Andréasson（2008）的定理。它对满足两个条件的静态球形 GR 解成立：p_r ≥ 0 和 p_r + 2p_t ≤ ρ。那么 2m/r ≤ 8/9，对密度如何变化没有要求。这里 p_r ≥ 0。所以要超过 4/9，就必须违反迹条件 p_r + 2p_t ≤ ρ。这在中心发生于 ψ_c > 3/2，也就是 C > 0.3615。GR 自身的均匀恒星在 C > 5/18 时也违反同一条件。把恒星带到 Buchdahl 假设之外的是各向异性。有效应力的主能量条件在 ψ_c > 7/4（C > 0.4289）时不再满足。但要超过 4/9 并不需要这一点。

现实的状态方程与 NICER

什么是状态方程。 状态方程说明物质在某一密度下提供多大的压强。想一想海绵和石头。挤压它们时，海绵立刻变形，石头则抵抗。中子星的核物质有自己的“硬度”，至今还不太清楚。科学家使用几种可能的状态方程：SLy、APR4 等。“较硬”的状态方程抵抗得更强。

它如何进入计算。 使用与上面相同的三个方程。但用的是冷核物质的现实状态方程 ε(p)。这里 ε 是总能量密度，上面我们称之为 ρ。所以：

  • ψ 来自哈密顿约束 ∇²ψ = −2πεψ⁵（ε 为总能量密度）；
  • N = 2/ψ − 1；
  • p 来自守恒：p′ = −(ε + p)N′/N。

中心值 ψ_c 由在无穷远处 ψ → 1 的要求确定。质量从外部 ψ = 1 + M/2r 读出。面积半径是 ψ(R)²R。比较的对象是 GR，也就是使用相同状态方程的 TOV 方程。我们使用 Read 等人（2009）给出的 SLy 和 APR4 的分段多方形式，以及他们的 SLy 壳层。恒星在 dM/dp_c > 0 的分支上计入，也就是质量随中心压强增长的分支。对这条规则而言，这个静态准则是一个假设，因为没有动力学。

计算之前预注册的六条预测。 为这次比较写下了六条预测，在计算之前用 SHA-256 指纹固定：

  1. GR 的值在 2% 以内重现 Read 等人的结果；
  2. 这条规则使最大质量至少提高 3%；
  3. 它使 1.4 M☉ 处的半径移动不到 0.5 km，
  4. 且向上移动；
  5. GR 和这条规则都落在 PSR J0437−4715 的区间内；
  6. 二者都至少达到 2.01 M☉。

六条全部成立。 这一节尚未独立重新运行。符号 M☉ 代表太阳的质量：1.4 M☉ 意思是太阳质量的 1.4 倍。

  • PSR J0740+6620：M = 2.08 ± 0.07，R = 12.49 (+1.28/−0.88) km（Salmi 等人 2024）。Dittmann 等人 2024 给出 12.92 (+2.09/−1.13) km。用这两个状态方程，GR 和这条规则在 2.08 M☉ 处给出的半径都低于 Salmi 等人的区间。这条规则更接近该区间，约近 0.35 km（APR4）。

这意味着什么。 用相同的状态方程，这条规则使最大质量提高约 5%。它使 1.4 M☉ 恒星的半径移动 0.10–0.13 km。（2.34.2 更正，更正 3：SLy 为 0.12 km，APR4 为 0.10 km。） 这一移动比目前约 ±0.8 km 的 NICER 误差小约十倍。所以今天的数据无法区分这条规则和 GR。

最大质量的 5% 与状态方程的硬度混在一起。版本 2.34.1 写道：“在 GR 中稍硬一点的状态方程会给出相同的结果”。这句话在版本 2.34.2 中撤回（更正 7）：它未经计算。 仍然成立的是，这一增加与各状态方程之间的差异一样大。

要把二者分开，需要约 0.1 km 的半径误差，或者对状态方程的独立确定。用 SLy 和 APR4，这条规则与 PSR J0437−4715 相容。与 GR 一样，对 PSR J0740+6620，它给出的半径低于 Salmi 等人的区间。这些数据并不证实它。

没有主张的内容

  • 并未主张这条规则在物质内部成立：这是假设的。
  • 并未主张各向同性变量优于其他变量：这也是假设的。
  • 没有协变的或动力学的表述。所以对径向稳定性（恒星能否经受小的推动）、转动或动力学完备化的后牛顿约束，什么也没有说。（版本 2.34.2 增加了两种后牛顿解读：见后文。）
  • 没有主张对所有密度剖面或所有状态方程成立的上界。（版本 2.34.2 对不向外增加的剖面证明了一个上界 12/25。）
  • 没有主张因果性。对均匀密度，无论在 GR 中还是用这条规则，声速都是无穷大。在物理学中，没有什么应该比光更快。
  • 并未主张 NICER 数据支持这条规则而不是 GR。用 SLy 和 APR4，在今天的误差范围内二者无法区分。

版本 2.34.1 中增加的内容

谁已经做过：Buchdahl 1964 年的假设

物质内部的关系 N = 2/ψ − 1 并不新。

  • Buchdahl 的选择。 1964 年，Buchdahl 在寻找指数为 5 的埃姆登（Emden）多方球的相对论版本。多方球是恒星的一种简单模型。Buchdahl 选择各向同性坐标，取 ψ = 1 + f 和 N = (1 − f)/(1 + f)（他的方程 2.2）。这正是 N = 2/ψ − 1。他的理由与上面给出的相同：外部施瓦西度规具有这种形式（他的方程 2.3）。
  • 他的计算。 然后他要求物质是理想流体。压强的各向同性，也就是各个方向上压强相等，给出 f f″ − 3f′² − f f′/r = 0（他的方程 2.7）。解是 f = (A + Br²)^(−1/2)（他的方程 2.8）。
  • 取 A = 0，就回到施瓦西外部解。
  • 取 A > 0，就得到他的 n = 5 解。它半径无穷大，质量有限。

资料包中的一个程序重做了这一计算。版本 2.34 为 4/9 极限引用了 Buchdahl（1959），但没有引用这篇论文。

这项工作的不同之处。 Buchdahl 要求度规是带理想流体的爱因斯坦方程的解。这样就只剩下他的 n = 5 族。而在这里，这个关系取代时移方程，适用于任何密度剖面：

  • 物质仍然是理想流体，压强由守恒得出；
  • 恒星具有有限半径；
  • 放弃的是有效应力（用爱因斯坦方程解读度规所得的应力）的各向同性：这个有效应力是各向异性的。

均匀密度的精确最大值 2^(1/3) − 2^(−1/3)、五个剖面和现实状态方程，都是这第二种选择的结果。

其他先前工作。 这些是在 2026 年 10 月 7 日所做的一次新颖性核查中发现的：

  • Buchdahl 解在 ψ = 1 + f 形式下的度规，是 Delgaty 和 Lake（1998）目录中的条目“Buch2”；
  • 均匀密度恒星的共形因子是哈密顿约束的 n = 5 莱恩–埃姆登解。Baumgarte、Ó Murchadha 和 Pfeiffer（2007）把它作为初始数据研究过，没有时移函数；
  • Puttasiddappa、Bretón 和 Pérez Bergliaffa（2026）构造了均匀密度的各向异性恒星，也超过了 Buchdahl 极限。在他们的恒星中，各向异性与 ρ k^μ∇_μP_r 成正比，系数为常数。这项工作的恒星不属于那一族：相应的比值沿半径变化。

中子星的结合能

结合能说明恒星形成时释放了多少能量。想一想一堵砖墙：你称一称所有散开的砖，再称一称砌好的墙。对真实的墙来说，这个差别是看不出来的。而在中子星中，整颗恒星比一块一块计入的物质更轻。这个差 BE = M_B − M 就是结合能。M_B 是重子质量，也就是一块一块计入的全部物质的质量。M 是引力质量，也就是从外部测得的质量。

这一部分的预测在计算之前预注册。一个核查程序是在计算之后写的，没有预注册。

  • 状态方程。 使用 Read 等人（2009）的 17 个分段多方形式。它们的参数是凭记忆输入的。因此对照已发表的最大质量作了核查：全部 17 个都在 1.1 % 以内相符。（2.34.2 更正，更正 2：ALF2 的参照值有误，被准入的状态方程是 16 个，而不是 17 个。）

结果。

  • 在固定质量下，两种理论的结合能几乎相同。
  • 在 1.25 到 1.6 M☉ 之间，这条规则与 GR 在 0.1 % 以内相等。（2.34.2 更正，更正 1：改为“低了不到 0.2 %”。）
  • 在 GR 的最大质量处，它低 0.4–0.75 %，尽管那里的半径增大 0.61–1.18 km。（2.34.2 更正，更正 1：0.43–0.80 % 和 0.74–1.36 km。）
  • 一个可能的原因是两种理论有相同的哈密顿约束。正是这个约束由能量密度确定空间的几何。这是对数字的一种解读，不是证明。
  • 准普适关系 BE/M(β) 不能把这条规则区分出来。 这里 β 是致密度。平均偏移是 +2.4 %，而 GR 的离散度是 4.3 %。
  • 脉冲星 PSR J0737−3039B（Podsiadlowski 等人 2005）在两种理论中选出相同的五个状态方程。

有两条预测不成立。 下面是预注册的文本（译自意大利文），然后是结果。

新结果

用精确公式表示的有效应力。 我们用爱因斯坦方程来解读规则的任何位形，取任何密度剖面。符号计算给出：

  • ρ_eff = ρ；
  • 迹 S = p_r + 2p_t = ρ(ψ − 1)/(2 − ψ)；
  • p_r = −ψ′[(rψ)′ − 1]/[2πrψ⁵(2 − ψ)] ≥ 0。

迹条件 p_r + 2p_t ≤ ρ 恰好在 ψ ≤ 3/2 的地方成立。

密度不增加时的上界。 规则的每个密度不向外增加的位形都有 C < 12/25 = 0.48。证明分三步：

  1. q = ρψ⁵ 不增加；所以 m̃(r)/r³（其中 m̃ = −r²ψ′）不增加；
  2. 由此得出 ψ_c − ψ_R ≥ (ψ_R − 1)/2；
  3. 中心的时移函数必须为正，ψ_c < 2；这给出 ψ_R < 5/3。

几点说明：

  • 初始数据。 这个上界只用到哈密顿约束和 ψ_c < 2。
  • 没有不增加条件时，薄壳趋近 C = 1/2，也就是 2M/R → 1。
  • 状态方程。 对由正压状态方程构造的恒星，密度自动不增加。
  • 数值核查。 没有任何阶梯剖面超过均匀值 2^(1/3) − 2^(−1/3) = 0.46622。这个值对真正的最大值而言仍然是一个猜想：
  • 在随机取的 120 个不增加的阶梯剖面中，最大的是 0.4662163；
  • 对两级阶梯剖面的局部优化再次找到均匀剖面。这个程序由一个充当审稿人的 AI 助手独立编写。

  • 匹配其余系数给出 β = γ = 1、ζ₃ = 0、ζ₂ = 1/2 和 ζ₄ = −1。
  • 每个由不变作用量导出的理论都有 α₃ = ζᵢ = 0（Lee、Lightman 和 Ni 1974）。
  • 双脉冲星给出 |α₃ + ζ₂| < 4×10⁻⁵，从而约束 ζ₂（Will 2014）。在强场中 |ζ̂₂| < 1.3×10⁻⁵（Freire 和 Wex 2024）。
  • 所以，在这种解读下，这条规则不是任何由作用量导出的度规理论的静态极限，也不是任何与这些上界相容的度规理论的静态极限。 不成立的解读：把这条规则当作修改引力。
  • 此外，根据 Will（1976，2014）的一个论证，在任何合理的理论中 6ζ₄ = 3α₃ + 2ζ₁ − 3ζ₃。那么 ζ₄ = −1 且 ζ₃ = 0 就要求 3α₃ + 2ζ₁ = −6，而 |α₃| < 4×10⁻²⁰。

因果恒星：有效应力。

  • 斜率。 在 c_s² = 1 的最大质量规则恒星中，有效应力的斜率 dp_r/dε 和 dp_t/dε 不超过 0.922 和 0.917。它们不是特征速度，也就是波在介质中传播的速度：有效介质对扰动没有规定的响应。
  • 主能量条件。 在这颗恒星中成立。
  • 最大质量恒星中心的迹。 我们比较这条规则的 S/ε 和 GR 的 3p_c/ε_c：
  • c_s² = 1：1.52 对 2.01；
  • c_s² = 1/2：0.90 对 1.13；
  • c_s² = 1/3：0.65 对 0.79；
  • SLy：1.20 对 1.62；
  • APR4：1.52 对 2.11。

术语表

  • 作用量。 一个公式，一个理论的所有方程都由它得出。这项工作的规则没有作用量。
  • 各向异性。 随方向而不同。各向异性的应力向外的推力和沿表面的推力不同。
  • 结合能。 一块一块计入的物质的质量与整颗恒星的质量之差。
  • Buchdahl 极限。 在 GR 中，密度不增加的理想流体恒星不能超过 C = 4/9。
  • 因果。 如果物质中的声音不比光快，状态方程就是因果的：dp/dε ≤ 1。
  • 闭合，规则。 也被强加在物质内部、取代 GR 时移方程的关系 N = 2/ψ − 1。
  • 致密度 C。 一颗恒星被压得有多紧：C = GM/(Rc²)。
  • 共形因子 ψ。 这个数说明，在某一地点，地图上的一段实际上有多少空间，与非常遥远的地方相比是多少：在质量附近，同样的一段需要更多的直尺。
  • 状态方程。 说明物质在某一密度下提供多大压强的规则，也就是它有多“硬”。
  • 广义相对论（GR）。 爱因斯坦的引力理论。
  • 时移函数 N。 这个数说明，在某一地点，一个时钟与遥远的时钟相比走得多慢。
  • M☉。 太阳的质量，用作单位。
  • 中子星。 一颗死亡的恒星，被压得非常紧：质量大约与太阳相当，却集中在一个城市大小的球体里。
  • NICER。 国际空间站上的一台仪器，测量脉冲星的质量和半径。
  • 后牛顿。 一步一步计算对牛顿引力的修正的方法。
  • 脉冲星（PSR）。 发出规则脉冲的旋转中子星。
  • 转折点。 沿恒星序列的质量最大值。在 GR 中，超过这一点恒星就不稳定；对没有动力学的这条规则来说，它只是一个指示。
