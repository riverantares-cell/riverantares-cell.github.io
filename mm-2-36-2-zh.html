MM（Mathematical Materiality，数学物质性）是作者的理论框架。在 MM 中，物理量是从计数列表中读出的。这些列表称为记录器。记录器彼此比较。人们测量它们在统计意义上重叠多少：这就是贝叶斯重叠。本工作只用到 MM 的一小部分。它在第 2 节中概括。

1. 物质之外（真空中）的规则

现在我们来看一条精确的数学规则。它在一个质量周围的空旷空间中成立。

在物理学中，度规是说明距离和时间如何测量的规则。想一想地图。比例尺告诉你纸上一厘米相当于多少实际的千米。在恒星附近，引力既改变距离，也改变时钟的快慢。

取一个不随时间变化的物体：它称为静态的。它具有完美球体的形状：它称为球对称的。我们使用各向同性坐标。这是一种测量网格，在每一点上它在所有方向上的表现都相同。它不会把形状压扁。

在这个网格中，直尺由一个空间部分描述：ψ⁴(dr² + r²dΩ²)。这里 ψ（psi）是一个数。它称为共形因子或深度。它说明，在某一地点，地图上的一段实际上有多少空间，与非常遥远的地方相比是多少：在质量附近，需要更多的直尺才能铺满同样的一段。时钟的快慢由另一个数 N 描述。它称为时移函数，也就是速率。它说明，在该地点一个时钟与遥远的时钟相比走得多慢。为方便起见，物理学家把引力常数和光速都取为 1（G = c = 1）。

在爱因斯坦（Einstein）的广义相对论中有两个公式成立。它们在质量 M 之外、距离 r 处的空旷空间中成立。第一个是 ψ = 1 + M/2r。第二个涉及这两个数的乘积：Nψ = 1 − M/2r。这两个表达式都是调和的。调和函数是一种光滑的分布。它不会在任何空的点上堆积。想一想一个房间的温度，房间中央的空气里没有打开的取暖器。

我们把 ψ 和 Nψ 相加。+M/2r 和 −M/2r 这两项相互抵消。剩下的是：

ψ + Nψ = 2

这个关系对施瓦西（Schwarzschild）度规精确成立。施瓦西度规是爱因斯坦方程在球形质量周围空旷空间中的解。相对论用两种方式从远处测量总质量。它们称为单极项 M_ADM 和 M_Komar。在这里它们给出相同的值 M：M_ADM = M_Komar = M。

对单个中心，逆命题也成立。这用一个精确公式来检验。取 ψ = 1 + a/r。施加速率 N = 2/ψ − 1，这是 ψ + Nψ = 2 的另一种写法。我们得到的恰好是各向同性的施瓦西度规，质量为 M = 2a。在太阳系中，人们用两个参数来检验引力模型。它们称为 γ（gamma）和 β（beta）。在这个外部空间中，两者都恰好为 1：γ = β = 1。

不过，当球形失去时，这条规则不能推广到多个质量。我们用位于点 x₁ 和 x₂ 的两个质量来试一试。我们写出 ψ = 1 + a₁/|x − x₁| + a₂/|x − x₂|。这个 ψ 仍然是调和的。但现在我们施加静态速率 N = 2/ψ − 1。于是爱因斯坦真空方程不再被满足。曲率用一个数学对象来测量：里奇（Ricci）张量。在真空中它应当为零。而这里它不为零。留下了一个残余，它正比于两个质量的乘积（量级为 a₁a₂）。这个残余存在于空间的一个开放区域中。只有去掉两个质量中的一个，它才消失。技术说明：这个双中心的 ψ 是 Brill–Lindquist 共形因子。在广义相对论中，它描述两个静止的黑洞，处在单一的、时间对称的初始时刻。这里不成立的是另一回事：让静态速率 N = 2/ψ − 1 在时间中保持固定的那种解读。

因此，关系 ψ + Nψ = 2 只在精确的球对称下成立。本工作的适用范围：静态、球对称、单个物体。

2. 五行概括模型

在计算之前，我们先来看模型的五个基本组成部分。模型用它们从计数出发构建空间。

  1. 记录器。 记录器是一个计数列表 c ∈ ℕ^K。它分为 K = 4 个类别。每个类别 k 至少有一个计数（c_k ≥ 1）。所有计数之和是 n。一个具体的例子：一本有 4 栏的笔记本。你在栏中画叉，记下驶过的汽车的颜色：红、蓝、绿、黄。记录器的状态由一个概率分布描述。它称为 狄利克雷（Dirichlet）后验分布。它有一个证据值 E(c) = log[(K−1)! ∏_k c_k! / (Σ_k c_k + K − 1)!]。证据衡量观测到恰好这一计数列表的可能性有多大。
  1. 抽样和 Fisher 距离。 记录器以均匀的方式随机抽取。在概率空间（称为单纯形）上使用 Fisher 测度（Amari 和 Nagaoka 2000）。实际操作中，用钟形曲线（高斯 g）生成 4 个随机数。然后计算 p = g²/|g|²。接着用一种称为多项分布的规则抽取计数：c = 1 + Multinomial(n − K, p)。两个记录器之间的距离不是用直尺测量的。它用 Fisher 距离测量：d(p, p′) = 2 arccos Σ_k √(p_k p′_k)。如果两个记录器在 4 栏中的百分比相近，它们就靠得近。如果它们很容易区分，它们就相距很远。把统计可区分性用作距离的想法可追溯到 Wootters（1981）。认为信息几何就是物理空间的几何的想法来自 Caticha（2005、2016、2019；见第 9 节）。
  1. 记录器之间的连接。 两个记录器 i 和 j 由一个权重连接。它称为归一化贝叶斯重叠：w_ij = exp[E(c_i + c_j) − ½E(2c_i) − ½E(2c_j)]。这个权重衡量两个记录器能在多大程度上纳入同一个计数。每个记录器与自身的权重为 1（自权重 1）。只保留相近的记录器之间的连接。相近是指在 3.5 个典型涨落宽度之内。一个宽度在坐标 2√(c/n) 中是 2/√n。
  1. 图上的算子。 相连的记录器构成一个网络。它称为图，就像由道路连接的城镇网络。在网络上定义一个数学算子。它衡量数值从一个节点到其相邻节点如何变化。它是归一化图拉普拉斯（Laplace）算子 L = I − D^(−1/2) a D^(−1/2)。这里 W 是权重 w_ij 的表。d 是 W 的行和。于是 a = d⁻¹Wd⁻¹。D 是 a 的行和。
  1. 静态响应。 我们在最均匀的记录器上放一个点源 δ。它是 4 栏几乎相等的那个记录器。我们寻找在时间中保持不变的响应。方程 L G = δ 在源周围半径 0.7 的球内求解：这就是 Fisher 球。在这个半径之外，我们令 G = 0。0.7 这个值是一个数值上的选择。得到的势是 φ = D^(−1/2) G。

这个图存在于一个三维空间中：记录器状态的空间。为什么是三维？类别数是 K = 4。但是，如果你知道前三个百分比，第四个就确定了。总和必须是 100 %。所以剩下 4 − 1 = 3 个自由度。在这个抽象空间中有距离。把它们等同于物理空间的距离，是这个框架的一个前提。它是第 3 节的前提 P3。它不是经计算证明的结果。

第 3 节增加了同一框架的三个概念。它们是记录器的有效密度、沿一条直线看到的记录器的图像，以及记录器的碎片化。第 7 节使用一个单独的测试平台，在那里加以描述。

3. 从计数前提到数 ψ 和 N

现在我们来看，引力的两个数是如何从计数记录器中读出的。它们是空间深度 ψ 和时钟速率 N。

为清楚起见，每一步都在方括号中带有一个标记：

  • [C] 标记计算所得的内容，用手或用计算机；
  • [P] 标记前提，即理论框架所假定的出发点；
  • [S] 标记在多种可能的备选中作出的选择；
  • [T] 标记唯一的转移公设，它把计数与引力联系起来。

这整条步骤链是静态的：它不随时间变化。它的定律在解读次数 T 非常大时成立。这称为多解读极限。存在正比于 1/T 的小修正。

3.1 基本恒等式 [C]

我们从一个纯数学性质开始。它涉及两条钟形曲线。想象两个模糊的光斑，中心相同。它们处在 D 维空间中。它们由两个各向同性高斯（Gauss）分布 p₀ 和 p_x 描述。

  • 第一个的方差是 s₀²。方差是模糊宽度的平方。它代表远方观测者的分辨率。
  • 第二个的方差是 s_x²。它代表被观测地点的分辨率。

两个光斑之间的重叠是它们乘积的积分：Λ_ab = ∫ p_a p_b。从 b 看向 a 的归一化重叠是 ℓ(a→b) = Λ_ab/Λ_bb。我们把两个宽度之比记为 q = s₀²/s_x²。

计算给出：

  • ℓ(0→x) = (2/(1+q))^(D/2)
  • ℓ(x→0) = (2q/(1+q))^(D/2)

当维数为 D = 2，也就是在平面上时，发生了一件值得注意的事。指数 D/2 变成 2/2 = 1。于是两个重叠之和是： 2/(1+q) + 2q/(1+q) = 2(1+q)/(1+q) = 2，对 q 的任何值都如此。

还有一种非常常用的统计工具。它称为相对熵，或 Kullback–Leibler（KL）散度。用这个工具，两个方向之和不是常数：KL(0‖x) + KL(x‖0) = (D/2)(q − 1)²/q。本节其余部分说明，为什么两个重叠 ℓ 对应于深度 ψ 和乘积 Nψ。

3.2 五个前提 [P]

下面是 MM 框架的公理。公理是不加证明的基本原理。这里用清晰的形式写出。

  • P1（时钟）。 一次又一次地有新的解读到来，也就是一个新的计数。每一次，一个地点的记录器都会更新一点。该地点的固有时是停留在那里的时钟所标记的时间。每次解读时它前进一个量：这次小更新的 Fisher 长度。解读以相同的速率到达各处。用统计涨落的大小来测量时间，是 Caticha 2011 年的想法：熵时间。Ipek、Abedi 和 Caticha 在 2018 年，Ipek 和 Caticha 在 2020 年，把它定域化。不过在他们的工作中，速率 N 已经由几何给定。正是这个速率确定涨落。这里方向反过来了：是计数确定速率 N。我们将在第 9 节看到这一点。
  • P2（图像）。 有两个视点：质量附近的地点和远方观测者。它们描述同一样东西：一个百分比组成相同的记录器。但是它们收集的解读次数不同。它们通过观察图像来比较各自的描述。图像投影在垂直于连接它们的视线的平面上。想一想从远处看的一个球：你看到一个扁平的圆盘。所以这种比较是在二维（D = 2）中进行的。
  • P3（距离）。 空间中的物理距离是记录器碎片化的量度。碎片化说明记录器的副本在记录器状态空间中移动和散开了多少。
  • P4（质量）。 一个记录器的副本数目，也就是它的倍数，是物体的质量。多个副本的效应相加。
  • P5（吸收）。 一个副本到达某一地点。在那里它被吸收进两个视点的联合状态，也就是合并的状态。这个联合状态保持完整：各部分的总和仍然构成整体。

3.3 时钟：N = τ₀/τ_x [C]

现在我们来看，为什么计数更多的时钟走得更慢。

记录器的有效密度是数 τ = T + 1。T 表示收集到的解读次数。+ 1 考虑了起始计数（先验伪计数）。一次新的解读到来：记录器的状态平均移动多少？想一想一个水箱。如果箱里只有一升水，再加一杯就会使水位变化很大。这是计数少的情形。如果有一千升水，同样一杯几乎不改变水位。这是计数多的情形。

我们在定域 Fisher 度规中计算一次新解读的平均步长。这就是均方根 Fisher 步长。对记录器的任何百分比组成，它恰好是 √(K − 1)/τ。对 K = 4 个类别，用公式的计算是精确的。在计算机模拟中，它在 0.23 % 以内成立。对所有组成，它在 0.35 % 以内相同。当每个类别都包含许多解读时，有限的 Fisher–Rao 距离也与之相符。

我们比较地点 x 的时钟步长和远方观测者 0 的时钟步长。地点 x 的密度为 τ_x。远方观测者的密度为 τ₀。两个步长之比是 τ₀/τ_x。这由计算机在 0.3 % 以内检验。对相同的组成，狄利克雷分布的方差之比也恰好给出相同的结果。

现在我们使用前提 P1。该地点的时钟相对于遥远时钟的速率，就是时移函数 N。而它正好是这个比值：

N = τ₀/τ_x

解读越多的地方，τ_x 越大。于是每次解读的步长越小。该地点的时钟走得越慢（N < 1）。我们来看这条定律的形式。速率 N 是在远处测得的量与在该地点测得的同一个量之比。这个形式与热物理中著名的 托尔曼–埃伦费斯特（Tolman–Ehrenfest）关系完全相同：T_loc N = T_∞（Tolman 和 Ehrenfest 1930）。这里，取代温度 T 的是解读密度 τ。

3.4 深度：ψ = 2τ_x/(τ_x + τ₀) [C，多解读极限]

现在我们计算第二个数 ψ。我们通过在一块平面屏幕上比较两个记录器的图像来计算。

我们取两个记录器的概率分布 Dir(τp)。我们使用 Fisher 坐标 y = 2√p。我们把它们投影到垂直于该地点与远方观测者之间视线的平面上。前提 P2 要求这样做。然后我们计算从该地点看向远方观测者的归一化重叠：L⊥(x→0) = ∫f_x f₀ / ∫f₀²。

计算是在真实的投影狄利克雷图像上进行的。这些图像由计算机抽样，没有使用近似的高斯公式。结果与公式 2τ_x/(τ_x + τ₀) 相符：

  • 当远方观测者有 T₀ = 100 次解读时，在 0.44 % 以内；
  • 在 T₀ = 300 时，在 0.10 % 以内；
  • 在 T₀ = 1000-3000 时，在 0.03-0.04 % 以内。

差别是 1/T 量级的小修正。结果在 0.1 % 以内不依赖于视线的方向。还不止这些。两个相反方向之比 ∫f₀²/∫f_x² 趋于 τ₀/τ_x。所以我们通过第二条独立的途径，重新得到第 3.3 节的同一个速率 N。如果我们不投影到平面上呢？如果我们在整个三维状态空间中作重叠呢？那么公式就变了：它带的指数是 3/2，而不是 1。

[S] 已声明的选择。 我们把空间深度 ψ 等同于从该地点看的方向性重叠：ψ = 2τ_x/(τ_x + τ₀)。为什么不用一个以相同方式对待两个视点的对称公式？因为对称的比较区分不出谁的解读多、谁的解读少。在数学上，它是相对差 z = (τ_x − τ₀)/(τ_x + τ₀) 的偶函数。用对称公式，在一阶我们将看不到空间的曲率。我们会得到 γ = 0。这是一个不成立的解读，因为观测与它相矛盾。所以选择方向性重叠。它对解读的超出量作线性响应：它区分正号和负号。

3.5 一个联合计数的两个份额 [C]

现在我们把 N 和 ψ 放在一起。我们来看规则 ψ + Nψ = 2 具有怎样简单的含义。

我们停留在 3.4 中看到的多解读极限。我们把这两个数除以 2：

  • ψ/2 = τ_x/(τ_x + τ₀) 是地点 x 的解读所占的比例。它是 x 在两个视点的联合总数（τ_x + τ₀）中的份额。
  • Nψ/2 = (τ₀/τ_x) · τ_x/(τ_x + τ₀) = τ₀/(τ_x + τ₀) 是远方观测者 0 的解读所占的比例。它是远方观测者在同一总数中的份额。

一个用虚构数字的例子。两个孩子把贴纸放进一本共用的相册。第一个孩子放进了 60 % 的贴纸（ψ/2 = 0.60）。那么第二个孩子放进了其余的 40 %（Nψ/2 = 0.40）。两个份额之和是 1，也就是相册的 100 %。我们乘以 2。ψ + Nψ = 2 说的只是这一点：两个份额之和为一。

这就是为施瓦西关系提出的解读。它在物质之外和物质之内（第 4 节）都成立。在第 11 节中，我们还将把它解读为一种交换的守恒定律。在各向同性坐标中，空间的几何形状是平坦的。关于空间度规的全部信息都在标度因子 ψ 中。它正是信息几何单靠自身留下的自由的定域标度（Caticha 2016；第 9 节）。

3.6 源：碎片化给出 1/r 行为 [C]

到目前为止，我们谈的是某一地点的解读密度 τ_x。但是，为什么质量附近的解读更多？为什么这种超出量恰好按距离的倒数 1/r 减小？

我们跟踪一个 K = 4 个类别的记录器的碎片化。它的副本逐渐远离。它们一次解读接一次解读地失去精度。这个过程的行为恰好像三维 Fisher 空间中的各向同性布朗运动。布朗运动是沿所有方向、以小步进行的随机行走。想一想被水分子撞击的一粒花粉。这种行走的内部时钟 s 是 Fisher 步长的平方和。

这项检验使用计算机模拟的 60,000 条链。运动在 1.8-5 % 以内在所有方向上相同（各向同性）。每个方向上的方差在 1.4 % 以内等于 s。

在每一步，我们对副本留在该地点的东西加权。权重是失去的精度 Δs。于是，在距离源 r 处沉积的量遵循定律 1/(2πr) − B。一旦计算的约定确定下来，就没有需要手动调节的参数。这些约定是：Fisher 坐标、时钟 s、切空间的欧几里得体积、最小停止阈值 n_min。这个几何计算不给出以物理单位（如米和千克）表示的 G 值。在距离 r = 0.005 和 r = 0.04 之间，把模拟的点与公式比较。平均比值是 0.998。没有哪个距离带的偏离超过 3 %。常数 B 的出现，是因为碎片化在计数用尽时停止。这发生在最大时间 s_max。整个剖面由函数 [1/(2πr)] erfc(r/√(2s_max)) 描述。

在数学上，1/(2πr) 是三维布朗运动的格林函数。它是 3D 空间中随机行走留下的平均痕迹。MM 框架增加了一点：4 个类别的记录器的统计碎片化，其行为恰好像那个布朗运动，步长也恰好是那个精确的步长。

[S] 已声明的选择。 有两件事是已声明的选择：记录器失去计数的方式，以及给予沉积的权重 Δs。在较早的一次检验中，每次解读的权重相同，没有 Δs。那次检验没有得到预注册的斜率 1/r，那个解读不成立。根据前提 P3，记录器空间中的距离 r 就是物理距离。根据前提 P4，n 个副本沉积的量是 n 倍。

3.7 与物理学的衔接：公设 T [T]

现在我们有了各个部分。还缺最后的桥梁。在步骤 3.3-3.6 中，没有任何内容说明如何把碎片化沉积的量度转换成带有常数 G 的物理数 ψ。这一转换被公开声明为一条公设。

公设 T（转移）。 每次沉积把一份计数从远方观测者移到该地点：ψ − 1 = Σᵢ wᵢ。对距离 rᵢ 处的每个质量 mᵢ，移动的份额是 wᵢ = Gmᵢ/(2rᵢc²)。系数由实验标定：常数 G 是测量的，不是计算的。份额始终保持为正（Σᵢ wᵢ < 1）。对质量为 M 的单个物体，必须留在半径 r > GM/(2c²) 之外。

公设 T 的动机来自前提 P5。一个被吸收的副本，会重新分配一个保持完整的联合状态的各部分。但是公设 T 并不必然由 P5 得出。把计数相加再重新计算总数，同样会得到一个完整的状态。

公设移动的量是 w = GM/(2rc²)，用各向同性半径 r 写出。在一阶它与 −Φ/2c² 相同。一阶是指远离质量、处于弱场。这里 Φ = −GM/r 是牛顿（Newton）引力势。

Erik Verlinde 写过一篇关于涌现引力的著名论文。在最初的版本（预印本：2010 年的 arXiv:1001.0785v1，方程 3.16 和第 4 节）中，恰好有这个量 −Φ/2c²。在那里它衡量每比特信息的细节损失。这称为 coarse graining（粗粒化）。它是 0 到 1 之间的一个数。只有在黑洞的事件视界上它才等于 1。

在期刊发表的版本（JHEP 04 (2011) 029，方程 3.12 和第 4 节）中，Verlinde 把同一件事写成 −2Φ/c²。在称为面积坐标的标准坐标中，这个量在视界上等于 1。在那些坐标中，视界半径是 r = 2GM/c²。而在我们的各向同性坐标中，黑洞视界位于 r = GM/(2c²)。我们的份额 w 正是在那里达到 1。于是 ψ = 2，N = 0：时钟停止了。这个精确的值来自一个选择：公设 T 是用各向同性半径写的。它并非来自超出第一级近似之外与 Verlinde 公式的恒等。

3.8 由公设 T 得出的结果 [C]

我们来看这条公设的直接结果。先看单个物体，再看两个物体。

  • 单个物体。 我们有 ψ = 1 + GM/(2rc²)。份额是完整的（3.5），所以 N = 2/ψ − 1。这恰好是各向同性的施瓦西度规。γ = β = 1 成立。在质量之外，轨道就是广义相对论的轨道（程序 perielio.py 计算它们）。例如，水星近日点的移动结果相同。
  • 两个物体。 求和 ψ = 1 + Σᵢ Gmᵢ/(2rᵢc²) 精确满足爱因斯坦真空方程中的一个。它称为哈密顿约束。它支配空间在给定时刻的曲率。这就是著名的 Brill 和 Lindquist（1963） 初始数据：两个在一瞬间静止的黑洞。重要说明：用解读 S1，约束将不被满足。S1 相加的是原始计数，而不是份额。
  • 两个物体不会保持静止。 我们把速率规则 N = 2/ψ − 1 推广到两个物体的情形。那么完整的静态真空方程不被满足。空间张量 E_ij = R_ij − D_iD_jN/N 不为零。在物理上这是理所当然的。在广义相对论中，两个被放置为静止的质量同样不会保持静止。它们开始相向下落。因此，两个静止的物体只是一张初始快照。此后一切都必须随时间变化。这里 E_ij 并不直接是一个测量到的力。而我们的静态链还不包含运动定律，也就是动力学。

3.9 第 3 节的小结

我们如实总结一下，哪些做了，哪些没有做。施瓦西度规在本工作中不是从零开始推导出来的。它通过公设 T 进入。它与碎片化的 1/r 行为（3.6）和对应选择 S4 一同进入。计数链真正给出的有三点：

  1. 两个量的数学形式：N 是密度之比，ψ 是份额；
  2. 关系 ψ + Nψ = 2，这样解读：一个总数的两个份额之和为一；
  3. 由记录器的布朗碎片化产生的 1/r 定律。

4. 物质内部：一种唯象闭合，还不是理论

到目前为止，我们一直停留在恒星之外的空旷空间。现在我们进入恒星的物质内部。我们来看，如果规则 ψ + Nψ = 2 在那里也成立，会有什么变化。

在第 3 节的解读中，这个关系说的是一件事：联合计数的两个份额之和为一（3.5）。让它在物质内部继续成立，就意味着逐点施加这种完整性。即使在恒星气体的中央也是如此。

我们先来看通常的广义相对论怎么做。取一颗静态恒星，用各向同性坐标。有两个主要方程。其中 ρ 是物质的质能密度，p 是流体的压强。

  1. 哈密顿约束，针对空间：∇²ψ = −2πρψ⁵。
  2. 时移方程，针对时间：∇²(Nψ) = 2πNψ⁵(ρ + 6p)。

符号 ∇² 称为拉普拉斯算子。它衡量某一点的值偏离邻近各点平均值的程度。我们把这两个爱因斯坦方程相加。得到：

∇²(ψ + Nψ) = 2πψ⁵[N(ρ + 6p) − ρ]

在恒星内部这个结果不为零。它是一个很小但确实存在的量：它是第一后牛顿阶的。现在我们把这个效应在恒星的整个体积上加起来。在数学上这称为取体积分。根据一条定理（散度定理），结果是通过表面的通量。它只取决于 ψ 和 N 在远处的行为：ψ → 1 + M_ADM/2r 和 N → 1 − M_Komar/r。得到：

∫ ∇²(ψ + Nψ) d³x = 4π(M_Komar − M_ADM)

在广义相对论中，对每一颗静态恒星，两个总质量 M_Komar 和 M_ADM 都严格相等。Beig 在 1978 年证明了这一点；另见 Tolman 1930。所以这个总积分为零。简单地说：在广义相对论中，恒星内部的和 ψ + Nψ 并不逐点保持为 2。但在整颗恒星上加起来，效应相互抵消。在物质内部保持 ψ + Nψ = 2，意味着逐点施加广义相对论只在整体上、即在整颗恒星上保证的东西。

变量的选择是一个假设

规则是针对各向同性因子 ψ 写的。也就是说，空间度规具有 ψ⁴δ_ij 的形式。这是一个明确的选择：一个假设。用通常的面积坐标，真空中类似的性质是 g_tt g_rr = −1。Jacobson 在 2007 年研究过它。在物质内部施加那个公式会给出不同的结果。

替换了什么，代价是什么

下面是我们的模型在恒星内部的工作方式：

  1. 它保留哈密顿约束：∇²ψ = −2πρψ⁵。
  2. 它用一条代数规则替换爱因斯坦的时移方程：N = 2/ψ − 1。
  3. 它从能量动量守恒定律中得到流体的压强。这条定律说，恒星的每一层都必须保持平衡而不坍缩：dp/dr = −(ρ + p) d ln N/dr。

这一做法的代价是什么？流体的压强不再进入产生引力场的方程。 在物质内部，几何不再完全由流体产生，而爱因斯坦方程是这样要求的。因此，在物质内部，这个提议是静态方程的一种唯象闭合。唯象闭合是一条实用规则。它使方程组闭合，从而可以进行计算。它还不是一个完整的理论。

我们来看一颗密度均匀的理想恒星的数字：ρ 在每一点都相同。

  • 爱因斯坦张量中与时间有关的部分恰好给出密度：−G^t_t/8π = ρ。
  • 而与空间有关的部分并不给出流体压强 p。在恒星中心，几何*看到*的大约是流体压强的一半：在弱场中 G^r_r/8π = G^θ_θ/8π ≈ 0.50 p_c。
  • 向表面走去，差别变成各向异性的。也就是说，它随方向而变化。在径向（向外）和切向（沿表面）是不同的。切向部分为正。

一位相对论物理学家用爱因斯坦方程来解读这颗恒星。于是这位物理学家会说：恒星内部除了正常流体之外，还有一种额外的各向异性应力。这种应力自身守恒。而且它的能量密度等于零。

这涉及恒星物理学的一个著名极限。一颗恒星在坍缩成黑洞之前能有多致密？致密度用比值 C = GM/(Rc²) 衡量。这里 M 是恒星的质量，R 是恒星的半径。

  • 1959 年，Buchdahl 证明了一个极限。它在广义相对论中，对各向同性的理想流体成立，流体的密度不向外增加。致密度永远不能超过 C = 4/9 ≈ 0.4444。否则中心压强将变为无穷大。
  • 2008 年，Andréasson 证明了一个更一般的定理。它对任何静态球形物质都成立，即使是各向异性的。Bowers 和 Liang 在 1974 年研究过各向异性球体。始终有 2m/r ≤ 8/9，即 C ≤ 4/9。不过需要两个关于能量的条件。径向压强不能为负：p_r ≥ 0。压强之和不能超过密度：p_r + 2p_t ≤ ρ。

所以，我们取本模型中一颗致密度高于 4/9 的恒星。如果我们用广义相对论来解读它，它必定违反 Andréasson 的两个条件之一。它是通过额外的各向异性应力来违反的。因此，在物质内部，这个模型不是广义相对论加上一个简单的额外假设。

用一个公式表示的最大致密度极限

取一颗固有密度均匀的恒星。哈密顿约束变成天体物理学中一个已知的方程。它是指数 n = 5 的莱恩–埃姆登（Lane–Emden）方程。公式 ψ = ψ_c(1 + br²)^(−1/2) 是它的精确解。这里 ψ_c 是中心的值。在表面（r = R）我们把内部与空旷的外部空间相匹配。得到 ψ_R = ψ_c^(2/3)。

当中心达到份额的最大值 ψ_c = 2 时，可能的恒星族就终止了。这意味着 N_c = 0：时间在恒星中心停止。在那里，最大致密度恰好是：

C_max = GM/(Rc²) = 2^(1/3) − 2^(−1/3) ≈ 0.4662，而 Buchdahl 极限是 4/9 ≈ 0.4444。

在真实恒星的致密度下会发生什么

不必达到极端的极限就能看到差别。天文学家观测到的中子星，典型致密度为 C = 0.16、0.19 和 0.22。取具有这些致密度值的均匀密度恒星。我们的模型支撑恒星所需的中心压强低于广义相对论的中心压强。分别低 7.4 %、9.3 % 和 11.4 %。

当然，从中心到壳层都相同的均匀密度，对真实的中子星来说并不现实。可以使用核物质的现实状态方程。那样，联系恒星质量和半径的曲线就会移动。计算这一移动是工作的下一步。这里还没有做。从中心向外下降的其他密度剖面，在同一作者发表在 Zenodo 上的单独记录 MM 2.34 中研究。能量条件也在那里研究。

6. 在模型的图上检验 1/r 行为

现在我们在计算机上构建第 2 节的记录器网络。然后我们测量势 φ 在远离源处如何减小。

  1. 每个记录器 n = 512 个计数，网络有 64,000 个记录器，自由指数为 p = 0.937；
  2. 每个记录器 n = 1024 个计数（181,019 个记录器），指数升到 p = 0.956；
  3. 每个记录器 n = 2048 个计数（512,000 个记录器），指数达到 p = 0.980。

这是三个点。每个点都用单个随机种子计算。所以没有统计误差棒。

这种向 1 的趋近正是数学所预言的。Belkin 和 Niyogi（2008）以及 Coifman 和 Lafon（2006）证明了这一点。取图上的拉普拉斯算子，其连接由类似高斯的钟形权重构成。当点数增加时，这些算子趋近于其下方空间的连续几何算子。这就是拉普拉斯–贝尔特拉米（Laplace–Beltrami）算子。K = 4 个类别的记录器的状态空间有三维。因此它的静态响应必定趋于 1/r。

因此，1/r 行为反映的是 K = 4 这一事实。它不是动力学运动定律的结果。 第 3.6 节给出了通向 1/r 的第二条途径。它从单个记录器的碎片化出发。两条途径都依赖于 K = 4 时状态空间的三维。前提 P3 把这个空间等同于物理空间。

10. 运动中的时钟（展望；版本 2.36.1 增加）

现在我们离开引力。我们来看，副本的计数如何为平坦空间中快速时钟的变慢给出理由。

第 3 节谈的是质量附近静止的时钟。现在我们取一个以恒定速度运动的时钟。它在没有引力的平坦时空中运动。在这里，基于计数的解读产生爱因斯坦狭义相对论的时间膨胀。

想象时钟的出发事件和到达事件。在这两点之间，光线画出一个四边形。它称为光菱形或因果菱形。菱形沿光的方向的两条边是 a = cΔt − Δx 和 b = cΔt + Δx。这里 Δt 是实验室中经过的时间。Δx 是时钟走过的距离。

这里 MM 框架的另外两个前提开始起作用。

  • P6（第二环节）。 在运动的一个基本步中，沿两条光边的两个计数是互素的。如果两个整数除了 1 之外没有公约数，它们就是互素的，比如 3 和 5。副本在它们的公倍数处产生。因此，边长为 a 和 b 的菱形包含的单元数等于乘积 ab = gcd(a, b)·lcm(a, b)。这里 gcd 是最大公约数，lcm 是最小公倍数。
  • P7（没有预先指定的地点）。 空间中的地点在副本到达之前并不存在。预先固定的地点网格会定义一个特权参考系：一种静止的*以太*。因此，在计算机模拟中，副本独立而随机地分布在时空体积中。这是一个实用的假定。前提 P7 为它提供动机，但在数学意义上并不强加它。

[S] 已声明的选择。 运动时钟读出菱形内副本的数目。它把光的两个相反方向相乘来组合：这就是乘积规则。运动时钟标记的时间因此是乘积的平方根：√(ab)。而实验室中静止时钟的时间是两条边的平均：(a + b)/2。

这一切的数学原因用一行就能说清。菱形的面积正比于两边之积 ab。落入其中的副本数目也是如此。因此，一个计数副本并取平方根的时钟（正如乘积规则所要求的），测量的是两条边的几何平均 √(ab)。测量最长链的时钟也是如此，因为链按计数的平方根增长。实验室时钟把两条边相加。它测量的则是算术平均 (a + b)/2。

在数学中有一条非常简单的规则。算术平均总是大于几何平均。 唯一的例外是两边相等的情形（a = b），也就是静止的时钟。而两种平均之比恰好是爱因斯坦的时间膨胀因子。 一个由我们选定数字的例子：a = 2，b = 8。算术平均是 (2 + 8)/2 = 5。几何平均是 √(2 × 8) = √16 = 4。运动时钟标记 4，而实验室中过去了 5。用公式表示：

√(ab) / ((a + b)/2) = √(1 − v²/c²)

我们来看时钟在光格点上如何一步一步前进。静止的时钟走对称的步 (1, 1)。边 a 和 b 互素的步是不可分的。从 (0, 0) 到 (a, b) 的直线段内部恰好包含 gcd(a, b) − 1 个网格点。当最大公约数为 1 时，内部点为零。这在 3600 对数上无一例外地得到核查。运动时钟每个基本步在空间中前进 (b − a)/2。

[S] 已声明的形式化。 我们用三个等同把前提 P8 转译成公式。

  1. 交换分数的两个部分是第 3.5 节的两个份额：ψ/2 = (1 + w)/2 和 Nψ/2 = (1 − w)/2。每一个沿相反方向移动 w/2。一个增加 w/2，另一个减少 w/2。
  2. 远方观测者的单位是稳定的：这意味着两个份额之和保持不变。ψ + Nψ = 2。
  3. 光是构型的一种变化。它读出时间和长度的定域单位之积：Nψ² = ψ · Nψ。

[C] 结果。 从这三行立即得出 Nψ² = (1 + w)(1 − w) = 1 − w²。第 11.1 节中观测所要求的项 −w²，就是这样产生的：来自通过乘积读出的一个固定的和。特别地，并没有假定两个份额在统计上独立。在概率论中，两个事件独立时概率相乘。而这里两个份额的依赖程度最高：一个给出的恰好是另一个收到的。

还不止这些。两个份额之比 ψ / (Nψ) = 1 / N 恰好等于 1 + z。这是在该地点发射、在远处接收的光向红端的引力移动（redshift）。数 w 衡量两个份额之间的不平衡。它是转移的分数 w/2 的两倍。我们在下一段中看到：在理想的布朗模型中，w 也是一种到达概率。

逻辑地位。 P8 是一个前提。三个等同是它的已声明转译。和在 3.5 中一样，两个份额之和按构造为一。P8 把这一事实解读为一种交换。但是在这里它没有给出运动方程，也就是交换如何随时间发生的动力学。如果我们在恒星内部逐点保持这一解读，就重新得到第 4 节的闭合。

11.3 解读为到达概率的沉积 [C]

现在我们来看引力与随机行走击中目标的概率之间的联系。

取三维空间中的布朗运动。它永不停止地行走。它从距一个半径为 ε 的小靶球 r 处出发（r ≥ ε）。它迟早碰到那个小球的概率是多少？一条经典定理给出回答：Kakutani 1944，对 ℝ³ 中的正则靶成立。这个到达概率恰好是 ε / r。

我们把这个公式与第 3.6 节的沉积比较，后者是 1/(2πr)。这两个数只相差一个固定常数：2πε。现在我们来看公设 T（第 3.7 节）。它说移动的份额是 w = GM/(2rc²)。什么时候份额 w 对每个距离 r 都恰好等于到达概率 ε/r？当靶的半径为：

ε = GM / (2c²)。这恰好是各向同性坐标中黑洞视界的半径。

因此，公设 T 的系数恰好是各向同性视界的半径。对太阳，它约为 738 m。对地球，它是 2.2 mm。它们是物体中心的虚拟靶。我们取平坦几何作为参照（欧几里得度规 δ）。相对于它，函数 w = ε/r 是调和的。它在视界球面 r = GM/(2c²) 上为 1。它在无穷远处降到 0。所以 w 恰好是平坦空间中布朗路径到达视界球面的概率。

如果布朗运动在恒星或黑洞空间的弯曲几何中行走呢？这种几何由度规 ψ⁴δ 描述。在那个弯曲空间中，布朗运动的算子是 ½Δ_g。在那里函数 w 不再是调和的：事实上 Δ_g w = 2ψ⁻⁵|∇w|²，它不为零。那么，在弯曲几何中，在视界上为 1、在无穷远处为 0 的调和函数是什么？计算给出 1 − N = 2w/(1 + w)。

1 − N 是落入视界的概率。它对一的补数，也就是 N，于是有明确的含义： 时钟速率 N（时移函数）是在空间的弯曲几何中，一条布朗路径从不碰到视界而逃逸到无穷远的概率。

在广义相对论中，已知静态真空的时移函数 N 在空间度规中是调和函数。这是一个深刻的数学性质。例如，它被用来证明黑洞的唯一性定理（Bunting 和 Masood-ul-Alam 1987）。它还在 Bray 著名的质量–容量不等式（2001）中定义视界的*容量*。简而言之：

  • 在欧几里得解读中，也就是平坦的解读中，不平衡量 w 是到达视界的概率；
  • 在空间的弯曲解读中，N 是逃逸到无穷远的概率，1 − N 是到达视界的概率。

这些陈述在空旷的外部空间（r ≥ GM/(2c²)）成立。视界被当作吸收边界。路径有无限长的时间可用。对于太阳或地球这样的普通物体，视界会埋在物质内部。在那里靶只是虚拟的。这一解读描述的是理想化的外部场。

11.4 在碎片化测试平台上的检验 [C]

沉积与到达概率之间的这种联系，对连续而理想的布朗运动成立。对我们的记录器碎片化（第 3.6 节）的离散步骤，它也成立吗？

作者用一系列计算机检验核查了这一点。预测在计算之前预注册。在第 3.6 节测试平台的原始尺度上，立刻出现了一个几何问题。在距离源 r 处，一条链大约有 1/(r² + 1/T) 次解读。所以它迈出的步长与 r² 相近。这些步长与 3.6 中使用的靶单元相比并不小。链有可能*跨过*单元而碰不到它。就像巨人跨过一块小石子而没有踩到它。

为了减小这种由离散步骤造成的误差，整个检验的几何缩小了 4 倍（尺度 1/4）。并且跟踪了每一次解读，一次也没有跳过。每条链有 4,000,000 次解读，共模拟 3000 条链。下表给出六个距离 r 上测得的到达概率与理论布朗定律之比。比值等于 1 表示完全一致。

下面是所有的结果：正面的结果，以及未满足的预注册阈值。

  • 与沉积成正比。 在缩小为 1/4 的平台上，到达概率与沉积成正比，在 4.4 % 以内。这是用预注册的估计量时中心值之间的最大差别。比例常数是 0.952 × 2πε。计算之后在同一球壳上所作的直接比较给出 4.5 % 和常数 0.948。
  • 亏缺的减小。 在两个最小的半径（0.0015 和 0.002）上，与 1 的差别几乎为零：0.998 和 0.993。它在 0.011 和 0.012 的统计误差之内。在其他半径上，相对于 1 的亏缺比原始尺度缩小了 3 到 6 倍。这证实了一点：在原始尺度上漏掉的到达，有很大一部分取决于离散步骤的大小。
  • 分块观察丢失的到达。 我们可以不检查每一次解读，而只按解读块检查位置。这样会丢失多少到达？链可能在一块和下一块之间进入又离开单元。在相同的链上测得，在最小半径处丢失 4.7 % 的到达。在最大半径处丢失 1.3 %。
  • 与检验前预注册的预测比较。 一项预注册的预测说明了转到尺度 1/4 时偏差会缩小多少。这项预测成立。而最严格的阈值 E3 未满足。它要求在所有半径上都保持在 0.95 以上。在两个最大的半径上，值停在 0.915 和 0.904。此外还有核查 E1，针对快速块生成器与精确路径的比较。它以很小的差距没有达到容差。而在最初的检验中，在原始尺度上，预注册的准则未满足。

总之，数值结果支持这一假说：在连续极限下，碎片化的首次到达遵循布朗运动的定律。这正是数学上的不变原理使人预期的。不过，要作严格的证明，需要一条专门针对碎片化路径的收敛定理。我们要记住，这整个平台存在于记录器状态的 Fisher 空间中（前提 P3）。它在有限的最大时间 s_max 停止。这就是 erfc 修正因子的来源。

12. 对最常见问题的回答（预想的问题）

下面是细心的读者可能提出的七个批评性问题。每个问题都有直接的回答。

  1. 重叠是在哪些分布之间计算的？你们为什么不用相对熵？

它是在该地点和远方观测者的狄利克雷分布之间计算的。它们被投影到垂直于连接两者的视线的平面上（第 3.4 节）。解读很多时，这些光斑是圆的（各向同性），宽度为 1/τ。我们使用归一化重叠，是因为它的两个相反方向之和是一个固定常数：在平面上是 2。而用相对熵，这个和逐点变化（第 3.1 节）。取从该地点看的方向是一个已声明的选择。

  1. 在物质之外，规则 ψ + Nψ = 2 不就是一个平凡的结果吗？真空中的拉普拉斯方程是线性的。

是的。 在物质之外，这个关系是真空广义相对论的一个简单性质。模型新的物理内容在物质内部（第 4 节）。

  1. 广义协变的形式，也就是在任何坐标系中都成立的形式，是什么？一般情况下 ψ 和 N 从哪些量读出？

目前没有广义协变的形式。不过，在我们有限的范围内，即静态和球对称，ψ 和 N 的定义没有歧义。N 是静态基灵（Killing）矢量的长度（范数），该矢量指示静态时间的流动。ψ⁴ 是空间度规的标度因子。事实上，每个球对称的三维空间都可以写成一个平坦网格乘以因子 ψ⁴。

  1. 物理空间有三维，为什么你们在重叠公式中使用 D = 2 维？

因为比较是在投影到垂直于视线的屏幕上的图像上进行的（前提 P2）。在整个三维状态空间中出现的是指数 3/2。那样和就不再是 2（第 3.4 节）。本工作没有指出直接测量这种重叠的实验室仪器。

  1. 在恒星内部放弃了哪个爱因斯坦方程？能量条件会怎么样？

放弃的是广义相对论的时移方程。哈密顿约束被保留。压强由流体静力学平衡，也就是由守恒得到。因此，流体的压强不再产生引力场。透过广义相对论的眼镜看，恒星有一种额外的各向异性应力。如果致密度超过 4/9，这种应力必定违反 Andréasson（2008）的条件之一：p_r ≥ 0 或 p_r + 2p_t ≤ ρ。在均匀密度的恒星中，流体的压强无论如何都保持为正。并且它从中心到表面平滑下降。能量条件在记录 MM 2.34 中详细研究。

  1. 在公设 T 中，你们为什么选择归一化 S4 而不是 S3？

两者都通过今天在太阳系中的检验，因为它们都给出 γ = β = 1。但是 S4 在所有阶上都精确重现施瓦西度规。而 S3 在三阶偏离它。选择 S4 是把广义相对论用作外部的指导准则。它不是 MM 的前提所强加的。

  1. 这种推理不是循环的吗？也就是说：你们是不是一开始就放进施瓦西度规，到最后再把它找回来？

施瓦西度规进入的地方是公开声明的。它随公设 T 和选择 S4 进入（第 3.7 节）。链的所有其他步骤计算的是数学形式：密度之比、两个视点之间的份额、来自布朗运动的 1/r 沉积。这些形式不包含引力的度规。
